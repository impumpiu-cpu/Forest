# Тёплый Брод

Симуляция поселения в духе RimWorld: физические поля на сетке, навигация по полям течения и агенты с потребностями, характерами и вечерним советом у костра. Работает в браузере без зависимостей во время выполнения.

## Запуск

Код написан на ES-модулях, поэтому `index.html` нужно открывать через локальный сервер:

```bash
python3 -m http.server 8000      # или: npm run serve
# затем http://localhost:8000
```

Для запуска без сервера есть собранная версия `dist/forest.html`: это один файл, который открывается двойным кликом. Пересобрать её можно так:

```bash
npm install      # один раз, ставит esbuild
npm run build    # src/ → dist/forest.html
```

При запуске открывается выбор режима: **Мир** — полигон глобальной карты (генерация мира по этапам с летописью сбоку), **Карта** — поселение на локальной карте. Пока это два независимых полигона; как они сошьются, записано в `docs/WORLD.md`.

## Проверки и балансный прогон

Всё ниже работает без браузера, на том же ядре, что и игра.

| Команда | Что делает |
|---|---|
| `npm test` | Четыре проверки подряд: ядро не зависит от экрана, глобальная карта детерминирована, ссылки в справочниках сходятся, игра детерминирована и сохранение продолжается тик в тик, колония живёт 2 дня без ошибок |
| `npm run atlas -- 3 medium` | Глобальная карта: один сид даёт тот же мир, доля суши, море по краю, целые плиты, породы и руды по геологии, пояса температуры и осадков, дождевая тень, сток без петель, солёные озёра в сухом климате, золотой песок в реках, биомы по Кёппену, зоны по широте, лесистость, плодородие почв, дикая эра: звери в своих биомах, логова порознь, летопись; эпоха древних: города на суше и с подходящими постройками, дороги у городов и не по морю |
| `npm run smoke -- 10 лес` | Колония на 10 дней с сидом «лес»: что происходило по дням, снаряжение, журнал |
| `npm run determinism -- 4` | Две игры с одним сидом совпадают; сохранённая на середине игра продолжается так же, как исходная |
| `npm run balance:standard` | **Стандартный балансный прогон**: набеги нет / редкие / частые, волки стаями, 10 сидов × 30 дней |
| `npm run balance -- …` | Балансный прогон со своими параметрами: много игр параллельно, таблица и отчёт с графиками |

### Балансный прогон

Стандартный прогон — с ним сравниваем каждое изменение баланса:

```bash
npm run balance:standard
# то же самое полностью:
node tools/balance.mjs --seeds 10 --days 30 --vary raids=off,rare,often --set predators=many
```

Три варианта набегов (нет, редкие, частые) при стаях волков, по 10 сидов на 30 дней, всего 30 игр. На двух ядрах занимает около 5 минут. Отчёт ложится в `runs/<дата-время>/report.html`. Чтобы положить его в свою папку, добавьте `-- --out runs/имя`.

Свои прогоны:

```bash
npm run balance -- --seeds 12 --days 30                         # базовые настройки меню, 12 сидов
npm run balance -- --set raids=often --set predators=many       # поменять настройки для всех игр
npm run balance -- --vary raids=off,rare,often --seeds 10       # сравнить варианты
npm run balance -- --vary raids=rare,often --vary stock=poor,normal   # варианты перемножаются
```

Параметры: `--seeds N` (сиды 1…N), `--seed-base K` (сдвиг сидов), `--days N`, `--set ключ=значение` (любой ключ стартового меню из `data/presets.js`, например `size=large`, `colonists=5`, `climate=cold`), `--vary ключ=a,b,c`, `--jobs N` (потоков, по умолчанию все ядра), `--out папка`.

Игры идут в рабочих потоках, по одной на ядро. Результат — в `runs/<дата-время>/`:
- `report.html` — отчёт: итоги по вариантам, доля выживших поселений по дням, любой показатель по дням (медиана и разброс между сидами), причины смертей, скорость расчёта;
- `runs.csv` — строка на каждую игру: выжила ли, на какой день пала, все показатели на конец;
- `days.csv` — строка на каждый игровой день каждой игры, для своих графиков в таблицах;
- `summary.json` — то же, что в отчёте, для скриптов.

Что измеряется, задаёт справочник `data/metrics.js`: добавленная туда строка сама появится в CSV, отчёте и выборе показателя. Игра без экрана запускается функцией `simulate(cfg, {days})` из `src/headless.js`.

На средней карте день игры считается примерно за секунду, игра на 30 дней — за полминуты на ядро.

GitHub Pages работает с `index.html` напрямую: Settings → Pages → ветка `main`.

### Проверка справочников

`tools/check-data.mjs` (входит в `npm test`) проверяет, что все ссылки между записями сходятся: ресурсы в ценах и рецептах, постройки в `requires` и `needs`, мастерские у рецептов и работ, значки предметов, мысли у еды. Ошибка останавливает тест с понятным текстом, а предупреждение говорит о записи, которая в игре никогда не появится (ресурс ниоткуда не добывается, предмет нельзя сделать).

### Проверка логики

`tools/logic-check.mjs` (входит в `npm test`) собирает маленькие сцены на ровной пустой карте и проверяет правила, которые нельзя нарушать: хищник не бьёт издалека, несъедобный груз не становится сытостью, груз не мешает ответить на нападение, спрятавшуюся нечисть не бьют, никто не срезает угол между скалами, яд действует на всех, жаростойкий зверь не бежит от тёплой земли, караван без дороги не считает себя пришедшим, старая отметка застревания не мешает новой цели, волк не идёт к чужой добыче, совет видит кости от охоты. Сцены T18–T22 проверяют отряды налётчиков: у отряда одна цель, вожак и роли; при больших потерях и гибели вожака он отступает; противника держат и не мечутся; грабитель идёт к складу мимо защитников; пришедшие за одним идут за ним и уходят после расправы. Сцены T27–T31 проверяют туши и охоту стаей: добыча остаётся тушей, и стая ест из неё; голодный зверь возвращается к недоеденной туше; охотник отбивает тушу у сытых зверей; в погоне есть ведущий и загонщики, а охота закрывается одним итогом; неубранная туша в темноте поднимает упыря. Сцены T23–T26 проверяют совместные действия: одиночку в опасном лесу сопровождают; раненого перевязывают, и он это помнит; выздоравливающий уступает койку; при опасности ссору откладывают. Сцены T12–T17 проверяют резервы и жизненный цикл: к занятому верстаку второй не идёт, лишнему раненому койки нет, одно тело несёт один, прерванное дело отдаёт свои резервы, прерванный сбор продолжается с того же места, отказавшее дело не берут снова сразу же.

### Поведенческие метрики

Балансный прогон, кроме запасов и смертей, считает, как ведут себя существа (`settlement/behaviour.js`, группа «Поведение» в `data/metrics.js`): недопустимые состояния (существо в скале, в воде, за картой, груз не сходится — должно быть 0), простой и время в тревоге в процентах, смены дела и остановленные дела на человека в день, итоги поручений (доля сорванных — заблокировано или невозможно, и сколько на человека в день доведено, заблокировано, невозможно, прервано), отказы «пути нет» (всего и у поселенцев), время реакции на нападение и нападения, оставшиеся без ответа, исходы визитов отрядов налётчиков (цель достигнута, отступили, разбиты), охоты стаей (сколько в день, доля удачных), туши на земле и поднявшиеся из них упыри, совместные действия (доля времени в сопровождении, сопровождения в день, перевязки, уступленные койки, отложенные ссоры, забытые обиды). В консольной сводке видны простой и недопустимые состояния, остальное — в `runs.csv`, `days.csv` и отчёте.

### Жизненный цикл задач и резервы

Каждая задача поселенца входит один раз и закрывается один раз с итогом (`agents/lifecycle.js`): **сделано**, **заблокировано** (здесь сейчас нечего делать: нет заказа, нет свободной койки — это же дело не берётся 120 тиков), **невозможно** (туда нет пути — пауза 600 тиков) или **прервано** (пришло что-то важнее: нападение, совет, сон, дело получше). Задача сама заканчивает себя через `endTask()`, а задачу, которую сменили снаружи (выбор `decide()`, рефлекс, тревога), ловит `syncTask()` — мозг вызывает его вокруг каждого шага. Закрытие всегда одинаково: отдаёт резервы, сбрасывает путь и преследование, вызывает выход задачи (`exit`, у работ — `RUNNER_EXIT`). Сбор и поле при прерывании запоминают сделанную работу (`a.resume`), и вернувшийся к тому же кусту продолжает с того места. Срыв или прерванная работа видны в карточке с причиной (`a.lastStop`).

Резервы (`settlement/reserve.js`) — аренда «один держатель на место»: верстак мастерской (`bench:<id>:<k>`, столько, сколько у здания `benches`), койка у лекаря (`bed:<id>:<k>`), тело для похорон (`corpse:<id>`), зверь у скотника (`beast:<id>`). Резерв берётся при выборе дела, продлевается по пути и в работе, истекает сам через 40 тиков и снимается при закрытии задачи или смерти. Поэтому двое не идут к одному верстаку: второй сразу выбирает другое дело. Хранится в `w.reserve` и `a.holds` и сохраняется с миром.

### Быстродействие

Поля течения, которые нужны только тому, кто ими ходит (грядки, руда, берег, мастерские, поле, хижина лекаря, ягоды, лес), пересобираются только пока кто-то занят такой работой (`inUse` в `data/navmaps.js`); устаревшее поле всё равно ведёт в нужную сторону, а работник, пришедший к пустой грядке, помечает его к пересборке. Поле добычи для хищников строится, только пока хищник голоден. Проход огня по всей карте пропускается, когда нигде не горит и нигде не жарко до возгорания.

Тепло и дым считаются по всей карте каждый тик, это самая дорогая часть. Снос ветром считает точку выборки для столбцов и строк один раз, а не для каждой клетки; дым не считается вовсе, пока нет огня и прежний дым рассеялся. Карта местности и слои перерисовываются несколько раз в секунду, огонь и дым — каждый кадр. Вопросы, которые за тик задают много раз (список колонистов, что колония может сделать в мастерских, какую руду копать), считаются один раз через `perTick` и лежат в `w.scratch`, который не сохраняется. Медленные кэши, которые должны пережить сохранение, лежат в `w.cache` и хранят только данные.

### Ядро и оболочка

Состояние игры — один объект `world`, который передаётся во все функции. Модули не держат глобального состояния.

Код делится на **ядро** (всё, кроме `ui/`, `render/` и `main.js`) и **оболочку**. Ядро не знает об экране: не импортирует оболочку и не трогает `document`, `window`, хранилища браузера. Это проверяет `tools/check-layers.mjs` при каждом `npm test`. Оболочка читает `world`, чтобы рисовать, а менять мир может только через `COMMANDS` из `commands.js`. Поэтому любую другую оболочку — другой рендер, сервер, бота, балансный прогон — можно подключить к тому же ядру без правок.

### Детерминизм и сохранения

Один сид, одни настройки и одни действия игрока дают одну и ту же историю. `Math.random` в ядре не используется. Карта строится из одной последовательности `w.rng`, а идущая игра берёт случайность из отдельных потоков по подсистемам (`w.rngs`, `core/rng.js`): погода, огонь, звери, нечисть, бой, поселенцы, отношения, внешний мир и рождение существ. У каждого потока своё зерно — сид игры плюс имя потока. Правка в одной части меняет только её поток: если поправить бой, у того же сида останутся прежними погода и всё, что от боя не зависит. Поэтому сравнение «до и после» на одном сиде показывает саму правку, а не другую историю. `tools/rng-check.mjs` (входит в `npm test`) проверяет это: сдвигает поток поселенцев на одно число и сверяет погоду. Если код начнёт брать погоду из чужого потока, проверка упадёт.

`world/save.js` превращает мир в JSON и обратно. Справочники и пресеты в сохранение не копируются, а записываются ссылкой вида `building:hut`. Живые части собираются заново: каждый поток случайности продолжает с сохранённой позиции (формат сохранения 2; сохранение формата 1 с одним потоком тоже загружается — его потоки засеваются из сида и позиции старого потока, одинаково при каждой загрузке), навигация получает свои поля расстояний в том же состоянии. Поэтому загруженная игра продолжается тик в тик как исходная. Если в мир попадёт то, что нельзя сохранить (функция, экземпляр класса), сохранение остановится с точным путём к этому месту.

В браузере сохранения лежат в IndexedDB: кнопка «Сохранить», автосохранение каждое утро, список в меню. Кнопка «В файл» скачивает сжатое сохранение (на средней карте около 450 КБ), а меню открывает его обратно.

### Граница с внешним миром

Локальная карта общается с остальным миром только через `outside/`:
- **внутрь** приходят группы: переселенцы, звери, налётчики (позже послы, торговцы, поручения);
- **наружу** уходит ежедневный отчёт колонии: жители, оружие, броня, постройки, запасы (позже дань и послы).

У каждого прибытия две половины. **Предложение** — кто выходит в путь и когда — решает поставщик за границей. **Приём** — сколько из них останется — решает местная запись в `data/migrations.js`: есть ли место и еда, прокормят ли луга ещё зайцев, нет ли уже стаи волков.

Сейчас за границей стоит заглушка `outside/scripted.js` с соседями из `data/neighbours.js`: Род Ольхи (переселенцы, иногда из других дружественных рас), Враждебные земли (налёты разных банд), Имперский тракт (караваны), Дикие леса (звери). Налётчики не видят лагерь: угрозу они считают по последнему отчёту колонии, то есть по слухам суточной давности. Позже на место заглушки встанет статистическая карта мира с поставщиком той же формы, и локальная игра этого не заметит.

## Как добавить новое

**Ресурс.** Запись в `data/resources.js` с группой `group` (раздел на складе). Тег `fuel` пускает ресурс в костёр (порядок задаёт `burn`), `smelt` — в плавильню и кузницу, `ore` с полем `ore` — в добычу на руднике, `luxury` с `value` — в товары для будущей торговли. Склад, панель и грабёж подхватят ресурс автоматически.

**Городской инструмент (ключ).** Ресурс с тегом `key`, `sell: false` и описанием `opens` в `data/resources.js`. Постройка, которой он нужен, называет его полем `key` и включает в `cost`; инструмент, который работает со склада, задаёт `effects` (и `with: '<вид>'`, если нужен ручной зверь). Торговцы привозят такие инструменты сами, колония покупает их, когда может применить.

**Мебель.** Запись в `data/furniture.js`: `comfort` (насколько она поднимает статус постройки), цена и `recipe` (где и из чего делают) или `tradeOnly` (тогда добавьте её в `TRADE.WARES`). Мебель сама становится ресурсом и рецептом. Постройка принимает мебель, если у неё `furnish: true`.

**Домашний зверь.** Блок `tame` у вида в `data/species.js`: шанс приручения, места в загоне, приманка, сколько сена ест, молоко, шерсть, приплод, работа на колонию (`effects`) и имена. Загон, скотник, кормление и забой подхватят его сами.

**Еда.** Запись в `data/foods.js`: сытность, скорость порчи `spoil`, вкус `taste` (вкусное чаще становится любимым). Еда сама попадает в ресурсы с тегом `food`. У каждого поселенца есть любимая и нелюбимая еда: любимую он берёт первой, нелюбимую ест только когда больше нечего, и то и другое оставляет мысль в дневнике. Работа, которая приносит еду, указывает её полем `food`: такую работу колония хочет тем сильнее, чем сытнее эта еда (мясо и рыба сытнее ягод) и чем больше жителей по ней скучает, когда её запас кончился; сам поселенец охотнее берётся за работу, которая приносит его любимую еду.

**Работа.** Запись в `data/jobs.js` с одним из исполнителей:
- `harvest`: идти по полю `nav`, работать `time` тиков, взять единицу, унести `carry` единиц. Нужны `valid(w, i)` и `take(w, i)`. Если цель новая, добавьте поле в `navmaps.js`.
- `hunt`: выслеживать добычу из `prey` и стрелять с дистанции `range`.
- `build`: работать на стройке.

Каждая работа указывает навык `skill` из `data/skills.js`: его она тренирует и по нему считает скорость. Мастерская берёт навык рецепта (`skill` у рецепта или навык станции из `STATION_SKILL`). Опыт начисляется только за реально сделанную работу (`practice` в `agents/skills.js`), а не за выбор работы или подсчёт скорости. Новой работе нужна строка в `FROM_JOB`, чтобы старые сохранения знали, куда перенести её опыт.

С `preferable: true` работа попадает в пул, из которого поселенцам выпадают любимая и нелюбимая работа. `requires: 'quarry'` открывает работу только после постройки. `desire(w, ctx)` задаёт, насколько колонии нужна эта работа сейчас.

**Предмет.** Запись в `data/items.js`: слот, число рук, `melee`, `ranged`, `block`, `armor`, `warmth`, `tool`, `dur`. Поселенцы сами оценят предмет и наденут его, если он им выгоден. Если у вещи есть особый значок в руке, добавьте его в `GLYPHS` в `render/looks.js`. Чтобы предмет можно было делать, добавьте рецепт.

**Руда.** Запись в `data/ores.js` (код в сетке, какой ресурс даёт, цвет, как лежат жилы: пласты `seam` или гнёзда `pocket`) и ресурс для неё в `data/resources.js` с `target` — сколько держать на складе. Рудник, слой ресурсов, подкраска скал, карточка клетки и легенда подхватят её сами.

**Украшение.** Запись в `data/luxury.js`: сколько самоцветов, во что оправлен (`setting`), работа, цена `value`. Из записи сами получаются ресурс склада и рецепт ювелира.

**Товар у торговца.** Строка в `TRADE.WARES` (`data/trade.js`): еда, ресурсы из списка или предметы (`'plain'` — что умеет делать форпост, `'any'` — что угодно, что бывает лучше, или список id) с качеством `q`. Цена берётся из `value` ресурса или предмета; у ресурса `keep` или `keepPerHead` — сколько колония оставляет себе, прежде чем продавать. Предмет с `tradeOnly: true` в поселении не делают, его можно только купить.

**Дикая грядка (растение, камыш, глина, борть).** Запись в `data/plants.js` (где бывает, у воды ли, как редко, как быстро возвращается, в какие сезоны собирают, цвет) и ресурс для неё. Слой на сетке, отрастание, поле течения `plant:<id>`, подкраска карты и слой ресурсов появятся сами; поле `job` сразу делает работу по сбору.

**Полевая культура.** Запись в `data/crops.js` (семена, урожай с грядки, возврат семян, срок, сезоны сева) и ресурсы для семян и урожая.

**Качество.** Запись в `data/quality.js`: насколько лучше бьёт, защищает, работает и служит вещь и сколько стоит ступень. `sold: false` — такую вещь торговец не возит (+3 будет только в руинах).

**Рецепт.** Запись в `data/recipes.js`: мастерская `at`, стоимость, работа, результат (`item` или `resource`), нужные постройки, `fuel` (сколько угля берёт горн) и функция `want(ctx)`: насколько колонии сейчас нужна эта вещь. Новая мастерская — это постройка с `station: true` и работа `{runner: 'craft', stations: ['id'], desire: atStations(0.5)}`: работа откроется, как только мастерская построена, и будет нужна, пока там есть заказ. Поле течения к мастерской создаётся само.

**Черта характера.** Запись в `data/traits.js` с множителями `mods`: `bravery`, `cold`, `hunger`, `speed`, `work`. Черты из одной группы `group` взаимоисключающие.

**Потребность.** Запись в `data/needs.js` (убывание, вред, задача, срочность) и имя потребности в `needs` у вида. Задачу, которая её утоляет, нужно добавить в `agents/tasks.js`.

**Существо.** Запись в `data/species.js`: здоровье, скорость, потребности, внешний вид `look`, мозг `brain`, добыча `yields`. Если нужна новая форма, добавьте её рисовальщик в `render/looks.js`. Если нужно новое поведение, добавьте мозг в `agents/brains/` и зарегистрируйте его в `brains/index.js`. Пример — волки: запись `wolf` в `species.js` с блоком `predator` (добыча, жертвы, рывок, выносливость, боязнь лагеря), фракция `predators`, мозг `brains/predator.js`, рисовальщик `wolf` в `looks.js` и миграция `wolves`. Остальные системы волков не знают. Разумная раса описана ниже.

**Разумная раса.** Запись в `data/races.js`: пределы SPECIAL `special`, здоровье и скорость, физиология `body` и множители `mods` (`hunger`, `cold`, `sleep`, `regen`…), врождённые черты `innate`, мировоззрение `align`, веса ценностей `values`, строка таблицы отношений `rel`, имена и `settle` — вес среди переселенцев (0 — сама не приходит). Подрасы — `peoples`: сдвиг пределов `shift`, свои `mods` и `innate`. Новой строке `rel` нужна строка и столбец в `data/relations.js`. Чтобы раса ходила в набеги, добавьте её в банду в `data/raids.js` с ценой в `COST`.

**Зверь.** Запись в `data/bestiary.js`: SPECIAL (`around({...})` — типичный зверь и разброс), где живёт (`habitat`: биом → `common`, `usual`, `rare`, `scarce`), мозг (`predator`, `mule`, `grazer`, `vermin`, `spirit`) с его блоком, внешний вид, добыча `yields` и блок `arrive`: размер группы, раз в сколько дней приходит, шанс, сколько может быть на карте, с какого дня, только ли ночью, строка журнала. Прибытие, расписание, список соседа и легенда соберутся сами. Особые свойства: `venom` (яд), `web` (паутина замедляет), `breath` (дыхание поджигает траву), `drinks` (лечится кровью), `nocturnal` (уходит с рассветом), `hibernates` (зимой спит), `resist` (простое оружие берёт хуже). Нечисть — `resident: true` и `respawn`: живёт здесь, убитая возвращается через столько дней. Новой форме нужен рисовальщик в `render/looks.js`. Проверка: `node tools/bestiary-check.mjs [дней]`.

**Биом.** Запись в `data/biomes.js` с видом (`kind`: природная зона, высотный пояс, интразональный, особое место), цветом и пределом лесистости `trees`. Природную зону карта мира узнаёт по климату в `atlas/biomes.js classify` (пороги — `KOPPEN`). Регион задаёт доли биомов (`biomes` в `data/regions.js`, в сумме 1), звери называют свои биомы в `habitat`. Новому биому нужна почва в `data/soils.js`.

**Чудовище.** Запись в `data/monsters.js`. Ступень разума `mind`, `undead` (без потребностей и страха), `mindless` (идёт на живых, не грабит, не боится огня), `rots` и `sun` (гниль слабеет в тепле и на солнце), `drinks` (лечится кровью), `resist` (`{ranged: 0.45}` — стрелы пролетают насквозь), `weakTo: ['silver']`. Нежить с полем `master` идёт за некромантом и разбредается, когда он гибнет.

**Банда налёта.** Запись в `data/raids.js`: вес `weight(w, угроза, ночь)`, состав `members(w, rng, бюджет, угроза)` через `fill`, цели `goals(w, group)` (веса грабежа, расправы, поджога, разведки), стойкость `nerve`, сообщение. Бюджет — размер банды в «людях-налётчиках», каждый член стоит своё в `COST`. Оружие по виду берётся из `KITS`.

**Ценность.** Запись в `data/values.js` с парами `clash`. Расы называют её в весах `values`.

**Фракция.** Запись в `data/factions.js`: цвет, мозг по умолчанию, список врагов.

**Постройка.** Запись в `data/buildings.js`: цена, работа, эффекты (`add`, `mul`, `yield.<ресурс>`, `jobSpeed.<работа>`) и `motive`, доводы для совета. Для особого эффекта при достройке есть `onFinish`: функция или имя хука в `settlement/buildings.js`.

**Миграция.** Две записи. В `data/migrations.js` — как выглядит группа (вид, фракция, снаряжение, сообщение) и `accept`: сколько из предложенных примет колония. В `outside/scripted.js` — поток: от какого соседа, когда первая проверка, сколько выходит в путь, когда следующая.

**Показатель для балансного прогона.** Строка в `data/metrics.js`: `id`, подпись, группа, число знаков и `get(w)`.

**Действие игрока.** Функция в `COMMANDS` (`commands.js`), а в оболочке кнопка, которая её вызывает.

## Механики

**Регион.** Земля под форпостом выпадает из сида мира (`data/regions.js`, `world/region.js`): лесистые холмы, речная долина, каменистое предгорье, северная тайга или старые копи у потухшего вулкана. От местности зависят руды (нет, бедно, есть, богато), золото в отмелях, могут ли попасться золотая жила и мифрил, есть ли магма, какие звери приходят, какие дикие грядки растут (пчёлы, травы, солонцы, дикий лён) и как близко тракт (чаще или реже караваны). Каждый уровень при броске может сдвинуться на шаг, так что две долины различаются. Лес, ягоды, вода, крапива, камыш, глина и зайцы есть везде; если нет ни оленей, ни коз, придут хотя бы олени. Что есть в регионе, показано на вкладке «Мир». Позже местность будут выбирать на глобальной карте.

**Руда и металлы.** В скалах лежат жилы железной руды, угля, самоцветов, медно-оловянной руды, серебристой руды и (очень редко) мифрила — сколько и каких, решает регион. Цепочка:
- рудник открывает работу «добывать руду»: копают ту руду, которой на складе меньше нужного; выработанная жила оставляет проход, и за ним открывается новый склон. Из серебристой руды порой падает самородное серебро;
- уголь один: углежогная яма жжёт его из брёвен (4 → 3), рудник копает из пласта. Костёр жжёт сначала дрова, потом уголь (он горит вдвое дольше);
- **жар.** У каждого рецепта горна и кузни есть уровень жара. На дровах (3 полена за единицу жара) плавят медь, бронзу, золото и серебро; железо плавят и куют только на угле. Где угля много, горн берёт уголь и для меди — он идёт дальше дров. Магма (позже) не будет расходоваться;
- **кузнечные меха** (у торговца) ничего не открывают, но лежа на складе экономят четверть топлива, ускоряют работу горна и кузни на четверть, и кованая вещь в 5% случаев выходит добротной (+1);
- сыродутный горн (камень, дерево, глина): железо на угле; медно-оловянная руда сразу в бронзу; золотой песок (12) и самородки в слитки; серебристая руда в слитки с покупными купелями, самородное серебро — без них. Из бронзы льют наконечники копий, топоры и колокол для святилища;
- походная кузня (с наковальней): меч, копьё с железным наконечником, железный топор, ламеллярный доспех, кованый сундук; посеребрённые меч и копьё;
- верстак резчика (с резцами): самоцвет + кость, дерево, камень или железо → украшения на продажу; резной ларец.
Стали форпост не делает.

**Золото, серебро, мифрил.**
- **Золото** моют в отмелях: в регионах с россыпями у воды лежат золотоносные пески. Нужен промывочный лоток (ремесленник, 2 древесины); подо льдом не моют. Песок идёт малыми долями, изредка (2%) попадается самородок. Когда выработанная жила вскрывает новый склон, в регионе с золотом раз за игру может открыться кварцевая жила с самородным золотом (шанс 2% на выработку): об этом узнают все, и слух поднимает угрозу набега.
- **Серебро** нужно для оружия против тех, кто боится серебра (поле `weakTo: ['silver']` у вида): посеребрённый клинок бьёт их в 2,5 раза сильнее, обычный — вдвое слабее. Таких чудовищ пока нет, но кузня держит пару посеребрённых клинков, если серебро есть.
- **Мифрил** форпост переработать не может: нужна магмовая кузня, её нельзя построить, только захватить (позже, через глобальную карту). Руду продают купцу (40 зол. за единицу); прослышав о мифриле, купец приходит с туго набитым кошельком. Слух о мифриле тоже поднимает угрозу набега.

**Металл как деньги.** Казна — это монеты плюс золото и серебро по курсу: слиток золота 0,9 своей цены, слиток серебра 0,85, самородок 0,8, самородное серебро 0,75, песок 0,7. Колония платит сначала монетами, потом металлом с самым низким курсом; металл уходит купцу. Металл не продают как товар: это деньги. Налётчики первым делом хватают золото и серебро, но кованый сундук в любой постройке прячет больше половины.

**Хлеб, свечи, меха.** Ручные жернова мелют ячмень в муку, на очаге из неё пекут хлеб (сытнее зерна, хранится дольше каши). Из воска делают свечи: свеча у святилища делает молитву утешительнее. Лисьи меха идут на тулуп на меху — самую тёплую одежду форпоста. Соль можно собирать на солонцах, семена льна — с дикого льна осенью, если они есть в регионе.

**Карта.** Колесо мыши приближает к курсору, перетаскивание левой (или любой) кнопкой двигает карту, кнопки «+», «−» и «Вписать» в углу карты делают то же с клавиатуры: `+`, `−`, `0`. Ближе всего клетка становится 40 точек экрана. Щелчок без перетаскивания — действие инструмента.

**Торговля.** По Имперскому тракту приходят караваны: проверка на 10-й день, потом каждые 10 дней, и каждый раз караван выходит с вероятностью 70%. Он выходит с края карты утром и к вечеру встаёт лагерем в нескольких шагах от костра: купец (жёлтый), два охранника в кольчугах с мечом и щитом +1 и 1–3 вьючных мула с двумя ящиками по 10 мест, заполненными на 50–100%. Сразу после совета идёт торг, вторая сходка вечера: поселенцы собираются у товара. Колония продаёт работу ювелира, лишнее снаряжение со склада (то, что никому не было бы шагом вперёд) и запасы сверх того, что оставляет себе; потом покупает еду, если её мало, и вещи, которые кому-то заметно лучше нынешних, — сначала самые выгодные за свою цену. Остальное золото копится до следующего каравана. Купец платит 0,7 цены и просит 1,2; деньги — имперские золотые, другого пути к ним нет. Ночь караван проводит у костра и утром уходит. Если купца убьют, торга не будет. Всё это видно на вкладке «Торговля».

**Времена года.** Год — четыре сезона по 30 дней, игра начинается весной (сезон и день видны в шапке рядом с часами). Всё, что меняет сезон, — числа в `data/seasons.js`:
- **весна** — прохладно, часто дожди, звери возвращаются;
- **лето** — тепло, ягоды и травы растут быстрее всего, но еда на складе портится быстрее, а лес легче загорается;
- **осень** — рост замедляется, земля желтеет, все охотнее делают заготовки;
- **зима** — около −10 °C по ночам в умеренном климате (−19 °C в холодном), снег. Первый мороз сбивает почти все ягоды с диких кустов, ничего не растёт, рыба ловится вдвое хуже, зайцев втрое меньше, волки голоднее; еда почти не портится. Живут запасами, тёплой одеждой и огнём: шалаши греются от костра, и замёрзшие идут греться к ближайшему огню или в шалаш. Зимой одежду выбирают по теплу, а не по броне; ремесленник к осени шьёт тулупы из шкур.

**Заготовки и готовка.** Вешала и бочки (14 древесины) — заготовки: ягоды, рыбу и мясо вялят на ветру (кроме зимы), а с солью, которую привозят только торговцы, солят в бочках в любое время. Вяленое и солёное почти не портится. Заготовки делают из того, что сверх еды на ближайшие дни, осенью охотнее всего, и останавливаются, когда запасено около 10 порций на жителя. Очаг (8 камня, 6 древесины) — повар варит похлёбку из двух припасов (зимой и из заготовок): она сытнее, чем они порознь, горячая еда поднимает настроение, но похлёбка не хранится. За едой берут сначала похлёбку, потом то, что портится быстрее, а заготовки остаются на зиму; любимая еда (и всё, что из неё сделано) по-прежнему важнее. Соль колония покупает у каждого торговца, пока её меньше 12.

**Почва.** У каждой клетки своё плодородие (слой «Почва»: от бледной глины до тёмного перегноя; значение видно при наведении и в карточке клетки). Поле (4×4 грядки) и ягодный огород (4×3 куста) — участки земли за изгородью, а не дома: их ставят на самой плодородной земле в двадцати клетках от лагеря, предпочитая лишние несколько шагов тощей почве. На хорошей земле хлеб растёт быстрее и родит больше (урожай ×0,4…×1,6), ягоды в огороде зреют быстрее. Зола после пожара немного удобряет землю.

**Ремесло форпоста.** Форпост делает грубую версию вещи, хорошую нужно купить. Цепочки:
- крапива (дикие грядки на плодородной земле) → волокно → верёвка (у ремесленника) и грубый холст (на ткацком станке) → холщовая одежда; лён с поля даёт волокна больше;
- камыш у воды → кровля изб, короба;
- глина в берегах озёр (яма понемногу наполняется) → горшки в гончарной яме: еда в горшках портится медленнее, и крысы до неё не достают; глиной обмазывают избы;
- брёвна → тёс на козлах для распила → избы;
- дикие пчёлы в дуплах → мёд (не портится) и воск на продажу; пчёлы жалят;
- луговая трава летом и осенью → сено: подстилка в шалашах и корм скоту;
- козы в загоне → молоко → сыр; шерсть → шерстяная свита, холст, ковры.

**Жильё.** Шалаш строится из подножного сырья, но продувается: зимой его очаг жжёт много дров, а ночёвка в нём греет слабо. Изба из тёса под камышовой кровлей, с обмазанными глиной стенами держит тепло на малых дровах, и выспаться в ней — радость. Обе постройки — места для жизни, их очаги топятся из общего запаса, пока горит костёр.

**Звери и меха.** Олени — главная дичь: много мяса, хорошая шкура. Лисы — мех, который охотно берут торговцы. Кабан, как мул, не бежит: подранок бросается на охотника, поэтому за кабаном идут, только когда другой дичи нет. Крысы приходят на полный склад и грызут еду, лежащую открыто (в горшках и амбаре её не достать). У каждой своё укрытие в зарослях в 7–13 клетках от костра. Пока у склада кто-то бодрствует, крыса сидит в укрытии; когда лагерь затихает (обычно ночью) или терпение кончилось, она делает вылазку: бежит к припасам, грызёт и возвращается. Кто подойдёт близко, тот её спугнёт, а кто окажется вплотную — может прибить. Волки теперь охотятся и на оленей и лис.

**Поля.** Поле (8 древесины, 2 верёвки) появляется, когда у колонии есть семена — их привозят торговцы. Вокруг сарая распахивают 16 грядок. Весной и летом на пустые грядки сеют то, что сейчас нужнее (ячмень — зерно и солома, репа — сытная и хранится, лён — волокно), по семени на грядку; урожай жнут, как только созреет, и часть семян возвращается, так что поле, которое держат засеянным, кормит себя само. Несжатое к зиме побьёт мороз. Из ячменя у очага варят кашу, из репы — похлёбку.

**Лекарь.** Лечебные травы растут редкими грядками на плодородных лугах и полянах (жёлтые крапинки на карте и на слое ресурсов) и отрастают сами. Хижина лекаря (20 древесины) открывает работу «лечить раненых» со своим навыком лекаря; лекарь в поселении один. Поселенец, у которого меньше трёх четвертей здоровья, идёт лечь в хижину (на три места) и лежит, пока почти не поправится. Лекарь выхаживает лежащих: без трав раны затягиваются примерно втрое быстрее, чем сами по себе, с травами — раз в семь быстрее; одна охапка трав даёт около трети здоровья. Когда лечить некого, лекарь собирает травы, пока их меньше десяти. Числа — в `settlement/healing.js`.

**Качество вещей.** У вещи бывает качество +1 (добротная), +2 (мастерская), +3 (редкая) и +4 (эпическая): она бьёт и защищает лучше, работает быстрее и служит дольше, а стоит намного дороже, как волшебные вещи в D&D 5: оружие +1 — «необычное», доспех +1 — на ступень реже и дороже. Форпост делает только простые вещи; +1 и +2 привозят торговцы, +3 появится позже в руинах, +4 — добыча с боссов подземелий (тоже позже). Эпическая вещь может носить своё имя (`{type, q: 4, name: 'Клык Вожака'}`), колония её никогда не продаёт; на карточке поселенца вещи +1/+2 подписаны золотым, +3 синим, +4 фиолетовым. Железные доспехи (кольчуга, чешуйчатый) тоже только покупные; ламеллярный доспех куют в своей кузне.

**Инструменты из города — ключи к технологиям.** Форпост не делает тонких городских инструментов, их привозят только торговцы (группа «Инструменты» на складе). Одни открывают постройку: без них её даже не обсуждают на совете, а при постройке инструмент уходит в неё (поле `key` в `data/buildings.js`). Другие работают со склада, когда стоит их постройка (`useWith`):
- продольная пила → козлы для распила (тёс, а с ним избы);
- купели и тигли → плавка серебристой руды в горне;
- кузнечные меха — не открывают, а улучшают: меньше топлива, быстрее работа, иногда добротная вещь;
- наковальня с молотами → походная кузня (мечи, копья, ламеллярные доспехи);
- резцы и лучковое сверло → верстак резчика (украшения, резные ларцы);
- железный лемех работает прямо со склада: с ручным мулом поля родят на треть больше.

Караван везёт один-два инструмента из тех, которых у колонии ещё нет. Колония покупает инструмент, как только может им воспользоваться, раньше всего, кроме еды. «Городские» постройки переделаны под форпост: вместо плавильни — сыродутный горн, вместо кузницы — походная кузня под навесом с покупной наковальней, вместо ювелирной мастерской — верстак резчика.

**Скот.** По лугам бродят дикие козы (светлые, с рожками) и мулы. Когда построен загон (14 древесины, 2 верёвки, участок 4×4 на 6 мест: коза занимает одно, мул два), скотник идёт к дикому зверю с охапкой сена: подходит медленно, и зверь его подпускает. Каждая неудачная попытка приучает зверя, следующая выходит легче; мул после неудачи лягается. Приручённый зверь носит красную верёвку, живёт в загоне (зона поселения, волки туда не ходят) и получает имя. Каждое утро:
- скот ест: летом его почти целиком кормит трава в загоне, зимой — ветки и кора, но больше всего сено со склада; косцы летом и осенью запасают сено и на скот. Если сена не хватает на всю зиму, лишних (молодых коз, потом мулов) забивают на мясо, пару коз оставляют на племя. Голодный несколько дней зверь уходит в лес;
- коза даёт молоко (зимой мало), скотник её доит; раз в 40 дней отрастает шерсть, её стригут весной и летом. Две сытые козы в тёплое время приносят козлят;
- ручной мул (полезны двое) возит брёвна и камень (рубка, камень и руда +15%) и тянет соху (поле +25%);
- в голод колония забивает козу, пока их больше двух.

Молоко быстро киснет; на очаге из него давят сыр (с солью больше), он хранится всю зиму. Шерсть идёт на шерстяную свиту у ремесленника, холст и ковры на ткацком станке. Охотники стреляют диких коз только в голод.

**Быт и настроение.**
- **Мебель.** Лавки, столы, ковры, кованые сундуки и резные ларцы делают в мастерских из того, что у колонии в избытке; зеркала, гобелены и светильники привозят торговцы. Каждая капитальная постройка (не шалаш, не поле, не яма и не изгородь) вмещает до 3 вещей со склада, их ставят каждое утро, сначала в избы. Убранство — это статус постройки: в обставленной избе спят с лучшим настроением, в мастерской и у лекаря работают быстрее (каждая вещь +4–14%), в святилище молитва утешает сильнее. На карте вещи видны золотыми точками в углу постройки.
- **Святилище** (14 древесины, 6 камня): резной идол и погост рядом. Кто пал духом, раз в день приходит помолиться. Умершего у святилища хоронят с обрядом, и скорбь отпускает живых вдвое быстрее.
- **Похороны.** Погибший остаётся лежать, где упал (серое пятно на карте). Кто-то относит тело на погост: у святилища или, если его нет, на участок у лагеря, и ставит крест. Пока волки рыщут рядом с телом, за ним не идут. Непогребённые тела больше полудня тяготят всех.
- **Брага.** Из лишних мёда с ягодами, ячменя или ягод на очаге ставят брагу (только когда еды с запасом). Вечером после совета тем, кто в самом плохом настроении, наливают по чарке, а если браги хватает на всех — пируют всем поселением. Иногда наутро болит голова.
- **Хандра.** Кто встречает утро в очень плохом настроении два дня подряд, может захандрить: несколько часов бродит по лагерю вместо работы. После пяти таких дней подряд человек может уйти из поселения насовсем, оставив снаряжение на складе.
- На вкладке «Люди» под списком жителей — скот и «дух поселения»: среднее настроение, кто не в духе, могилы, ушедшие.

**Мулы.** Крупные травоядные, почти быки: много здоровья, тяжёлый удар копытом. Мул не бегает от людей: тому, кто подошёл и напал, достаётся копытом, а на того, кто выстрелил издалека, он несётся и бьёт с разбега сильнее. Сильно раненный мул уходит, и только такого волки решаются загнать, да и то стая выходит из боя потрёпанной. Дикие мулы иногда выходят на луга (коричневые кружки). Охотники берутся за мула, только если зайцев нет, а еды почти не осталось. Вьючные мулы торговцев везут ящики по бокам.

**Экран игры.** Над картой — время, инструменты, слои с фильтрами, скорость, ветер и действия. Справа — вкладки: склад и работы, поселенцы, постройки, совет, торговля, журнал, мир. Под картой — клетка под курсором и выбранный объект: поселенец, зверь, постройка (с её заказами) или клетка (с рудой). Пояснения об устройстве симуляции — в стартовом меню.

**Совет у костра.** Пока колония копит, вкладка «Совет» показывает, чего ждут: каждый недостающий ресурс, откуда он берётся (работа, охота, мастерская) и сколько человек сейчас этим занято, а ещё сколько дней копят и какая доля недостачи уже собрана. Тяга цели доходит на одно звено вниз по цепочке: если не хватает верёвки, а её вьют из волокна, сборщики волокна тоже получают прибавку. С 19:00 до 21:30 поселенцы собираются у огня. Каждый голосует за постройку, которая решила бы его трудности за день: холод, голод, недосып, пожар, бой, долгие походы, неудачную охоту. Учитывается и любимая работа. Решение принимается большинством: если ни одна постройка не набрала больше половины голосов, две самые поддержанные идут во второй тур. Если ресурсов хватает, стройку закладывают сразу, иначе колония копит. Голосуют только за то, что ещё можно построить: у каждой постройки есть предел `max` (шалашей 4, изб 6, полей 3, огородов и вышек по 2, остальные — по одной). И только за то, на что колония может собрать: каждый недостающий ресурс должна приносить какая-то работа или делать уже построенная мастерская. Ткацкий станок не выберут, пока верёвку негде вить. Пока колония копит, работа, которая приносит недостающее, тянет сильнее. «Недостающее» считается так же, как при закладке: для древесины — цена плюс запас дров на костёр.

**Характеры.** Любимая и нелюбимая работа выбираются из пула работ с `preferable: true`. К ним добавляется до двух черт характера. Навыки растут с практикой и ускоряют работу до 1,7 раза.

**Зайцы.** Пасутся на лугах, предпочитая сочные и подальше от края карты, объедают ягоды, ночью дремлют, убегают от людей и огня. Охотник подкрадывается (так его замечают позже) и стреляет. Промах спугивает зайца. Размножения нет: зайцы приходят из-за края карты, пока луга могут их прокормить, и сами иногда уходят.

**Волки.** Стая из 2–4 волков приходит, когда на карте достаточно зайцев. Всё решает голод. Сытый волк бродит со стаей, но не упустит зайца, который выскочит прямо перед ним. Голодный идёт по следу (по полю течения к добыче, в обход озёр и скал) и загоняет зайца вместе со стаей: заяц быстрее на рывке, волк выносливее. Добыча делится между всеми, кто рядом, поэтому большой стае нужно много зайцев. Чем сильнее голод, тем смелее волк: подходит ближе к поселению, бросается на одинокого поселенца (ночью раньше), а изголодавшись — и на пару людей, и отступает неохотнее. Человек кормит стаю надолго. Оголодавшая стая без добычи может уйти искать другие угодья. Если волку не добраться до цели (вода между ними), он её бросает. Смелые поселенцы отбиваются, остальные бегут к лагерю, а соседи приходят на помощь. Как только рядом с жертвой двое и больше, стая отступает и какое-то время не пробует снова. Волки обходят освещённый лагерь, огонь и группы людей, а раненые или голодные уходят с карты. Пережитое нападение поселенцы вспоминают на совете и голосуют за частокол.

**Охота стаей и туши** (`agents/carcass.js`). Погоня — одна общая охота стаи. Добычу выбирают по выгоде: сытость на каждого, шанс догнать (скорость, рывок, выносливость), путь и риск (крупный зверь лягается). Чем голоднее стая, тем на меньшее она соглашается. В погоне у каждого своя роль: ведущий гонит прямо, загонщики заходят с боков чуть впереди добычи, выдохшийся отстаёт и бежит к месту, где добычу видели последней. Охота заканчивается для всех сразу с одним итогом: добыча взята, ушла из виду, укрылась в поселении, не добраться, стая выдохлась, к жертве пришла помощь, добычу перехватили. Итоги считаются в метриках поведения. В карточке хищника видно, на кого охота, его роль и когда добычу видели в последний раз.

Добыча остаётся на земле тушей. Стая ест её по очереди. Если кормление прервали (люди, огонь, толпа), голодный зверь потом возвращается к знакомой туше. На запах приходят и падальщики (гиены, любой голодный хищник), а ночью — кикимора: ей туша милее склада, и туша от неё быстрее гниёт. Охотник может отбить тушу. Сытые звери уступают, изголодавшиеся бросаются на него. Оставшееся мясо, шкуру и кости он несёт в лагерь, и стрелы для этого не нужны. Через два дня туша начинает гнить. Если от крупного зверя осталось неубранным заметное мясо, в глухую ночь из такой туши может подняться упырь. Через четыре дня туша сгнивает совсем. На карте туша — тёмно-красное пятно, которое уменьшается по мере того, как её едят, а гнилая — зеленоватая.

**Рыбалка.** При генерации мира вода делится на озёра. В озере не меньше 40 клеток живёт рыба: 0,3 рыбы на клетку, но не больше 90. Это конечный запас. Удочки с деревянным крючком (двуручные, работают и со спины) делают в хижине ремесленника, как луки и пращи, так что рыбачить можно с первых дней. Хижина рыбака (16 древесины) строится на берегу ближайшего рыбного озера, если такой участок есть в пределах 24 клеток от лагеря, и только улучшает рыбалку, как охотничий навес охоту: ловят на треть быстрее, каждая рыба даёт в полтора раза больше еды, удочки изнашиваются вдвое медленнее. Рыбак садится на берег озера с рыбой и ловит по одной. Рыбу можно выловить до последней. Тогда озеро «отдыхает»: рыба возвращается сама (логистический рост плюс понемногу заплывающая извне), и ловить там снова начинают, когда озеро заполнится наполовину. На это уходит около двух недель. Рыба — еда (сытнее ягод, портится быстрее), коптильня перерабатывает и её. Сколько рыбы в каждом озере, видно при наведении на воду, на панели склада и на слое ресурсов. Параметры лежат в `world/lakes.js`.

**Снаряжение.** У каждого гуманоида четыре слота: левая рука, правая рука, тело и спина. Одноручная вещь занимает одну руку, двуручная (посох, молот, лук, праща) — обе сразу. На спине носят одну любую вещь: колчан со стрелами, заплечный короб (+2 к переноске) или запасной инструмент, который помогает в работе. Всё сделано из дерева, кости, шкур и кожи.

| Дубина | 1 | удар ×1,3 |

| Топор с костяным клином | 1 | удар ×1,3, рубка ×1,6 |

Вещи изнашиваются: оружие при ударах и выстрелах, инструменты в работе, броня при попаданиях, щит при блоке. Сломанная вещь пропадает. Поселенцы сами выбирают снаряжение со склада, когда проходят через лагерь: смелым важнее оружие и броня, охотникам — лук или праща, любителям рубки — топор, мерзлявым — тёплая одежда. Там же они пополняют колчан стрелами.

**Личность.** У каждого поселенца есть пол, характер, дневник и настроение. События дня становятся мыслями в дневнике: поел после голода, замёрз, выспался в шалаше, с удовольствием взялся за любимое дело или нехотя за нелюбимое, сделал вещь, положил последнее бревно, подстрелил зайца, бежал от пожара, на него напали волки, погиб товарищ, на совете его поддержали или нет. У каждой мысли есть вес, и со временем она остывает. Из свежих мыслей и неутолённых потребностей складывается настроение, которое на ±10% меняет скорость работы. Щелчок по поселенцу открывает под картой карточку: что он делает и где, что у него на душе, характер, самочувствие, чего он хочет (поесть, оружие, тёплую одежду, какую постройку), снаряжение, навыки и дневник по дням. Новая мысль — это запись в `data/thoughts.js` и вызов `think(w, agent, id)` там, где происходит событие.

**Журнал.** У каждой записи есть рубрика и уровень. Красный (тревога) — налёты, нападения, смерти, сгоревшие постройки. Жёлтый (важное) — стройка, новые поселенцы, решения совета. Зелёный (прочее) — ремесло, звери, погода. Над журналом есть переключатели уровней и рубрик, например можно скрыть ремесло. Фильтр влияет только на отображение и запоминается в браузере. Новая рубрика — это запись в `data/logTopics.js` и её имя в вызове `log`.

**Рост колонии и налёты.** Поселенцы приходят по одному, и чем больше колония, тем дольше ждать следующего: при 8 жителях и меньше — день, при 9 — два дня, при 10 — три, и так далее. Кроме того, нужны запас еды и свободные места: без шалашей лагерь вмещает 8 человек. Если срок подошёл, а прийти некуда, панель показывает причину ожидания. Сила налёта задаётся угрозой (`settlement/threat.js`). Угроза растёт со временем и с каждым прошедшим налётом, а ещё с тем, насколько колония «обросла жиром»: числом жителей, вооружённых и общей бронёй. О колонии налётчики знают по слухам: по ежедневному отчёту колонии, поэтому угроза меняется раз в день. Враждебные земли лежат в 6 днях пути при редких набегах и в 3 днях при частых; примерно раз в половину этого срока враги решают, идти ли в набег, и выходят с вероятностью 60% (`chance` в `RAIDS`, `data/presets.js`); если не вышли, в журнале появляется запись о разведчиках, а у колонии есть время оправиться. Это временная механика: позже набеги будет определять карта мира. Кнопка «Набег» вызывает банду сразу, без жребия. От угрозы зависят размер банды (от 2 до 16), снаряжение, здоровье и меткость налётчиков, а каждый налёт немного приближает следующий. Колония, которая перестала расти, к третьей неделе встречает банды по 10 человек и больше. Ожидание поселенца, угроза, размер следующей банды, время до неё и соседи с расстоянием видны на вкладке «Мир».

**Скорость и производительность.** Скорости 1×, 2×, 4× и 8×; при 1× идёт 20 тиков в секунду. Панель «Расчёт за тик» показывает фактическую скорость рядом с выбранной: если компьютер не успевает, цифры разойдутся. Поля навигации больше не пересчитываются по кругу без нужды. Поле, помеченное изменённым, пересчитывается не чаще раза в 24 тика, чистое — раз в 600 тиков, а во время пожара раз в 24, потому что огонь и дым меняют цену пути. Поля, которые следят за движущимися целями (дичь, огонь), обновляются чаще. На средней карте тик стоит около 0,8 мс вместо 3,2 мс, поэтому 8× идёт без потерь.

**Конец игры.** Если в поселении никого не осталось или остался один человек, а лагерь в руках налётчиков или только что разграблен, игра останавливается и показывает летопись поселения: сколько оно продержалось и сколько людей через него прошло, что построили и сделали, сколько налётов пережили. Дальше идут номинации («Опора поселения», лучший охотник, лесоруб, собиратель, каменотёс, мастер, строитель, защитник, долгожитель, живучий, душа компании, вечно недовольный), интересные факты (первая потеря, самый большой налёт, любимая постройка совета, что чаще мастерили, кто держался последним) и список всех, кто здесь жил, с их судьбой и делами. Кнопка возвращает в главное меню. Счётчики для летописи собирает `settlement/chronicle.js`, итог строит чистая функция `settlement/summary.js`.

**Расы и SPECIAL.** У каждого разумного существа и у каждого чудовища семь характеристик: Сила, Восприятие, Выносливость, Харизма, Интеллект, Ловкость, Удача. Шкала открыта сверху: человек живёт в 1–10, крепкие расы доходят до 15, чудовища могут идти дальше. 5 — человеческая норма, при ней все эффекты нейтральны. Вид задаёт жёсткие пределы, народ сдвигает их, особь бросает свои значения внутри (середина выпадает чаще краёв). Сила даёт урон в ближнем бою (огр с 14 бьёт примерно в 2,3 раза сильнее человека), Выносливость — здоровье и стойкость к холоду, Ловкость — скорость шага и удара, Восприятие — меткость и как рано замечен враг, Интеллект — как быстро растут навыки, Удача — шанс, что удар пройдёт мимо, Харизма — как к существу относятся соседи. Состязания считаются через отношение a / (a + b), чтобы одна формула годилась и для двух гоблинов, и для отряда против дракона.

Расы: люди, полурослики, великаны (2,5 м), лесные и тёмные эльфы, гномы (горные и глубинные), зеленокожие (орки, гоблины, огры, тролли — лесные, болотные, ледяные), гноллы. У рас своя физиология: эльфам хватает четырёх часов транса, гномов брага и кормит, и бодрит (без неё по утрам они хмурятся и работают медленнее), великаны и огры едят за троих-четверых, у орков и троллей быстро затягиваются раны, а у тролля — только пока рядом нет огня. Карточка поселенца показывает расу, характеристики с пределами расы во всплывающей подсказке, врождённые черты, мировоззрение, ценности и отношения к соседям.

**Мировоззрение и соседство.** Мировоззрение — это две оси (порядок ↔ вольница, милосердие ↔ жестокость, от −3 до +3) и две-три ценности из девяти. Мнение одного о другом складывается из старой памяти народов (`data/relations.js`, таблица несимметрична), общих и враждующих ценностей, пропасти в милосердии или порядке, харизмы другого и личных обид. Раз в день каждый записывает в дневник, кого не выносит и с кем ему хорошо. Двое, которые друг друга не любят, могут сцепиться, если окажутся рядом: оба теряют настроение, обида растёт. При опасности (налётчики на подходе, пожар, зверь рядом) ссору откладывают. Мнение состоит из двух частей: происхождение, ценности и мировоззрение задают исходное отношение и не меняются, а личный опыт (`agent.grudge`, от −4 до +4) меняется от того, что было между двумя: ссоры, совместная работа, помощь, общий бой. Обиды тают на 4% в день, добрые воспоминания — на 1,5%. В карточке у отношений с заметным личным опытом есть пометка «многое вместе» или «старые обиды».

**Совместные действия** (`settlement/together.js`). Когда в лесу бродят звери, охотящиеся на людей, или нечисть (риск считается по их силе против силы среднего поселенца, ночью выше), кто-нибудь идёт рядом с одиноким сборщиком или охотником: держится вплотную и встречает того, кто на него кинется. Вдвоём человек и как добыча хуже: хищники обходят компанию. Чаще идут с теми, к кому хорошо относятся, смелые и вооружённые; с тем, кого не выносят, не идут. Сопровождающих не больше пятой части поселения. Тяжелораненого в лесу идут выручать: перевязывают на месте и ведут к своим. Ненавистного выручит только милосердный. Работа, где трудится друг, манит чуть больше, а где тот, кого не терпят, — чуть меньше; работа бок о бок сближает. Если у лекаря все койки заняты, выздоравливающий уступает свою тому, кому заметно хуже, если не держит на него зла. Бой с налётчиками плечом к плечу сближает всех, кто в нём был, а давние недруги после него забывают обиды. Всё это попадает в дневники и в отношения.

**Переселенцы других рас.** Большинство приходит из Рода Ольхи, но изредка приходят полурослики, гномы, лесные эльфы и великаны. Чем лучше к расе относятся уже живущие в поселении (и она к ним), тем она вероятнее; расу, с которой у колонии вражда хуже −1, не ждут. В человеческий лагерь примерно половина новичков — люди, пятая часть — полурослики, шестая — гномы.

**Банды налётов.** Каждый раз, когда Враждебные земли выпускают банду, жребий выбирает, кто именно идёт: разбойники «Серых волков», орочья ватага с гоблинами (позже и с ограми), гоблинская шайка, гноллы, тёмные эльфы (чаще ночью, при угрозе от 8), огры-людоеды, тролль, мертвецы из курганов (ночью втрое чаще, при угрозе от 10 с некромантом), упыри (только ночью), вампир со свитой (ночью, при угрозе от 20). Размер банды — это бюджет в «людях»: орк стоит двух, гоблин — 0,6, тролль — пяти. Мертвяки медленные и гниют в тепле, стрелы почти не берут костяков, упыри лечатся кровью и уходят с рассветом, простое железо почти не берёт вампира. Убейте некроманта, и его мертвецы разбредутся.

**Отряд налётчиков** (`agents/squad.js`). Банда приходит с общим планом, и журнал сразу говорит, зачем она пришла. Цели бывают такие: **грабёж** (склад); **расправа** с одним поселенцем — с кровником, который убивал их людей, или с самым слабым; **поджог** деревянной постройки; **разведка** (небольшая ранняя банда смотрит на лагерь и уходит). Если разведчики вернулись домой, следующей придёт их банда, раньше обычного и на треть больше. Мертвецы просто идут на всё живое. Цели и их веса у каждой банды свои (`goals` в `data/raids.js`): огры и упыри приходят за людьми, гоблины — за добычей, орки охотно жгут, а чем больше налётчиков убила колония, тем чаще приходят за кровником.

У каждого в отряде есть роль. Вожак — сильнейший, у мертвецов некромант, у разбойников атаман. Передние бойцы встречают защитников. Стрелки бьют издали. Грабители, около 40% банды, идут к складу, пока остальные держат защитников, и отвечают только тому, кто подошёл вплотную. Поджигатели несут факел к стене. Замыкающий прикрывает отход. Противника налётчик держит: на другого он переключается, только если тот намного ближе или прошло время. Так банда не мечется между ближайшими целями. На удар и на врага вплотную отвечают при любом плане.

Боевой дух отряда падает от потерь, от гибели вожака и от перевеса защитников рядом. Ниже порога банда отступает, а замыкающий ещё какое-то время отбивается от погони. Порог у живых банд и боевых зверей разный (`nerve` в `data/raids.js`: тролль и вампир держатся дольше, гоблины бегут раньше). У безвольных мертвецов боевого духа нет: их держит только некромант. Начало и конец каждого визита записываются в журнал с причиной: цель достигнута, отступление из-за потерь или гибели вожака, разгром. В карточке налётчика видны роль, цель отряда, боевой дух и сколько осталось в строю.

**Серебро.** Простое оружие бьёт вампира вполовину, серебро — в два с половиной раза сильнее обычного. Серебряный кинжал отливают в плавильне из двух слитков серебра и кожи, без железа и кузни. В кузне железный меч или копьё можно посеребрить за слиток серебра. Пока колония не встречала вампира, мастерские делают серебро понемногу, только из лишних слитков. После первой встречи (`w.chronicle.silverFoes`) серебряный клинок нужен каждому второму, и на это идёт последний слиток. Торговцы возят серебряные кинжалы и посеребрённые имперские мечи и копья. Колония покупает их до половины жителей, если вампир уже приходил, а до этого — один запасной, если он дешёвый. Серебро никогда не продают как лишнее. Поселенец ценит серебро немного после встречи с вампиром и очень высоко, пока тот на карте, поэтому по тревоге у костра хватает серебряные клинки со склада. Проверка всех банд против обычной колонии: `node tools/races-check.mjs [дней] [сидов]`.

**Биомы и звери.** Регион — смесь биомов: Северная тайга это примерно 60% тайги, 20% болота, по 10% леса и водоёмов, и при броске каждая доля сдвигается до трети. Биомов десять: луга, лиственный лес, тайга, предгорья, высокогорье, болото, курганы, подземье, вулкан, водоёмы. Регионов теперь семь: к прежним пяти добавились Болотистое полесье и Курганная степь. Каждый зверь называет свои биомы и редкость в них: часто (×1,6), обычно (×1), редко (×0,5), очень редко (×0,15). Сколько зверя в регионе — сумма «доля × редкость» по биомам, у каждого вида ещё свой случайный сдвиг; ниже 0,12 зверь здесь не живёт. От этого числа зависит, как часто он приходит. На вкладке «Мир» видно доли биомов и всех, кто здесь живёт; легенда карты показывает только местных зверей. Пока биомы — это статистика: локальная карта по-прежнему рисуется из травы, леса, скал и воды.

**Бестиарий.** К первым восьми зверям (заяц, олень, лиса, кабан, волк, коза, мул, крыса) добавились:
- звери: варг (полуразумный волк-великан, стаи; ходит в набеги с орками), медведь (бьёт только того, кто тронул; зимой спит), рысь (одиночка, засада), лось (как мул, но в лесу; охотники берут его как опасную дичь), гиена (стаи курганной степи; ходит в набеги с гноллами), гигантская жаба (хватает языком с двух клеток);
- чудовища: грифон (уносит коз и мулов, нападает на одиночек), виверна (яд), дрейк (дыхание поджигает траву), гигантский паук (паутина замедляет, яд), каменный червь (почти неубиваемый), летучие мыши-кровопийцы (ночные стаи, уходят на рассвете), саламандра (живёт в жаре, огонь ей не вредит);
- нечисть, постоянные жители: леший (поселенцы в лесу рядом с ним плутают час-два; простое оружие его почти не берёт, толпе он не даётся и растворяется в чаще; смерть ему — огонь), русалка (раз за ночь зовёт одинокого поселенца к воде и топит, если рядом нет своих; устоять помогают Восприятие и Интеллект против её Харизмы; раненая уходит под воду), кикимора (по ночам портит припасы). Убитая нечисть возвращается через 5–8 дней.
У всех зверей есть SPECIAL. У зверя запись вида описывает типичную особь, поэтому характеристики двигают особь относительно сородичей (сильный волк кусает больнее среднего), а заодно сравнивают виды между собой: медведь 14 по силе против человеческих 5. Из зверей добываются новые материалы и реагенты: паучий шёлк, перья грифона, драконья чешуя, яд, медвежья желчь, жабья слизь, огненная железа.

**Тревога.** Когда налётчик может дойти до лагеря за 12 часов своим шагом (`raidAlarm`, `settlement/query.js`), поселенцы бросают работу и собираются у костра, чтобы встретить врага вместе внутри зоны поселения. Быстрая банда поднимает тревогу почти сразу, а медленные мертвецы — только на подходе, поэтому поселение не голодает у костра сутками. Тяжелораненые отходят в зону. Снаряжение налётчиков зависит от дня: первые банды приходят с дубинами и пращами в тряпье, поздние — с копьями, щитами, луками и в коже.

**Ремесло.** В хижине ремесленника делают одежду, оружие, инструменты, колчаны, короба и стрелы. Мастерская сама выбирает, чего колонии сейчас больше всего не хватает: одежды на всех, оружия на всех, лука для любителей охоты, стрел для лучников. Материалы, на которые совет копит, она не трогает. В дубильне шкуры выделывают в кожу. У каждой мастерской один верстак, поэтому за ним работает один мастер. Примерные сроки для обычного мастера: оружие или инструмент — полдня, броня — около дня, колчан или короб — треть дня, шкура или пять стрел — час-два. Кости и шкуры дают зайцы, а также волки, убитые в бою. Убитые налётчики оставляют снаряжение колонии как трофеи.

**Зона поселения.** Вокруг лагеря (8 клеток) и каждой постройки (5 клеток, у сторожевой вышки 11) лежат круги, которые сливаются в одну зону. В ней поселенцы бьют сильнее, частокол защищает их, волки не охотятся и держатся на расстоянии (ночью дальше), а человек внутри зоны не считается одиноким. При нападении поселенцы бегут к ближайшей точке зоны.

**Движение.** К общим целям (лагерь, ягоды, лес, добыча, край карты) существа идут по полям течения. К своей цели (зайцу, волку, налётчику, точке пастбища или маршрута) они идут по прямой, пока путь свободен, а когда мешает вода или скала — по пути A*, который пересчитывается, если цель сместилась. У угла препятствия существо скользит вдоль него. Если цель недостижима или существо долго не сдвигается с места, мозг получает отказ и выбирает другую цель. Для всех способов движения действует одно правило шага (`canStep`, `world/grid.js`): по диагонали можно пройти, только если обе боковые клетки свободны, так что между двумя скалами, сходящимися углом, не протиснется никто. Прямая видимость проверяется по клеткам, которые пересекает отрезок. Отметка «застрял» относится к одной цели и одной серии попыток, а бюджет поиска A* растёт с расстоянием.

**Бой.** Удар проходит, только если цель жива, видна и в досягаемости (`attack`, `agents/combat.js`). Нечисть видна лишь вблизи, а спрятавшаяся не видна вовсе: противник идёт к месту, где видел её в последний раз, и вскоре бросает поиск. Выстрел не проходит сквозь скалу. Голодный хищник идёт по следу зверя, которого он и правда ест, а поле добычи у охотников засевается только той дичью, которую они сейчас возьмут. Яд и паутина действуют на любое существо, а смерть оформляется через общий `kill`.

**Почему он это делает.** Карточка поселенца объясняет его выбор: что он выбрал на последнем раздумье, с какой оценкой и почему («древесина в запасе 18, копим на шалаш»), какой вариант был вторым, куда и каким путём он идёт (по полю к лесу, прямо, в обход, пути нет) и что он последним бросил и почему («охотится» — «дичи не видно»). У зверей карточка показывает путь. Ответ на нападение на себя весит больше любой потребности: никто не спит, пока его грызут. Внутри поселения атакованный не бежит, а принимает бой.

**Груз.** Ноша принадлежит поселенцу, а не работе. Если работа прервана, груз остаётся в руках и сдаётся на склад при первом проходе через лагерь. Голодный поселенец при пустом складе ест только еду из рук; дрова и камень сытостью не становятся. Доставку прерывает только срочное: нападение, враг рядом, крайний голод или рана.

**Слой ресурсов.** Под переключателем слоёв появляются фильтры по ресурсам, которые видны на карте: ягоды, древесина, камень. Их можно включать и выключать по отдельности. Ресурс попадает в фильтр, если в `data/resources.js` у него есть `map` и `mapColor`.

**Пожары и погода.** Влажная земля загорается хуже и сама гасит пламя. Дождь тушит огонь, а большой пожар делает дождь вероятнее.
