# Тёплый Брод

Гильдия приключенцев в живом мире: мир с историей, народами и державами живёт сам, а гильдия в его столице берёт работу, которую мир предлагает, растит людей поколениями и посылает отряды; бои и стоянки — на локальной карте в духе RimWorld. Физические поля на сетке, навигация по полям течения, агенты с потребностями, характерами и вечерним советом у костра. Работает в браузере без зависимостей во время выполнения.

## Запуск

**Windows:** двойной клик по `Forest.bat`. Он поднимает локальный сервер (Node.js, а если его нет — Python) и открывает игру в браузере. Окно сервера держите открытым, пока играете. Если нет ни Node.js, ни Python, `Forest.bat` подскажет, что поставить.

**Другие системы** — из папки проекта:

```bash
npm run serve                # то же, что node tools/serve.mjs: сервер без зависимостей, открывает forest.html
python3 -m http.server 8000  # без Node.js; затем открыть http://localhost:8000/forest.html
```

Сервер нужен, потому что код написан на ES-модулях, а браузер не грузит их со страницы, открытой с диска. Подробнее о запуске, экранах и управлении — [Как играть](docs/GAME.md).

## Что в игре

Главная страница — `forest.html`:

- **Продолжить** — последняя игра с того дня, на котором она сама сохранилась.
- **Новая игра:**
  - **Гильдия** — основная игра: гильдия в столице, люди у дверей, доска договоров мира, дом с комнатами, отряды, семьи и поколения, филиалы, Храм всех богов ([Гильдия](docs/GUILD.md)).
  - **Поход** (полигон) — караван из столицы идёт за короной сам; ночи и бои — на локальной карте ([Кампания](docs/CAMPAIGN.md)).

**Модификации:**
- **Создать землю** — плиты, рельеф, моря, реки и климат без народов; землю можно править рукой и сохранить.
- **Заселение мира** — история на сохранённой земле: народы, логова, бедствия, века летописи ([Карта мира](docs/WORLD.md)).
- **Конструктор существ** — зверь, чудовище или нечисть в одном окне: имя и облик, теги, тело и SPECIAL, список поведений ([Поведение](docs/BEHAVIOUR.md)), повадки, добыча; новый вид — копия существующего под новым id ([Таблицы → Конструктор существ](docs/TABLES.md#конструктор-существ)).
- **Таблицы** — все справочники игры таблицами: смотреть, править для опытов, выгружать в CSV/JSON ([Таблицы](docs/TABLES.md)).

**⚙ Настройки** — оформление карт, надмозг на карте, заставка. **Об игре** — что это за игра.

Время в игре идёт темпом наблюдателя — полмесяца в секунду на карте мира, час за 2,5 секунды на стоянке, — чтобы историю можно было смотреть, а не только дождаться; ускорение и пауза под рукой. Щелчок по городу, логову или войску открывает его карточку: что это, что у него есть, о чём оно думает ([Как играть → Управление](docs/GAME.md#управление)). Поселение на локальной карте описано на странице [Поселение](docs/SETTLEMENT.md): в игре оно живёт внутри похода, на стоянках каравана.

## Проверки

Всё проверяется без браузера, на том же ядре, что и игра:

```bash
npm test                 # ядро, справочники, логика, детерминизм, колония на 2 дня
npm run balance:standard # стандартный балансный прогон
npm run items            # оружие и броня на одной шкале
npm run arena            # бои без графики: оружие, расы, существа
```

Все команды и их ключи — на странице [Проверки](docs/TESTING.md).

## Главное правило

**Контент — это данные, системы — это код.** Всё, что можно перечислить (ресурсы, работы, черты, виды существ, постройки), лежит в справочниках `src/data/`. Системы ищут записи по `id` и не содержат списков. Новое добавляется одной записью в справочник, а не правкой систем.
