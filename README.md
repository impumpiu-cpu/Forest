# Тёплый Брод

Симуляция поселения в духе RimWorld на живой карте мира: мир с историей, народами и державами, поселение на клетке этого мира и поход каравана за короной. Физические поля на сетке, навигация по полям течения, агенты с потребностями, характерами и вечерним советом у костра. Работает в браузере без зависимостей во время выполнения.

## Запуск

**Windows:** двойной клик по `Forest.bat`. Он поднимает локальный сервер (Node.js, а если его нет — Python) и открывает игру в браузере. Окно сервера держите открытым, пока играете. Если нет ни Node.js, ни Python, `Forest.bat` подскажет, что поставить.

**Другие системы** — из папки проекта:

```bash
npm run serve                # то же, что node tools/serve.mjs: сервер без зависимостей, открывает forest.html
python3 -m http.server 8000  # без Node.js; затем открыть http://localhost:8000/forest.html
```

Сервер нужен, потому что код написан на ES-модулях, а браузер не грузит их со страницы, открытой с диска. Подробнее о запуске, экранах и управлении — [Как играть](docs/GAME.md).

## Что в игре

Главная страница — `forest.html`:

- **Создать землю** — плиты, рельеф, моря, реки и климат без народов; землю можно править рукой и сохранить.
- **Заселение мира** — история на сохранённой земле: народы, логова, бедствия, века летописи ([Карта мира](docs/WORLD.md)).
- **Кампания** — караван из столицы живого мира идёт за короной; ночи и бои — на локальной карте ([Кампания](docs/CAMPAIGN.md)).
- **Быстрый старт** — новый эпический мир по сиду и сразу поход.
- **Настройки** — все справочники игры таблицами: смотреть, править для опытов, выгружать в CSV/JSON ([Таблицы](docs/TABLES.md)).

Поселение на локальной карте описано на странице [Поселение](docs/SETTLEMENT.md). Технический полигон (`index.html`) хранит старые экраны для проверок: «Мир», «Карта», «Кампания», «Эпическая кампания»; меню само передаёт им управление там, где своего экрана ещё нет.

## Проверки

Всё проверяется без браузера, на том же ядре, что и игра:

```bash
npm test                 # ядро, справочники, логика, детерминизм, колония на 2 дня
npm run balance:standard # стандартный балансный прогон
npm run items            # оружие и броня на одной шкале
npm run arena            # бои без графики: оружие, расы, существа
```

Все команды и их ключи — на странице [Проверки](docs/TESTING.md).

## Главное правило

**Контент — это данные, системы — это код.** Всё, что можно перечислить (ресурсы, работы, черты, виды существ, постройки), лежит в справочниках `src/data/`. Системы ищут записи по `id` и не содержат списков. Новое добавляется одной записью в справочник, а не правкой систем.
