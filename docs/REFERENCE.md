# Справочник

## Снаряжение

Четыре слота: левая рука, правая рука, тело и спина. «2» — двуручная вещь, занимает обе руки. Подробнее — [Снаряжение](MECHANICS.md#снаряжение) в механиках.

| Вещь | Руки | Что даёт |
|---|---|---|
| Дубина | 1 | удар ×1,3 |
| Копьё с костяным наконечником | 1 | удар ×1,55 |
| Топор с костяным клином | 1 | удар ×1,3, рубка ×1,6 |
| Щит из жердей и шкуры | 1 | блок 32% ударов в ближнем бою |
| Посох | 2 | удар ×1,1, блок 15%, ходьба +5% |
| Деревянный молот | 2 | удар ×1,9, стройка ×1,45, камень ×1,35 |
| Удочка с деревянным крючком | 2 | нужна для рыбалки, ловля ×1,6 |
| Лук | 2 | выстрел ×1,7 на 7 клеток, нужны стрелы в колчане |
| Праща | 2 | выстрел ×0,6 на 4,5 клетки, камни есть везде; с каменоломней ×1,6 |
| Одежда из лубяной ткани | тело | броня 8%, тепло 35% |
| Кожаная куртка | тело | броня 20%, тепло 55% |
| Кожа с костяными пластинами | тело | броня 35%, тепло 45%, ходьба −5% |

## Инструменты из города

Их не делают, а покупают у торговцев. Одни уходят в постройку при закладке (поле `key`), другие работают со склада (`useWith`). Подробнее — [Инструменты из города](MECHANICS.md#инструменты-из-города--ключи-к-технологиям).

| Инструмент | Что открывает или улучшает |
|---|---|
| Продольная пила | козлы для распила: тёс, а с ним избы |
| Купели и тигли | плавка серебристой руды в горне |
| Кузнечные меха | не открывают, а улучшают горн и кузню: топлива на четверть меньше, работа на четверть быстрее, 5% кованых вещей выходят добротными (+1) |
| Наковальня с молотами | походная кузня: мечи, копья, ламеллярные доспехи |
| Резцы и лучковое сверло | верстак резчика: украшения, резные ларцы |
| Железный лемех | работает со склада: с ручным мулом поля родят на треть больше |
