Все команды `package.json`, что проверяет каждый скрипт `tools/` и с какими ключами он запускается. Всё работает без браузера, на том же ядре, что и игра.

## npm test

Цепочка проверок подряд; первая упавшая останавливает остальное. На двухъядерной машине — около пяти минут.

```text
check-layers · atlas-check 2 · atlas-save-check 1 · map-check 3 · seam-check 16 · campaign-check 2 ·
check-data · check-tables · align-check · leaders-check · buildings-check · elves-check · dwarves-check · greenskins-check · humans-check · kinds-check · fight-check ·
conditions-check · ranks-check · potions-check · checks-check · clock-check · kingdom-check · content-check · land-check · settle-check ·
quest-hand-check · audit-check · logic-check · behaviour-check · world-check · determinism 2 · rng-check 3 · smoke 2
```

Строка `ok …` — проверка прошла, `warn …` — предупреждение (тест не падает), `FAIL …` или выход с ошибкой — тест упал.

## Балансный прогон

Стандартный прогон — с ним сравнивают каждое изменение баланса колонии:

```bash
npm run balance:standard
# то же полностью:
node tools/balance.mjs --seeds 10 --days 30 --vary raids=off,rare,often --set predators=many
```

Три варианта набегов при стаях волков, по 10 сидов на 30 дней — 30 игр.

Ключи `tools/balance.mjs`:
- `--seeds N` — сидов на вариант (сиды 1…N), по умолчанию 12; `--seed-base K` — сдвиг сидов;
- `--days N` — длина игры (по умолчанию 30; игра кончается раньше, если поселение пало);
- `--set ключ=значение` — настройка старта для всех игр, повторяется; ключи — из `DEFAULT_CFG` (`data/presets.js`): `size`, `colonists`, `climate`, `raids`, `predators`, `stock`, `wildlife`, `monsters`, `spirits` и другие;
- `--vary ключ=a,b,c` — сравнить варианты, повторяется (варианты перемножаются);
- `--jobs N` — рабочих потоков (по умолчанию все ядра);
- `--out папка` — куда писать (по умолчанию `runs/<дата-время>/`).

Результат: `report.html` (итоги по вариантам, доля выживших по дням, любой показатель по дням — медиана и разброс, причины смертей, скорость расчёта), `runs.csv` (строка на игру), `days.csv` (строка на игровой день каждой игры), `summary.json`. Игра без экрана — `simulate(cfg, {days})` из `src/headless.js`.

## Баланс похода

`npm run campaign:balance -- [ключи]` (`tools/campaign-balance.mjs`) — целые походы от каждой столицы нескольких миров, параллельно.

- `--worlds N` — сколько миров (по умолчанию 4; сиды 777, 790, 803… — как в `campaign-check`); `--seeds 777,790` — свои сиды вместо них;
- `--size small` — размер миров;
- `--mode local|auto` — `local` (по умолчанию): бои и стоянки на локальной карте, как в игре; `auto` — быстро, бой решается сразу;
- `--epic` — эпические миры (три эпохи, квест могил и четвёртого босса); сотворённый мир кладётся в `runs/worlds/<размер>-<сид>-epic.json` и берётся оттуда в следующий раз;
- `--caps N` — столиц на мир не больше N (по умолчанию 8);
- `--set ИМЯ.ключ=значение`, `--vary ИМЯ.ключ=a,b` — числа справочников; массив пишется в скобках: `--vary EPIC.hunt.every=[60,30],[90,50]`. Доступные таблицы: `CAMPAIGN`, `CAMP`, `QUEST`, `BUBBLE`, `MARKET`, `VISIT`, `EPILOGUE`, `TRAIN`, `HERD`, `MINE`, `SMITH`, `EPIC`;
- `--jobs N`, `--out папка` (по умолчанию `runs/campaign-<дата-время>/`).

Печатает по вариантам и народам: долю вернувшихся с короной, годы в пути, сколько из восьми гибнет и от чего, первый месяц без потерь, голодные дни, бои, штурмы, погони, локальные карты — с ✓/✗ против целей (`AIMS`, для эпических миров ещё `EPIC_AIMS` в начале скрипта). Пишет `runs.csv` и `summary.json`.

## Арена и вещи

`npm run items -- [--csv файл] [--strict]` — PL оружия и брони, цены по кривой, вещи, которые хуже другой во всём (✗), то, на что стоит взглянуть (⚠), таблица клейм. Меряет по `data/balance/rules.js`. Подробно — [Баланс вещей](BALANCE.md).

`npm run arena -- [ключи]` — тысячи боёв без графики тем же кодом боя, что в игре, на ровном поле, без бегства. Три части: поединки оружия по тирам; групповые бои рас (сходится ли КС, какое `alpha`); каждое существо против рас (его поправка `ks`). Ключи:

- `--part all|weapons,races,monsters` — какие части (по умолчанию все);
- `--write` — записать подобранное в `data/balance/creatures.js`;
- `--fights 10000`, `--battles 4000`, `--per-creature 250` — объём каждой части;
- `--monsters all|id,id`, `--team 10`, `--horde 40` — кто и сколько на сторону;
- `--tiers 0,1,2`, `--races all|id,id`, `--stats rolled|norm`, `--skill random|0.5`;
- `--armor tier|any|none`, `--shield 0.5`, `--pair 0.3` (одноручное парное приходит со вторым таким же вместо щита), `--quality 0|mix`, `--cross 0.2`;
- `--foes id,id|monsters`, `--foe-share 0.3`, `--distance 8`, `--max-ticks 3000`;
- `--fair` — только вещи (люди, SPECIAL 5, навык 0,5, без межтировых боёв и существ, только `weapons`);
- `--seed arena`, `--jobs N`, `--out папка` (по умолчанию `runs/arena-<дата-время>/`).

Пишет `fights.csv`, `battles.csv`, `summary.json`, `report.html` и печатает короткую сводку. Неизвестный ключ — ошибка.

## Стресс-тест

Сколько стоит тик при разной толпе. Каждый сценарий идёт в своём процессе Node, без миграций и набегов: толпа ровно та, что поставил сценарий.

```bash
npm run stress                                       # быстрый набор
npm run stress:full                                  # сетка: medium…x512 × 8…1000 поселенцев в лагере
npm run stress:check                                 # mixed-100 укладывается в 6 мс на тик
node tools/stress.mjs --only camp-50,mixed-200@huge  # любые сценарии
node tools/stress.mjs --profile mixed-300            # CPU-профиль: какие функции съедают тик
node tools/stress.mjs --ticks 600 --out runs/stress  # длина прогона; таблица ещё и в stress.csv
node tools/stress.mjs --budget 6                     # выход 1, если mixed-100 дольше 6 мс на тик
```

Сценарии — `вид-число[@карта]`: `camp-N` — N поселенцев в одном лагере (худший случай: все друг другу соседи); `mixed-N` — 30% поселенцев в лагере, 55% оленей и зайцев и 15% волков по карте; `herd-N` — 8 поселенцев и N оленей. Карты: `small` 96×72, `medium` 128×96 (по умолчанию), `large` 192×144, `huge` 256×192, `x384` 384×288, `x512` 512×384. По умолчанию 1200 тиков (игровой день).

**Бюджет тика.** Тик при 1× — раз в 50 мс, значит тик вместе с отрисовкой (около 1 мс) должен укладываться в 50 мс при 1×, 25 мс при 2×, 12 мс при 4× и 6 мс при 8×. Колонка «скорость» — самая быстрая скорость, которую тянет сценарий. Опорный сценарий — `mixed-100`: целевой потолок игры, 100 объектов на карте. Меряйте на свободной машине: рядом с балансным прогоном цифры выходят в полтора-два раза хуже.

## Проверка слоёв

`tools/check-layers.mjs` (первая в `npm test`):
- ядро (всё, кроме `src/ui`, `src/render`, `src/app`) не импортирует оболочку и не трогает глобалы браузера (`document`, `window`, `localStorage`, `indexedDB`…);
- код, который работает для каждого существа каждый тик (`agents/brains/`, `agents/behaviours/`, `agents/tasks.js`, `jobRunners.js`, `combat.js`, `movement.js`, `data/jobs.js`), не перебирает `w.agents` целиком — нужен индекс `agents/lookup.js` или `agents/spatial.js`; дешёвый перебор помечается на строке `// scan: почему дёшево`;
- каждый файл `src/` разбирается (`node --check`);
- **числа в логике:** считает дробные числа в файлах логики (`agents`, `atlas`, `campaign`, `settlement`, `world`, `seam`, `nav`, `outside`) и сравнивает с `tools/numbers-baseline.json`. Больше линии — предупреждение (тест не падает): числу место в `src/data/` и таблице. Меньше — линию можно опустить: `node tools/check-layers.mjs --numbers`.

## Проверка справочников

`tools/check-data.mjs` (в `npm test`) проверяет, что ссылки между записями сходятся: ресурсы в ценах и рецептах, строки `data/balance/` у предметов, постройки в `needs`, мастерские у рецептов и работ, значки предметов, мысли у еды и так далее. Ошибка останавливает тест с понятным текстом; предупреждение (`warn`) говорит о записи, которая в игре никогда не появится (вид не живёт ни в одном регионе, ресурс ниоткуда не добывается). Значения таблиц по их схемам проверяет `check-tables.mjs` — [Таблицы](TABLES.md#проверка-таблиц).

## Проверка логики

`tools/logic-check.mjs` (в `npm test`) собирает маленькие сцены на ровной пустой карте, ставит несколько существ руками, запускает один мозг или одно дело и проверяет правило, которое нельзя нарушать. Сцены пронумерованы `T01`…`T143`; список групп — в шапке файла. Среди них:
- движение и бой: хищник не бьёт издалека, никто не срезает угол между скалами, спрятавшуюся нечисть не бьют, яд действует на всех, удар налётчика — нападение;
- груз и дела: несъедобный груз не становится сытостью, груз не мешает ответить на нападение, к занятому верстаку второй не идёт, прерванное дело отдаёт свои резервы;
- отряды налётчиков, туши и охота стаей, совместные действия поселенцев (сопровождение, перевязка, уступленная койка, отложенная ссора);
- SPECIAL и навыки, тиры, качество от мастера, криты и смертельная рана, торговля через переговорщика, трофеи;
- доска колонии: дозор, крик, тревоги, погоня, ночная стража, дикие стада;
- плен: путы, побег, смирение, доносчик, мастера и ученики, бывшие рабы, торговля пленными;
- клеймо кузнеца.

## Полигон поведения

`tools/behaviour-check.mjs` (в `npm test`; `node tools/behaviour-check.mjs B03` — одна сцена) — полигон для поведений ума `tabled` ([Поведение](BEHAVIOUR.md)). В отличие от сцен логики, здесь крутится вся симуляция (`sim.js step`) на ровной малой карте с одним неподвижным поселенцем у костра (чтобы поселение стояло), без прихода из-за края. Сцена ставит зверей руками и утверждает исход за N тиков: заяц бежит от человека и возвращается к траве (`B01`), стадо оленей тревожится от волка (`B02`), голодная стая начинает охоту, берёт добычу и ест тушу (`B03`), сытая стая не гонит дальнего зайца, но берёт ближнего (`B04`), голодная стая в сумерках нападает на одинокого поселенца и отступает от троих (`B05`), огонь и зона поселения отгоняют волка (`B06`), раненый уходит с карты (`B07`), каталог сходится с кодом и видами (`B08`), мул лягает напавшего и несётся на стрелявшего (`B09`), бык лосей заступается за лосиху (`B10`), медведь зимой уходит (`B11`), крыса днём сидит в норе, ночью грызёт, от проснувшегося бежит (`B12`), ручная коза идёт в загон, дремлет, бежит от волка, ручной мул без загона держится у лагеря (`B13`), леший держится леса, водит кругами, бьёт обидчика, от толпы уходит в чащу (`B14`), русалка зовёт одинокого к воде, второй подошедший снимает чары (`B15`), отряд налётчиков идёт на склад, грабит и уходит с добычей (`B16`), караван приходит, охрана бьёт волка на муле, все уходят (`B17`), беглый пленный уходит за край (`B18`), налётчик вяжет упавшего поселенца и уводит его, павший вор освобождает пленного, ушедший за край уводит его (`B19`). Статисты сцены — существа с умом `prop` полигона: стоят на месте, но чары на них действуют. Новое поведение получает свою сцену; перенос мозга на поведения проверяется тем, что старые сцены проходят.

### Полигон дел мира

`tools/world-check.mjs` (в `npm test`; `node tools/world-check.mjs W03` — одна сцена) — то же для ума карты мира (`atlas/actor.js`, [Мир](WORLD.md#нравы-дела-логов-и-держав)). Земля «Заселения мира» (`atlas/settle.js`) без эпох: рука ставит город и логово, поднимает в нём главаря и спрашивает ум с заданным списком дел и заданным броском, что он выберет; исход отряда проверяется вызовом его прибытия. Сцены: главарь гоблинов идёт набегом на город людей, с добычей логово сильнее (`W01`); на орков, которых зеленокожие терпят, не идёт (`W02`); слабого соседа подчиняет в данники, соперника бьёт (`W03`); из сильного логова выводит выводок — данника (`W04`); ум не взвешивает очередь дел, пока отряд в пути, жребий по весам (`W05`); в живой истории отряд главаря несёт id дела из списка его вида (`W06`); каталог сходится с кодом и с хозяевами логов (`W07`); стан без главаря осенью идёт набегом, весной и летом нет, слабый не идёт (`W08`); логово зверей без вожака на города не ходит (`W09`); сильное старое логово весной шлёт выводок, и тот основывает логово (`W10`); дракон спит, летом летит жечь самый богатый город, потом спит снова (`W11`); при вражде и границе люди объявляют войну, эльфы — нет, но войском отвечают (`W12`); в войне ход державы — войско к фронту, ход переходит, второго войска в год нет (`W13`); усталость от войны — мир в красной полосе прежде прочих дел (`W14`); орки с воинами грабят нелюбимый город не чаще `raidsPerYear`, люди набегами не ходят (`W15`); держава выжигает логово, достающее до её города (`W16`); стан гоблинов осенью уводит пленных, те живут при логове и тают (`W17`); орки с воинами уводят пленных, их город растёт, у людей такого дела нет (`W18`); караван, разбивший людей логова, освобождает его пленных (`W19`). Земля делается один раз, сцены — на её копиях: весь полигон — около секунды. Скрытое логово глуши: не выжигают, пока следопыты не найдут (`W16s`). Союз против бедствия: сильные войска берут логово, босс пал от союза, союз распадается (`W20`); слабые разбиты, союз пробует снова (`W21`). Кто нападает — из полей: волки там, где живут, вид логова в его землях — от логова (`W22`); второй вид — одной стороны (банда может вести зверей, звери банду — нет), с боссом никого (`W23`); сколько пришло — по плотности, именные и войска как прежде (`W23b`); звери стана в набеге — только если живут рядом, второй вид земли прибавляет силы (`W24`); следопыты вернее по густым следам и идут к тому, чьи следы гуще (`W25`); налётчики народов — когда враги каравану (`W26`); племя шлёт банду на поселение и без логова рядом (`W27`). Некромант: раса — жребий по плотности × мировоззрению, много эльфов перевесят одного орка (`W28`); башня-насос забирает гниль, поле мертвецов растёт, округа слабо хиреет (`W29`); логово мёртвых в её владениях — данник, дань идёт и без главаря (`W30`); скрытая башня раскрывается молвой, когда в ней главарь (`W31`); культисты — каждый боец свой жребий, видов сколько угодно, на полигоне их нет, вдали от башни тоже (`W32`).

## Поведенческие метрики

Что измеряет балансный прогон, задаёт `data/metrics.js`: строка, добавленная туда, сама появляется в CSV, отчёте и выборе показателя. Группы: «Поселение», «Люди», «Запасы», «Природа», «Оборона», «Торговля», «Поведение».

Группу «Поведение» считает `settlement/behaviour.js`: недопустимые состояния (существо в скале, в воде, за картой, груз не сходится — должно быть 0), простой и время в тревоге, смены и остановки дел на человека в день, итоги поручений (доведено, заблокировано, невозможно, прервано), отказы «пути нет», время реакции на нападение и нападения без ответа, исходы визитов налётчиков, охоты стаей и туши, совместные действия, «толпа» (доля работающих на самом людном деле) и «ночь без огня» (ночные тики без дров). В консольной сводке видны простой и недопустимые состояния, остальное — в `runs.csv`, `days.csv` и отчёте.
