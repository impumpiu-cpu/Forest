# Глобальная карта мира

Рабочий документ ветки `World`. Здесь записаны утверждённые решения, решения по сшиву, план этапов и открытые вопросы. Обсуждение вариантов идёт вне репозитория, сюда попадает итог.

## Два полигона

Стартовое меню предлагает два режима:

- **Мир** — полигон глобальной карты: генерация по этапам, летопись сбоку. Код в `src/atlas/`, экран в `src/ui/atlasView.js`.
- **Карта** — поселение на локальной карте, как раньше. Код в `src/world/`, `src/settlement/`.

Режимы развиваются независимо. Когда оба готовы, их сшиваем: место поселения выбирается на карте мира. До сшива ни один режим не импортирует другой.

## Утверждённые решения

| Вопрос | Решение |
|---|---|
| Форма мира | Прямоугольник, по всему краю океан, как в Dwarf Fortress. Широта честная: север и юг различаются |
| Сетка | Квадратная, чтобы сшивать с локальной картой |
| Масштаб | Подбирается экспериментально. Клетка мира — набор вероятностей и параметров для генератора локальной карты, а не геометрия. Км на клетку нужны только внутри мировой симуляции (эрозия, скорость расселения) и задаются одной константой |
| Календарь | Общий с локальной картой: сезон 30 дней, 4 сезона, год 120 дней (`data/atlas.js`) |
| Длина истории | 50–250 лет до высадки, шаг — сезон. Точное число подберём |
| Подземный слой (Z) | Нужен. Решение ещё не принято, ниже рабочий вариант |
| Режимы запуска | Общее меню: «Мир» и «Карта». Два полигона до сшива |
| Детерминизм | Каждый этап генерации мира тянет числа из своего потока (`сид:atlas:этап`), чтобы правка одного этапа не меняла остальные. Проверка: `npm run atlas` |
| Слой ядра | `src/atlas/` — ядро: без DOM и хранилищ браузера, проверяется `check-layers` |
| Широты | Настройка при генерации: «Одно полушарие» (север холодный, юг жаркий) или «Экватор посередине» (холодно у верхнего и нижнего края) |
| Число плит | Настройка при генерации: мало (7), обычно (13), много (22) |
| Материковая кора | Отдельное поле, а не свойство плиты: материковые плиты, размытые и с шумом. Поэтому берег чаще спокойный шельф внутри плиты, а материк может лежать на краю чужой плиты. Край мира — океаническая кора |
| Вид границы | Решает движение пары плит и кора по обе стороны шва. Один и тот же шов — желоб на океанской стороне и вулканическая дуга на материковой. Расхождение материка и океана — спокойный край без особой границы |
| Породы | 8 пород в `data/geology.js`: базальт, андезит, гранит (магматические); гнейс, кристаллический сланец (метаморфические); песчаник, известняк, глинистый сланец (осадочные). Известняк и уголь зависят от палеоклимата: смеси нынешней широты и древней (материки дрейфуют) |
| Вода | Сток по Priority-Flood и дереву стока, эрозия неявным stream power в 4 эпохи, озёра в котловинах, солёные бессточные озёра по балансу притока и испарения, поймы и дельты, золотой песок из бассейна. Породы и руды считаются после эрозии, на окончательном рельефе |
| Биомы | Общий справочник `data/biomes.js` переделан под физическую географию и делится по видам: природные зоны по Кёппену (льды, тундра, тайга, широколиственный лес, лесостепь и луга, степь, жестколистные кустарники, пустыня, саванна, влажный тропический лес), высотные пояса (предгорья ниже границы леса, высокогорье выше неё), интразональные (болото, водоёмы, вулкан) и особые места (курганы — из истории, подземье — из пород). Старые id сохранены, новые биомы добавлены в ареалы зверей по их настоящей экологии; «Курганная степь» теперь стоит на степи |
| Высота в км | Рельеф 0..1 растянут степенью 1,6: большая часть суши низкая, высокие только пики (`heightKm`, высочайший пик 5 км). Размах года в глубине материка у полюсов до ~55° (как в Якутске), у моря ~12° (как в Бергене) |
| Климат | Ветры по поясам трёх ячеек циркуляции, влага переносится ветром и выпадает при подъёме воздуха; дождевая тень получается сама: на подветренной стороне воздух опускается, теплеет и воды не отдаёт. Морские течения пока не учитываются |
| Руды | Потенциал = породы + тектоника (дуги, швы, щиты, вулканы, низины), собранный в рудные районы. Пороги уровней 0 / бедно / есть / богато подобраны так, что на обычном мире железо есть хотя бы бедно на половине суши, уголь — на четверти, редкие руды — на 15–20%, мифрил — на 5%. Доли печатает `npm run atlas` |

## Клетка мира

Клетка мира — это регион для локальной карты (схема уже есть в `data/regions.js`), только не брошенный от сида, а выведенный из полей мира:

- **природа:** доли биомов и пород, уровни руд, `placer`, `goldVein`, `magma`, флора, плотности зверей и монстров;
- **рельеф для генератора:** средняя высота и разброс, влажность, плодородие;
- **связи с соседями:** где на краях клетки входят и выходят реки, дороги, хребты;
- **люди и угрозы:** расстояния по дорогам до городов каждого народа и до логов. Из них считаются частоты караванов, набегов и переселенцев (`neighbours.dist`, `road`).

## Этапы генерации

Порядок, к которому идём. Отмечено, что уже есть в коде (`src/atlas/stages.js`).

1. **Плиты.** *Есть.* Зёрна растут по шероховатому полю цены, поэтому границы извилистые. У каждой плиты скорость и возраст. Материковые плиты — ближе к середине мира, по площади чуть больше доли суши. Из них строится поле материковой коры.
2. **Границы плит → рельеф.** *Есть.* Столкновение — хребты по обе стороны шва; материк над океаном — береговой хребет и вулканическая дуга; океан под соседом — желоб; океан над океаном — островная дуга; материк расходится — рифт с плечами; океан расходится — срединный хребет; сдвиг — разломы. Горячие точки: живой вулкан и цепь потухших по направлению движения плиты. Щиты (кратоны) — старые спокойные середины материков.
3. **Рельеф.** *Есть.* Дно 0,2, материк 0,55, шельф между ними + поднятие + пологие волны + мелкие неровности; на поднятом рельеф изрезаннее.
4. **Уровень моря.** *Есть.* Океан — вода ниже уровня моря, связанная с краем мира; котловины ниже уровня моря внутри материка — суша, они заполняются озёрами. Уровень подбирается под долю суши; если котловина вливается в море через пролив, доля прыгает, и берётся ближайшая сторона прыжка (промах до нескольких процентов).
5. **Породы.** *Есть.* См. решения выше.
6. **Руды.** *Есть.* Медь и олово, серебро, золото — у дуг и в швах; железо — в осадочных и щитах; уголь — в глинистом сланце низин; самоцветы — в метаморфических; мифрил — у потухших вулканов и в щитах; магма — только у живых вулканов. Россыпное золото (`placer`) появится вместе с реками: ниже по течению от рудного золота.
7. **Температура.** *Есть.* Средняя за год: от широты и высоты (−6,5° на км). В глубине материка в тропиках чуть жарче, ближе к полюсам холоднее, чем у берега. Размах года (`trange`) мал у экватора и у моря, велик в глубине материка у полюсов — пригодится сезонам локальной карты.
8. **Ветры.** *Есть.* Пояса трёх ячеек циркуляции (`data/climate.js WIND_BELTS`): у экватора затишье, до 30° пассаты к экватору, у 30° конские широты, 30–60° западные ветры, у 60° полярный фронт, дальше полярные восточные. Медленные вихри изгибают поток, над горами ветер слабее. При экваторе посередине пояса зеркальны в обоих полушариях.
9. **Осадки.** *Есть.* Влага на сетке вдвое крупнее мира: над морем воздух набирает воду (тёплое море даёт больше), ветер переносит её (полулагранжев перенос, как дым на локальной карте), вихри немного перемешивают во все стороны. Дождь идёт из любой влаги понемногу, сильнее — в поясах подъёма воздуха и когда ветер взбирается на склон; в поясах опускания воздух воду держит. Суша отдаёт воздуху часть недавнего дождя (растения, мокрая земля), поэтому дожди доходят вглубь материка, а дождевая тень остаётся сухой. Калибровка: у половины суши меньше ~450 мм в год, у двадцатой части больше ~3 м. Проверка (`npm run atlas`): экватор влажнее конских широт, умеренные широты влажнее конских, за хребтом меньше 60% дождя наветренного берега.
10. **Эрозия.** *Есть.* 4 эпохи (`data/hydrology.js EROSION`): Priority-Flood (Barnes) заполняет котловины до порога и даёт каждой клетке сток — одно дерево стока на устье; вода собирается сверху вниз; закон stream power `dz/dt = −K·A^m·S` решается неявно (Braun–Willett), поэтому большие реки врезаются к уровню моря, а водоразделы стоят; склоны оплывают; хребты получают назад долю тектонического поднятия. После эрозии температура и осадки пересчитываются на новом рельефе. Берег при эрозии не уходит под воду.
11. **Реки и озёра.** *Есть.* Сток каждой клетки — сумма осадков всех клеток выше по течению. Ручей, река, большая река — по порогам стока (`RIVERS`). Озеро — вода в заполненной котловине глубже порога. Бессточное солёное озеро — где испарение (растёт с теплом) больше притока; оно оставляет воду себе, ниже по течению её нет. Поймы — плоские днища долин рек с заметным стоком, шире у больших рек; дельты — в устьях рек. Золотой песок (`placer`) — среднее рудное золото всего бассейна выше по течению, оседает там, где река замедляется; только в реках.
12. **Биомы.** *Есть.* Свой справочник `data/biomes.js`, общий с локальной картой, переделан под физическую географию (см. решения). Карта мира выбирает биом по Кёппену (`atlas/biomes.js classify`): самый тёплый и самый холодный месяц (средняя ± половина размаха года), осадки против порога сухости `P_dry = 20·T + 140` мм, высота и крутизна, вода в земле.
13. **Почвы.** *Есть.* По Докучаеву (`data/soils.js`): у каждой природной зоны своя почва, в поймах и дельтах аллювий, в болотах торф, на вулканах вулканическая; порода делает почву богаче (известняк, базальт) или беднее (песчаник, гранит). Плодородие `fert` — для локальной карты.
14. **Леса.** *Есть.* Клеточный автомат роста и пожаров (Дроссель–Швабль): деревья расселяются от соседей до предела биома, молнии поджигают сухие тёплые леса, огонь бежит по сухому лесу, гари зарастают. Сухие края пятнистые, влажные сомкнутые.

## Эры истории

Главный принцип: **массу считаем полями, историю рассказывают сущности.** Плотности зверей, народов, влияния — поля (дёшево, плавное расползание). Города, логова, герои, армии, караваны — сущности с именами, из них пишется летопись.

1. **Дикая эра.** *Есть.* Длина — настройка «Дикая эра»: 25, 40 или 70 лет, шаг — сезон, свой поток случайности истории.
   - **Звери полями** (`atlas/fauna.js`, `data/history.js FAUNA`) на грубой сетке (4×4 клетки мира). Каждый вид с ареалом (`habitat` из `data/species.js`, `data/bestiary.js`) получает ёмкость K от биомов клетки (доля × редкость) и плотность N. Травоядные растут логистически по сезону (весной роды, зимой убыль); хищники едят свой список добычи (`predator.prey`, отклик Холлинга II), сыты — плодятся, голодны — вымирают; хищники весят десятую часть добычи (трофический уровень); все понемногу расходятся к соседям (диффузия); духи (леший, русалка, кикимора) привязаны к местам. Погода года — широкое случайное поле, ускоряет или тормозит рост; худшая зима года, если она лютая, убивает треть зверей округи (где зимы без мороза — это засуха); мор бьёт вид, где он расплодился сверх меры.
   - **Логова** (`atlas/lairs.js`, `data/lairs.js`) — точки с хозяином, силой, возрастом и владениями: гнёзда грифонов и логова виверн на кручах, логова дрейков у вулканов, паучьи гнёзда в густых лесах, норы каменных червей и пещеры кровопийц в известняке и базальте, логова варгов в тундре, тайге и степи. Стоят порознь по владениям; сила растёт, когда в округе хватает добычи; логово держит своих зверей вокруг себя; сильное весной выпускает выводок, и тот основывает новое логово рядом; соперники (грифоны, виверны, дрейки) с соприкасающимися владениями дерутся — победа по силе и SPECIAL хозяев; голодное или побитое логово пустеет; старше 30 лет — «древнее». Часть логов стоит с незапамятных времён.
   - **Летопись** с годом и сезоном: начало эры, мор, лютые зимы и засухи, годы изобилия и тяжёлые годы видов, новые логова, схватки, запустение, древние логова, итог эры. Место события — биом и сторона света («в тайге на северо-востоке»).
2. **Эпоха древних народов.** *Есть.* Длина — настройка «Эпоха древних»: 25, 40 или 60 лет, сразу после дикой эры; звери и логова живут дальше.
   - **Народы** (`data/peoples.js`, `atlas/peoples.js`): эльфы (раса `elf`) и гномы (раса `dwarf`). Каждый народ — поле на той же грубой сетке, что звери: ёмкость K от родных биомов (эльфам — леса, гномам — предгорья и высокогорье плюс богатство руд) и плотность u, которая растёт логистически и расползается фронтом Фишера–КПП, быстрее по своим краям (эльфы — по лесам, гномы — по горам).
   - **Приход:** эльфы пробуждаются в самой древней чаще, гномы выходят из-под гор у самых богатых жил — по два рода, далеко друг от друга, каждый сразу закладывает первый город.
   - **Города** — точки. Где плотность народа высока и рядом нет другого города, народ осматривается и садится на лучшее место (как в Sugarscape): родной биом, вода, берег, плодородие, лес (эльфам), руды и крутизна (гномам). Город растёт к тому, что кормит его округа, сильнее у дороги и в первых городах народа. Размеры: приют, селение, город, столица у эльфов; застава, посёлок, крепость, чертог у гномов. С ростом город строит из своего списка (`build`, id из `data/buildings.js`) то, что позволяет место: рудник и горн — только у руды, резчик — у самоцветов, огород — на плодородной земле, хижина рыбака — у воды, магмовая кузня — у магмы.
   - **Дороги** (`atlas/roads.js`, `data/roads.js`): раз в два года каждый город шлёт движение к трём ближайшим городам народа, с которым нет вражды; путь — A* по цене местности (эльфам лес дешевле, гномам горы), наезженная дорога дешевле, поэтому движение собирается на одних путях и наезживает их в тракты, а заброшенные зарастают. Уровни: тропа, дорога, тракт.
   - **Против дикости:** город бьётся с логовами, чьи владения до него достают; сила города — √жителей, логова — сила × SPECIAL хозяина; проигравшее логово выжжено, проигравший город теряет пятую часть жителей. Люди охотятся: звери вокруг них редеют, хищники и чудовища сильнее.
   - **Первая встреча** народов — когда их земли соприкоснулись; тон — из `data/relations.js` (эльфы и гномы помнят старую неприязнь, −2), и дорог между ними нет.
3. **Люди и орки.** Поля влияния народов, конкуренция по Лотке–Вольтерре, контакт на перекрытии; исход (торговля, проникновение, война) — из `data/relations.js` и ценностей. Войны оставляют курганы и руины.
4. **Пауза и высадка.** Выбор клетки, регион и соседи считаются из мира.

## Подземье (рабочий вариант, не утверждён)

- Несколько слоёв вместо непрерывного Z: поверхность, верхние пещеры, глубокие пещеры, магма. Слои в тех же координатах, что поверхность.
- Разреженность: в слое маска открытых клеток; поля и агенты живут только на них. Цена слоя пропорциональна пустотам.
- Неактивный слой живёт статистикой, как граница `outside/`, но вниз. Прибытия идут через порталы (устья пещер, провалы, вскрытая жила). Когда свод пробит, слой генерируется и начинает тикать.
- Навигация иерархическая: своя на каждом слое плюс граф порталов.
- На карте мира подземье — поля: вероятность пещер из пород (карст, лавовые трубки, древние залы), глубина магмы, отдельная сеть подземных дорог гномов и тёмных эльфов.

| Вопрос | Решение |
|---|---|
| Через что общаются | Мир становится провайдером `outside/` вместо `scripted`. Локальная игра не меняется |
| Что передаётся | Клетка мира → объект региона (`data/regions.js`) вместо `rollRegion(seed)` |
| Биомы клетки | `atlas/biomes.js cellBiomes(a, i)` отдаёт доли биомов по клетке и соседям (ближние весомее) — то же поле `biomes`, что в регионе. Выгоревший или поредевший лес частью считается лесостепью; известняк и базальт добавляют подземье (карст, лавовые трубки) |
| Звери клетки | `atlas/fauna.js faunaAt(a, i, вид)` — сколько вида живёт в клетке против того, что прокормят её биомы. Станет `faunaShift` региона вместо случайного разброса |
| Города и дороги | Расстояние до городов каждого народа по дорогам станет `dist` соседей в `data/neighbours.js`, дороги рядом — `road` региона (частота караванов). Посёлок места высадки сможет выйти на ближайший тракт |
| Логова | `atlas/lairs.js lairAt(a, i)` — логово, в чьих владениях клетка. Логова рядом с местом поселения — будущие гости локальной карты и угроза |
| Руды клетки | `atlas/geology.js cellGeology(a, i)` отдаёт уровни руд в терминах региона (`ores`, флаги `goldVein`, `magma`). Это первая часть будущего объекта региона |
| Продолжение рек и рельефа | Предложение: локальная карта строится из окрестности 3×3 клеток мира, края — граничные условия. Не утверждено |

## Открытые вопросы

- Км на клетку и клеток в мире.
- Подземье: утвердить или изменить рабочий вариант.
- Сколько лет истории по умолчанию.
- Генерация в Web Worker: когда этапы станут тяжёлыми. Сейчас весь мир 256×192 — около 0,3 с.
- Постройки городов мира пока берутся из каталога локальной карты. Для больших городов, вероятно, понадобятся новые: рынок, храм, каменные стены, гномьи подземные ходы.
- Тёмные эльфы и глубинные гномы — с подземьем.
- Морские течения (тёплые и холодные берега) и сезонные муссоны — позже, если понадобятся для биомов.
- Пещеры из пород: карст в известняке, лавовые трубки в базальте — вместе с подземьем.

Проверка: эра прошла до конца, численности конечны, звери в своих биомах, логова одного рода не теснят друг друга, летопись пишется.
