# Глобальная карта мира

Рабочий документ ветки `World`. Здесь записаны утверждённые решения, решения по сшиву, план этапов и открытые вопросы. Обсуждение вариантов идёт вне репозитория, сюда попадает итог.

## Два полигона

Стартовое меню предлагает два режима:

- **Мир** — полигон глобальной карты: генерация по этапам, летопись сбоку. Код в `src/atlas/`, экран в `src/ui/atlasView.js`.
- **Карта** — поселение на локальной карте, как раньше. Код в `src/world/`, `src/settlement/`.

Режимы развиваются независимо. Когда оба готовы, их сшиваем: место поселения выбирается на карте мира. До сшива ни один режим не импортирует другой.

## Утверждённые решения

| Вопрос | Решение |
|---|---|
| Форма мира | Прямоугольник, по всему краю океан, как в Dwarf Fortress. Широта честная: север и юг различаются |
| Сетка | Квадратная, чтобы сшивать с локальной картой |
| Масштаб | Подбирается экспериментально. Клетка мира — набор вероятностей и параметров для генератора локальной карты, а не геометрия. Км на клетку нужны только внутри мировой симуляции (эрозия, скорость расселения) и задаются одной константой |
| Календарь | Общий с локальной картой: сезон 30 дней, 4 сезона, год 120 дней (`data/atlas.js`) |
| Длина истории | 50–250 лет до высадки, шаг — сезон. Точное число подберём |
| Подземный слой (Z) | Нужен. Решение ещё не принято, ниже рабочий вариант |
| Режимы запуска | Общее меню: «Мир» и «Карта». Два полигона до сшива |
| Детерминизм | Каждый этап генерации мира тянет числа из своего потока (`сид:atlas:этап`), чтобы правка одного этапа не меняла остальные. Проверка: `npm run atlas` |
| Слой ядра | `src/atlas/` — ядро: без DOM и хранилищ браузера, проверяется `check-layers` |
| Широты | Настройка при генерации: «Одно полушарие» (север холодный, юг жаркий) или «Экватор посередине» (холодно у верхнего и нижнего края) |
| Число плит | Настройка при генерации: мало (7), обычно (13), много (22) |
| Материковая кора | Отдельное поле, а не свойство плиты: материковые плиты, размытые и с шумом. Поэтому берег чаще спокойный шельф внутри плиты, а материк может лежать на краю чужой плиты. Край мира — океаническая кора |
| Вид границы | Решает движение пары плит и кора по обе стороны шва. Один и тот же шов — желоб на океанской стороне и вулканическая дуга на материковой. Расхождение материка и океана — спокойный край без особой границы |
| Породы | 8 пород в `data/geology.js`: базальт, андезит, гранит (магматические); гнейс, кристаллический сланец (метаморфические); песчаник, известняк, глинистый сланец (осадочные). Известняк и уголь зависят от палеоклимата: смеси нынешней широты и древней (материки дрейфуют) |
| Руды | Потенциал = породы + тектоника (дуги, швы, щиты, вулканы, низины), собранный в рудные районы. Пороги уровней 0 / бедно / есть / богато подобраны так, что на обычном мире железо есть хотя бы бедно на половине суши, уголь — на четверти, редкие руды — на 15–20%, мифрил — на 5%. Доли печатает `npm run atlas` |

## Клетка мира

Клетка мира — это регион для локальной карты (схема уже есть в `data/regions.js`), только не брошенный от сида, а выведенный из полей мира:

- **природа:** доли биомов и пород, уровни руд, `placer`, `goldVein`, `magma`, флора, плотности зверей и монстров;
- **рельеф для генератора:** средняя высота и разброс, влажность, плодородие;
- **связи с соседями:** где на краях клетки входят и выходят реки, дороги, хребты;
- **люди и угрозы:** расстояния по дорогам до городов каждого народа и до логов. Из них считаются частоты караванов, набегов и переселенцев (`neighbours.dist`, `road`).

## Этапы генерации

Порядок, к которому идём. Отмечено, что уже есть в коде (`src/atlas/stages.js`).

1. **Плиты.** *Есть.* Зёрна растут по шероховатому полю цены, поэтому границы извилистые. У каждой плиты скорость и возраст. Материковые плиты — ближе к середине мира, по площади чуть больше доли суши. Из них строится поле материковой коры.
2. **Границы плит → рельеф.** *Есть.* Столкновение — хребты по обе стороны шва; материк над океаном — береговой хребет и вулканическая дуга; океан под соседом — желоб; океан над океаном — островная дуга; материк расходится — рифт с плечами; океан расходится — срединный хребет; сдвиг — разломы. Горячие точки: живой вулкан и цепь потухших по направлению движения плиты. Щиты (кратоны) — старые спокойные середины материков.
3. **Рельеф.** *Есть.* Дно 0,2, материк 0,55, шельф между ними + поднятие + пологие волны + мелкие неровности; на поднятом рельеф изрезаннее.
4. **Уровень моря.** *Есть.* Море по выбранной доле суши. Котловины ниже уровня моря внутри материка пока считаются морем; после Priority-Flood станут озёрами или внутренними морями.
5. **Породы.** *Есть.* См. решения выше.
6. **Руды.** *Есть.* Медь и олово, серебро, золото — у дуг и в швах; железо — в осадочных и щитах; уголь — в глинистом сланце низин; самоцветы — в метаморфических; мифрил — у потухших вулканов и в щитах; магма — только у живых вулканов. Россыпное золото (`placer`) появится вместе с реками: ниже по течению от рудного золота.
7. **Климат.** Температура от широты и высоты (−6,5° на км). *Есть, без ветров.* Дальше: пояса ветров, перенос влаги ветром (как `advect` в `world/fields.js`), горные дожди и дождевая тень.
8. **Вода и эрозия.** Priority-Flood (котловины → озёра), сток по 8 направлениям, накопление стока → реки, эрозия по закону stream power `dz/dt = U − K·A^m·S^n` плюс осыпание склонов. Тектоника, климат и эрозия повторяются несколько эпох. Итог: долины, поймы, дельты, россыпное золото ниже коренных жил.
9. **Почвы.** Порода + климат + наносы → плодородие.
10. **Биомы.** По Уиттекеру (температура × осадки), с привязкой к `data/biomes.js`. Нужны пустыня, степь, тундра. `barrows` — след истории, а не природный биом.
11. **Растительность.** Лес растёт клеточным автоматом роста и пожаров.


## Эры истории

Главный принцип: **массу считаем полями, историю рассказывают сущности.** Плотности зверей, народов, влияния — поля (дёшево, плавное расползание). Города, логова, герои, армии, караваны — сущности с именами, из них пишется летопись.

1. **Дикая эра.** Поля хищник–жертва с диффузией; логова монстров как точки с территорией (будущие «точки для логов»).
2. **Эльфы и гномы.** Фронт расселения Фишера–КПП `∂u/∂t = D∇²u + r·u(1−u/K)`; места для городов выбирают племена в духе Sugarscape; города растут по каталогу `data/buildings.js` (вероятно, расширим); дороги — путь наименьшей цены, который усиливается от движения и зарастает без него.
3. **Люди и орки.** Поля влияния народов, конкуренция по Лотке–Вольтерре, контакт на перекрытии; исход (торговля, проникновение, война) — из `data/relations.js` и ценностей. Войны оставляют курганы и руины.
4. **Пауза и высадка.** Выбор клетки, регион и соседи считаются из мира.

## Подземье (рабочий вариант, не утверждён)

- Несколько слоёв вместо непрерывного Z: поверхность, верхние пещеры, глубокие пещеры, магма. Слои в тех же координатах, что поверхность.
- Разреженность: в слое маска открытых клеток; поля и агенты живут только на них. Цена слоя пропорциональна пустотам.
- Неактивный слой живёт статистикой, как граница `outside/`, но вниз. Прибытия идут через порталы (устья пещер, провалы, вскрытая жила). Когда свод пробит, слой генерируется и начинает тикать.
- Навигация иерархическая: своя на каждом слое плюс граф порталов.
- На карте мира подземье — поля: вероятность пещер из пород (карст, лавовые трубки, древние залы), глубина магмы, отдельная сеть подземных дорог гномов и тёмных эльфов.

## Шов: решения по сшиву

Записываются по мере принятия.

| Вопрос | Решение |
|---|---|
| Через что общаются | Мир становится провайдером `outside/` вместо `scripted`. Локальная игра не меняется |
| Что передаётся | Клетка мира → объект региона (`data/regions.js`) вместо `rollRegion(seed)` |
| Руды клетки | `atlas/geology.js cellGeology(a, i)` отдаёт уровни руд в терминах региона (`ores`, флаги `goldVein`, `magma`). Это первая часть будущего объекта региона |
| Продолжение рек и рельефа | Предложение: локальная карта строится из окрестности 3×3 клеток мира, края — граничные условия. Не утверждено |

## Открытые вопросы

- Км на клетку и клеток в мире.
- Подземье: утвердить или изменить рабочий вариант.
- Сколько лет истории по умолчанию.
- Генерация в Web Worker: когда этапы станут тяжёлыми. Сейчас весь мир 256×192 — около 0,3 с.
- Пещеры из пород: карст в известняке, лавовые трубки в базальте — вместе с подземьем.
