# Карта мира

Код — `src/atlas/`, числа — справочники в `src/data/`. Экраны, на которых мир делают и смотрят, описаны в [Как играть](GAME.md).

## Мир в целом

- Мир — прямоугольник с квадратной сеткой, по всему краю океан. Широта честная: север и юг различаются (`atlas/latitude.js`).
- Размеры — `data/atlas.js ATLAS_SIZES`: малый 128×96, средний 256×192, большой 384×288 клеток. Ширины, радиусы и расстояния в справочниках заданы для мира высотой 192 клетки и масштабируются (`scaleOf` в `atlas/tectonics.js`).
- Календарь общий с локальной картой: сезон 30 дней, 4 сезона, год 120 дней (`SEASON_DAYS`, `SEASONS_PER_YEAR`).
- Клетка мира — не кусок геометрии, а набор долей и вероятностей для генератора локальной карты: одна клетка — одна локальная карта.
- `src/atlas/` — ядро: без DOM и хранилищ браузера (`tools/check-layers.mjs`). Экран мира — `ui/atlasView.js` (`MapView`), его используют «Создать землю» (`app/landView.js`), «Заселение мира» (`app/settleView.js`) и экран кампании.
- Главный принцип: **массу считают поля, историю рассказывают сущности.** Плотности зверей, народов, гнили — поля на грубой сетке. Города, логова, главари, войска, бедствия — сущности с именами, из них пишется летопись.

## Настройки и детерминизм

Настройки мира — `a.cfg` (по умолчанию `DEFAULT_ATLAS_CFG` в `data/atlas.js`):

| Ключ | Что | Справочник |
|---|---|---|
| `seed` | сид | — |
| `size` | малый / средний / большой | `ATLAS_SIZES` |
| `land` | доля суши: архипелаг, материк, суша | `ATLAS_LAND` |
| `plates` | число плит: мало, обычно, много | `data/geology.js PLATE_COUNTS` |
| `hemisphere` | «Одно полушарие» (север холодный) или «Экватор посередине» | `HEMISPHERES` |
| `wild`, `elder`, `young` | длина трёх эпох | `data/history.js WILD_YEARS`, `data/peoples.js ELDER_YEARS`, `YOUNG_YEARS` |
| `epic` | эпический мир кампании: эпохи по 75–150 лет, бедствия | `EPIC_YEARS` |
| `free` | «Заселение мира»: эпох нет, историю ведёт рука | `FREE` |
| `shape` | правки руки на земле | `atlas/shape.js` |

**Потоки случайности.** Каждый этап суши тянет числа из своего потока `сид:atlas:<этап>` (`atlas/generate.js runNextStage`), история — из `сид:atlas:history`. Свои потоки и у систем, которые добавлялись поверх истории, чтобы не сдвигать её: держава (`:atlas:kingdom`), главари (`:atlas:leaders`), преемство (`:atlas:succession`), бедствия (`:atlas:calamity`), годы эпического мира (`:atlas:epic`), места силы (`:atlas:seats`), мировоззрение державы (`:align:<id>`). Позиции этих потоков хранятся в мире (`a.kingdomRnd`, `a.leadRnd`, `a.succRnd`, `a.calRnd`).

**Отпечаток.** `atlasHash(a)` берёт все поля клеток, зверей, гниль, логова, города с постройками, отношения, пепелища, угодья, отряды, сеть снабжения, державы, бедствия, артефакт, летопись и правки таблиц, под которыми мир сделан (`a.tables`). Тот же сид и те же настройки дают тот же мир.

**Пошагово.** `runNextStage(a)` делает следующий этап суши, а когда суша готова — следующий сезон истории. Экран зовёт его по кадрам и рисует мир по ходу; `generateAtlas(cfg)` делает всё сразу (проверки, headless).

## Этапы суши

Порядок задан в `atlas/stages.js` (`ATLAS_STAGES`). Каждый этап читает поля прежних, пишет свои и возвращает строку летописи.

1. **Плиты** (`plates`, `atlas/tectonics.js makePlates`). Зёрна плит растут по шероховатому полю цены, поэтому границы извилистые. У плиты скорость, направление, возраст. Материковые плиты — ближе к середине мира, по площади чуть больше доли суши. Материковая кора — отдельное размытое поле `crust`, а не свойство плиты: материк может лежать на краю чужой плиты, берег чаще спокойный шельф. Край мира — океаническая кора.
2. **Границы плит** (`tectonics`). Вид границы решает движение пары плит и кора по обе стороны шва (`data/geology.js BOUNDARIES`): столкновение материков, вулканическая дуга, глубоководный желоб, островная дуга, рифт, срединный хребет, сдвиг. Один шов бывает желобом с океанской стороны и дугой с материковой. Горячие точки дают живой вулкан и цепь потухших по ходу плиты. Щиты (`craton`) — старые спокойные середины материков. Этап пишет поднятие и тектонические факторы: `coll`, `arc`, `basv`, `volc`, `oldv`, `craton`.
3. **Рельеф** (`relief`). Дно плиты, поднятие от границ, пологие волны, мелкие неровности; поднятое изрезаннее.
4. **Уровень моря** (`sea`, `atlas/hydrology.js seaLevel`). Уровень подбирается под долю суши. Океан — вода ниже уровня, связанная с краем мира; котловины ниже уровня внутри материка остаются сушей и позже заполняются озёрами.
5. **Температура** (`temperature`, `atlas/climate.js`). Средняя за год — от широты и высоты (−6,5° на км). Высота в км — `heightKm`: рельеф растянут степенью 1,6, высший пик 5 км (`cfg.peakKm`). Континентальность `cont`: в глубине материка тропики чуть жарче, высокие широты холоднее. Размах года `trange` мал у экватора и моря, велик в глубине материка у полюсов.
6. **Ветры** (`winds`). Пояса трёх ячеек циркуляции (`data/climate.js WIND_BELTS`), медленные вихри изгибают поток, над горами ветер слабее. При экваторе посередине пояса зеркальны.
7. **Осадки** (`rain`). Влага на сетке вдвое крупнее мира: набирается над морем, переносится ветром, выпадает сильнее в поясах подъёма и на наветренных склонах; суша отдаёт часть дождя обратно. Дождевая тень получается сама. Числа — `MOISTURE`.
8. **Эрозия** (`erosion`). `EROSION.epochs` эпох: Priority-Flood заполняет котловины и даёт каждой клетке сток, закон stream power решается неявно, склоны оплывают, хребты получают долю поднятия. Берег под воду не уходит. После эрозии температура и осадки пересчитываются на новом рельефе.
9. **Реки и озёра** (`rivers`). Сток клетки — сумма осадков выше по течению; ручей, река, большая река — по порогам `data/hydrology.js RIVERS`. Озеро — вода в заполненной котловине. Озеро, где испарение больше притока, — солёное и бессточное. Поймы — плоские днища долин заметных рек, дельты — в устьях.
10. **Породы** (`rocks`, `atlas/geology.js`). 8 пород (`data/geology.js ROCKS`) выбираются по обстановке клетки с шумом. Известняк и уголь зависят от палеоклимата: смеси нынешней широты и древней (`paleo`).
11. **Руды** (`ores`). Потенциал каждой руды = породы + тектоника, умноженные на свой шум рудных районов (`ORE_GENESIS`). Уровни 0 / бедно / есть / богато — по порогам `levels`. Руды: железо, уголь, медь и олово, серебро, рудное золото, самоцветы, мифрил, магма (только у живых вулканов). Золотой песок (`placer`, `atlas/hydrology.js placer`) — среднее рудное золото бассейна выше по течению, оседает там, где река замедляется.
12. **Биомы** (`biomes`, `atlas/biomes.js classify`). По Кёппену: тепло самого тёплого и самого холодного месяца, осадки против порога сухости, высота и крутизна, вода в земле. Справочник общий с локальной картой (`data/biomes.js`): природные зоны, высотные пояса (предгорья, высокогорье), интразональные (болото, водоёмы, вулкан). Курганы и подземье карта мира не красит: они появляются только в долях клетки (ниже).
13. **Почвы** (`soils`). По Докучаеву (`data/soils.js`): своя почва у каждой зоны, аллювий в поймах и дельтах, торф в болотах, вулканическая на вулканах; порода делает почву богаче или беднее (`ROCK_FERT`). Плодородие `fert` 0…1.
14. **Леса** (`vegetation`). Клеточный автомат роста и пожаров: деревья расселяются от соседей до предела биома, молнии жгут сухие тёплые леса, гари зарастают. Поле `trees` — лесистость, `burnt` — сколько раз горело.

## Что лежит в клетке мира

Поля клеток — `a.f`, типизированные массивы длиной `w × h`.

| Группа | Поля |
|---|---|
| Тектоника | `plate`, `crust`, `bnd` (вид границы), `bdist`, `uplift`, `coll`, `arc`, `basv`, `volc`, `oldv`, `craton` |
| Рельеф и вода | `elev`, `land`, `ocean`, `flat` (ровность), `down` (куда стекает), `flow` (сток), `lake` (номер озера или −1), `alluvium` |
| Климат | `temp`, `trange`, `windX`, `windY`, `rain` (мм в год), `cont` |
| Недра | `rock`, `paleo`, `ore_<руда>` (потенциал 0…1 для каждой руды, включая `ore_placer`) |
| Жизнь | `biome`, `soil`, `fert`, `trees`, `burnt` |
| История | `road` (наезженность дорог), `sea` (наезженность морских путей), `bridge` (мост или перевоз снимает брод), `barrows` (курганы и могилы), `scourge` (земля, выжженная фуражирами) |

Кроме клеточных полей мир держит списки: `a.plates`, `a.hotspots`, `a.lakes`; поля грубой сетки — звери `a.fauna`, народы `a.peoples`, гниль `a.rot`; сущности — `a.lairs`, `a.towns`, `a.sites`, `a.realms`, `a.rel`, `a.ruins`, `a.parties`, `a.net`, `a.calamities`, `a.alliances`, `a.graves`; летопись `a.chronicle`.

**Доли клетки.** `cellBiomes(a, i)` отдаёт доли биомов по клетке и соседям (ближние весомее). Выгоревший или поредевший лес частью считается лесостепью, известняк и базальт добавляют подземье (карст, лавовые трубки), курганы былых битв — долю «курганов». `cellGeology(a, i)` отдаёт породу и уровни руд в терминах региона локальной карты (`ores`, `placer`, флаги `goldVein`, `magma`). `faunaAt(a, i, вид)` — сколько вида живёт против того, что прокормит земля. `lairAt(a, i)` — логово, в чьих владениях клетка.

## Рука на земле

Экран «Создать землю» делает только сушу — 14 этапов без народов и истории — и даёт руке править **основу генератора, а не результат** (`atlas/shape.js`, правки лежат в `cfg.shape`, пределы — `data/atlas.js SHAPE`):

- *плита*: новое направление и скорость, подъём или опускание целиком;
- *кисть*: поднять или опустить землю мазком трёх размеров;
- *климат*: сдвиг тепла у экватора и у полюсов, множитель осадков.

Каждая правка входит в цепочку на своём этапе (`FROM`): движение плиты — с границ плит, подъём плиты и кисть — с рельефа, климат — с температуры; всё ниже считается заново. Уровень моря ищется по рельефу до руки, поэтому поднятая плита выходит сушей, а не поднимает море. Модель экрана — `atlas/landMaker.js` (`LandMaker`): держит копии земли перед этапами правок и считает с ближайшей. Без правок генератор даёт ту же землю, что и без экрана.

## Часы истории и эпохи

История идёт по сезону за шаг (`atlas/history.js stepHistory`). Порядок дел в сезоне: погода года и мор (весной), лютая зима или засуха (зимой), приход народов в начале эпохи, народы и рост/стройка городов (весной; раз в `ROADS.every` лет — дороги, раз в `SEA.every` — морские пути), хозяйство городов (каждый сезон), звери, логова, главари, держава, бедствия, отряды по дням сезона, итоги года.

**Эпохи** (`data/history.js ERAS`):

| Эпоха | Что происходит |
|---|---|
| Дикая эра | разумных народов нет: звери, логова чудовищ, станы племён, гниль и мёртвые |
| Эпоха древних народов | приходят эльфы и дварфы, растут города, дороги, первые встречи |
| Эпоха молодых народов | приходят люди и зеленокожие: общие земли, торговля, смешанные города, войны и мир |
| Вольная история | только в «Заселении мира»: эпох нет, народы, логова и бедствия вносит рука |

**Длина.** Обычный мир — три настройки, каждая короткая / обычная / долгая (25/40/70 лет для дикой эры, 25/40/60 для двух других); по умолчанию 40 + 40 + 40 = 120 лет. Эпический мир (`cfg.epic`) — каждая эпоха 75–150 лет, годы бросаются один раз из своего потока и хранятся в мире (`a.epicYears`, `epicYears()`). «Заселение мира» (`cfg.free`, `atlas/settle.js`) — один отрезок `free`, который рука продлевает на 5–100 лет (`FREE.runs`); в конце отрезка летопись пишет итог («Прошло 25 лет. Городов 3 → 10…»).

**Лютая зима и засуха.** Худшая погода года, если она лютая, убивает долю зверей округи и жителей её городов — меньше там, где есть амбары, погреба и лекари (`FAUNA.harsh`, `townHarsh`). Где зимы без мороза, это засуха.

Конец каждой эпохи пишется в летопись итогом: сколько держав, городов и жителей у каждого народа, сколько было войн и пепелищ. Кампания продлевает историю за запланированный конец: мир живёт, пока идёт поход ([Кампания](CAMPAIGN.md)).

## Звери

`atlas/fauna.js`, числа — `data/history.js FAUNA`. Звери — поля на грубой сетке (`FAUNA.cell` клеток мира на сторону). Каждый вид с ареалом (`habitat` в `data/species.js`, `data/bestiary.js`) получает ёмкость K по биомам ячейки (доля × редкость `RARITY`) и плотность N.

- Травоядные растут логистически по сезону (весной роды, зимой убыль).
- Хищники едят свой список добычи (`predator.prey`, отклик Холлинга II): сыты — плодятся, голодны — вымирают; весят около десятой части добычи.
- Все понемногу расходятся к соседям. Духи (`resident`: леший, русалка, кикимора, водяной, полуденница) привязаны к местам, N = K.
- Погода года — широкое случайное поле, ускоряет или тормозит рост. Мор бьёт вид, расплодившийся сверх меры.
- Люди охотятся: где живут народы, звери редеют, хищники и чудовища сильнее (`TOWN_LIFE.hunt`).
- Летопись пишет годы изобилия и тяжёлые годы видов, не больше двух в год.
- **Живность логов** (`data/lairs.js LAIR_FIELD`, `atlas/lairs.js lairFolk`). Хозяева логов — чудовища с ареалом (варги, грифоны, виверны, пауки, черви, кровопийцы, дрейки, драконы) и дикие племена (гоблины, огры, гноллы, тролли, великаны: роль `folk`, K — родная земля расы) — такие же поля, как звери; отличие одно: звери логов не строят, а чудовища без логова не плодятся. Логово — источник: каждый сезон добавляет своим `source × сила × K × (1 − d/r)` в пределах владений (не выше `cap × K`); вдали от логов они едят, бродят и тают на `fade` за сезон. Новое логово приносит своих с собой (`pulse`). В мире без логов чудовищ нет — их выливают логова, поставленные при создании мира. Слой «Звери» показывает и племена; слой **«Живность»** — всех хозяев логов разом: в каждой клетке цвет того, кто живёт гуще всего, ярче — гуще (ореолы логов, следы выводков); в подписи клетки — «живность».

## Логова, племена, мёртвые и демоны

`atlas/lairs.js`, справочник `data/lairs.js` (`LAIRS`, `LAIR_LIFE`, `TRIBE_RAID`, `ROT`). Логово — точка с хозяином-видом, силой 0…1, возрастом и владениями (`radius`). Логово держит плотность своего вида вокруг себя не ниже своей силы.

| Род | Логова | Чем живёт |
|---|---|---|
| Чудовища | гнездо грифонов, логово виверны (кручи), логово дрейка (вулкан), паучье гнездо (глухая чаща), нора каменного червя и пещера кровопийц (известняк и базальт), логово варгов (тундра, тайга, степь) | добычей во владениях |
| Дракон | логово дракона у вулкана, одно-два на мир, древнее | ничем: спит и вылетает |
| Племена (`tribe`) | гоблинские норы (верхом на варгах), стан гноллов (с гиенами), логово огров, логова лесных, болотных и ледяных троллей, становище великанов | своей землёй: родные биомы расы (`home` в `data/races.js`) не ниже `TRIBE_HOME`; теснятся там, где селятся народы |
| Мёртвые (`undead`) | курганник (на курганах), гнездо упырей (у пепелищ), башня некроманта, усадьба вампира (в смешанном городе) | гнилью; вампир — жителями своего города |
| Демоны (`fiend`) | разлом у живого вулкана или на шве плит | ничем: стоит, пока его не закроют |

**Жизнь логова** (по сезону): сила растёт, когда сыто, и падает зимой; логово — источник своей живности (см. [Звери](#звери)); ниже `LAIR_LIFE.dies` логово пустеет — это тело логова, оно общее для всех. Что логово **делает**, решает ум субъекта мира по списку дел его вида ([Нравы](#нравы-дела-логов-и-держав), роль `lair`): сильное весной шлёт выводок (`expand`), и тот основывает новое логово рядом; стан, мёртвые и демоны осенью идут набегом (`raid`); дракон летом вылетает (`strike`). Соперники (грифоны, виверны, дрейки) с соприкасающимися владениями дерутся, победа — по силе и SPECIAL хозяев — это система логов, как охота стаи, а не дело. Старше `LAIR_AGE.ancient` лет логово «древнее».

**Расстановка.** Чудовища, дракон и племена ложатся в начале дикой эры на свою землю (`placeLairs`, `wildLairs`), часть — «с незапамятных времён». Мёртвые и разломы приходят через историю (`spawnLairs`, у рода есть `spawn`): с шансом в год, на своей земле, не ближе двух радиусов к логову того же рода.

**Набеги** (дело `raid` роли `lair`, `atlas/deeds/raid.js`; у станов гоблинов, гноллов, огров и у некроманта ещё `captives` — за пленными). Осенью стан племени идёт на ближайший город народа, чью расу его раса не любит (`data/relations.js`); мёртвые и демоны — на любой город; логово зверей без вожака на города не ходит. **Кто идёт** — из полей вокруг логова (`raidBand`, числа `RAID_MIX`): звери стана (`riders`: варги у гоблинов, гиены у гноллов) едут с ним, только если живут рядом, и добавляют `ridersMight`; с вероятностью по плотности к набегу пристаёт второй вид его земли — чудовища другого логова, другое племя, хищник («гоблины на варгах, с ними огры»), добавляя `might × плотность`. Сила набега — сила стана × SPECIAL хозяина × `might` рода × этот состав; против неё — сила города по постройкам. Удача — город теряет жителей и угодье, стан растёт; отбит — стан слабеет. Сильный набег (не слабее `PARTIES.threshold`) идёт отрядом по карте, слабый решается на месте. Каждый набег оставляет у города могилы. Города, в свою очередь, бьются с логовами, чьи владения до них достают (дело державы `clearLair`, числа `TOWN_WAR`): проигравшее логово выжжено.

**Логово из плотности.** Весной там, где хозяева какого-то рода логов живут гуще `birth` от K и в пределах владений нет живого логова, бродячие осели — рождается логово (не больше `births` в год × квадрат масштаба). **Выводок — миграция**: где он оседает, он выливает своих (`brood × K` к тому, что было). **Вид нового логова.** Выводок основывает логово только своего рода. Логово, рождённое плотностью или пришедшее в глушь (`WILD`), — жребий среди родов, чья земля подходит месту, с вероятностью по плотности их хозяев там: гуще живут — вероятнее, но и редкий род может осесть, и глушь сохраняет разнообразие; у пришельцев глуши их род весит на `own` больше. Логово, рождённое в глуши, скрыто.

**Некромант** (`atlas/necro.js`, числа `data/lairs.js NECRO`; логово рода `necromancer` с пометкой `domain`). Башня рождается из гнили сама: весной в каждой клетке, где гниль выше `rotAt` башни, с шансом `births` × насколько выше (не больше `most` в год × квадрат масштаба, не больше `max` башен, две башни — не ближе двух радиусов); стартует с силой `start`. **Кем был некромант** — жребий среди разумных, живущих на месте (народы — поле × удерживаемая земля, племена — их поле), с весом плотность × мировоззрение: `align.base + align.mercy × (5 − милосердие) / 10` — безжалостные вероятнее, но много эльфов перевесят одного орка. Раса записана на башне (`lair.race`) и переходит к её главарю: имя от расы, «некромант-орк». Главарь — как у всех логов: древняя (30 лет) башня с шансом `LEADER.chance` в год.

- **Насос.** Каждый сезон башня забирает `take` гнили в своих владениях (× 1 − d/r): гниль тает, **поле мертвецов** (`dead` на сетке зверей) растёт на `take × raise` (не выше `deadCap`); без хозяина мертвецы распадаются на `deadFade` за сезон. Кормится башня средней гнилью, до которой достаёт (над `feed`). Не воюет — выедает гниль и слабеет; воюет — набеги оставляют могилы, гниль растёт снова.
- **Владения** (`zone[0] + zone[1] × сила` клеток): курганник, гнездо упырей, усадьба вампира, поднявшиеся в них (или оказавшиеся там, когда владения выросли), склоняются перед башней — её данники (дань силой, `atlas/leaders.js`; башне для этого главарь не нужен). На слое «Державы» владения некроманта — тёмная земля со своей каймой там, где нет земли держав.
- **Культ.** Каждый сезон культ берёт живых во владениях: плотность народов и племён × (1 − `recruit.land` × близость), жители городов × (1 − `recruit.town` × близость) — деревни рядом хиреют, но слабо. **Культисты** — банда `cultists` (`data/raids.js`): каждый боец тянется отдельно из пула клетки (`cultPool`: живые по плотности × мировоззрению, мёртвые по полю мертвецов × `dead`), без предела видов — тролль-культист, пара орков, эльф и мертвецы в одном отряде. Приходят в набегах башни («некромант-орк повёл мертвецов и культистов», сила × 1 + `cultMight` × живые вокруг), во владениях и бродят малыми отрядами в округе (до `cult.roam` × владений), на клетке поселения — когда башня в досягаемости. На полигоне без мира культистов нет.
- **Скрытость и защита.** Рождённая в глуши башня скрыта; с главарём она — уже поселение: каждый сезон шанс `reveal`, что молва её раскроет, и без следопытов. Против города, что идёт её выжечь, она стоит × `might` рода × (1 + `guard` × мертвецы вокруг). Главари чужих логов башен не подчиняют.

**Скрытые логова глуши** (`data/lairs.js WILD`, `atlas/lairs.js spawnWild`, дело `scout`). Когда в мире есть народы, каждую весну глушь рождает новые логова — `WILD.perYear` в год на мир высотой 192 клетки (× квадрат масштаба), вид — ниже `max × crowdMax` своих, на его земле, только в глуши — на земле, которую не держит ни одна держава (`realmLand`, та же земля, что на слое «Державы»). Такое логово, как и выводок, осевший в глуши, **скрыто**: оно ест, плодится и ходит в набеги, но держава не может его выжечь (`clearLair` его не видит), пока его не найдут. Находят его: набег на город — отбитый с шансом `raid[0]`, удачный с `raid[1]` («по следам набега нашли…»); город, вставший ближе `settle` клеток; дело державы **«разведать глушь»** (`atlas/deeds/scout.js`, `WILD.scout`: шанс за сезон, ×`raided`, если город державы грабили за последние `recent` лет; следопыты идут к тому скрытому логову в `reach` клетках, чья живность ощущается гуще с поправкой на путь — плотность его хозяев вокруг него, делённая на 1 + расстояние в десятках клеток, — и находят его с `find[0] + find[1] × знание города + find[2] × ступень + find[3] × эта плотность`: чем гуще дичь, тем виднее след); караван похода — зашедший в его владения или подошедший ближе двух его радиусов там, где его хозяева живут не реже `trail`. На карте скрытое логово — пунктирный ромб без кольца владений, в карточке — «скрыто», у найденного — когда и кем найдено. Так в позднюю эпоху опасность держится в глуши и на окраинах: на малом мире за 200 лет «Заселения» к концу живых логов около 60 вместо 30, из них скрытых 7–18.

**Гниль** (`ROT`, `stepRot`). Поле 0…1 на грубой сетке: подпитывается могилами (`f.barrows` — курганы битв, мёртвые сожжённых городов и набегов, 2–5 курганов незапамятных времён), расползается к соседям, гаснет, быстрее в мороз и зной. Крысы с обозами разносят её по дорогам между городами; постройки здоровья её сдерживают. Башня мага и храм павших гасят гниль вокруг города, а башня мага ещё и усиливает город против набегов мёртвых (`wardMage`, `wardTemple`, `wardMight`). На карте — слой **«Гниль»**: шкала от чистой земли до густой по порогам, на которых встаёт нежить (вампир, упыри, курганники, башня некроманта), курганы и могилы — бурым.

**Дракон** (дело `strike`, `atlas/deeds/strike.js`; числа `data/parties.js DRAGON`). Спит несколько лет, потом летом летит к самому богатому городу в досягаемости; если город не отогнал его — жжёт угодья и жителей и летит домой спать. Его логово города могут выжечь обычным боем. Список дракона — `expand`, `strike`; плодится он с `breed` своего логова (0: таблица может включить).

## Главари логов

`atlas/leaders.js`, числа — `data/lairs.js LEADER`, имена и титулы — `data/names.js`.

- **Кто.** Древнее логово любого рода, кроме драконьего, усадьбы вампира и логова босса бедствия, раз в год с шансом `LEADER.chance` поднимает главаря; одновременно в мире не больше `LEADER.max`. Звери получают вожака, полуразумные и разумные — главаря (у разумных — имя своей расы и прозвище), нежить — владыку, демоны — князя.
- **Сила.** Существо своего вида, выросшее за его пределы: + `LEADER.add` к Силе, Выносливости и Ловкости (у босса бедствия больше).
- **Из поля в пешку.** Логово с главарём не шлёт набегов и выводков само. Каждую весну главарь с шансом `LEADER.think` выбирает дело из списка своего вида (`deeds.lair` в строке вида, [Нравы](#нравы-дела-логов-и-держав)) умом субъекта мира (`atlas/actor.js`) и ведёт отряд по карте (вид отряда `leader`, в отряде — `plan`: id дела). Дела главаря (`atlas/deeds/`, веса — `LEADER.plans`):
  - *набег* (`raid`) на ближайший город в досягаемости народа, которого его раса не любит (мёртвые, демоны и звери — любой; вожак зверей ходит на города реже, `beastRaid`); удача кормит логово, когда отряд вернулся, разбитый набег может стоить главарю жизни;
  - *выводок* (`expand`): из сильного логова — дочернее, его данник (`LEADER.expand`);
  - *подчинение* (`subdue`) слабейшего соседа без главаря и господина: данник каждый год отдаёт долю силы господину;
  - *война* (`rival`) на соперника рода (`rivals` логова): побеждённый слабеет или гибнет (`wiped`).
  Выбор записывается на логово (`lair.why` и след последних решений `lair.thoughts`: год, сезон, дело, причина, второй вариант) и виден в карточке логова (щелчок по карте, [Как играть](GAME.md#управление)).
- **Конец.** Стареет и умирает (`LEADER.life` лет); на его месте может подняться новый. Гибнет в разбитом набеге или бою, вместе с логовом, от рук каравана. Данники без господина освобождаются.
- Бедствие может подняться на живом главаре (ниже). Как главарь встречает караван — в [Кампании](CAMPAIGN.md).

## Нравы: дела логов и держав

Что логово, его главарь или держава делает на карте мира, записано в строке вида — как `behaviours` пешки ([Поведение](BEHAVIOUR.md)), только для субъектов мира: `deeds: {lair: [...], realm: [...]}` (`data/deeds.js DEED_WAYS`; таблицы «Монстры и звери» и «Расы», столбцы «Нравы: логово» и «Нравы: держава»; в конструкторе существ — раздел «Нравы на карте мира»). Державы диффузной модели — поля плотности народов, города, торговля — остаются её телом; то, что раньше решалось порогами внутри этих систем (война при `warAt`, набег Зеленокожих по списку `raiders`, город против логова по шансу), теперь решает тот же ум, что водит пешку, и потому мир и поселение перестали быть двумя механиками с разным нравом. Каталог дел — `data/deeds.js` (таблица «Дела мира»): `{id, label, band, party, requires}`; код — `atlas/deeds/<id>.js` с `want(a, actor, ctx) → [[plan, weight, why], …]`, `told` (строка летописи при выходе), `arrive` и `home` для отряда, который несёт дело (`atlas/parties.js BEHAVIOURS`).

Ум субъекта — `atlas/actor.js actorStep(a, actor, role, ctx)`. Роль даёт список, отряд субъекта в пути (`party`) и то, как дело выходит в мир (`setOut`). Роли: **логово** (`atlas/lairs.js lairRole`: думает каждый сезон своим потоком `H.rnd`; дело само шлёт отряд или решается на месте — `act`; логово — много воль и своего отряда не ждёт: набег осенью не мешает выводку весной), **главарь** (`atlas/leaders.js leaderRole`: весной, с шансом `LEADER.think`, своим потоком; один отряд за раз) и **двор державы** (`atlas/court.js`: каждый сезон, потоком истории, список `deeds.realm` расы народа; дела — `makePeace` (красная полоса), `warOn`, `march`, `raidTown`, `captives`, `clearLair`, `scout`, `liberate`; войск своих не ждёт — одно войско на войну держит сам `march`). Один список вида служит логову и главарю — дело знает, кто спрашивает (`ctx.role`): `raid` без главаря ходит только у разумных, мёртвых и демонов, `subdue` и `rival` — только у главаря.

Списки держав по народам (`DEED_WAYS`): Люди — `people` (мир, война, войско, выжигание логов, разведка глуши), Дварфы — `liberators` (то же + освобождение своих из неволи), Зеленокожие — `raiders` (+ набег и набег за пленными), Эльфы — `wardens` (войны не начинают, но отвечают войском и жгут логова). Списки логов: `lair` у всех, `captors` (+ набег за пленными) у гоблинов, гноллов, огров и некроманта, `dragon` (выводок и вылет), `vampire` (только выводок).

**Пленные** (дело `captives`, `atlas/deeds/captives.js`, числа `data/lairs.js CAPTIVE_RAID`) — набег, который берёт людей, а не убивает их. У стана — как осенний набег (сила, досягаемость, отряд или удар на месте), но город теряет `loss` жителей в полон, не в могилы; они живут при логове (`lair.captives` по народам), стан растёт на `feed`; каждую весну пленных остаётся `keep` (съедены, замучены, подняты). У державы Зеленокожих — как набег города с воинами, пленные растят город на `grow` своего числа и считаются державе (`realm.captives`). Опустевшее логово отпускает пленных по домам. Караван, разбивший людей логова в его землях, освобождает его пленных — они идут с ним ([Плен](CAPTIVES.md#пленные-в-походе)). На четырёх мирах за 120 лет — около 18 набегов за пленными на мир, две трети их — у Зеленокожих. Что осталось системами державы: расколы (`atlas/realms.js`), королевство (`atlas/kingdom.js`), союзы против бедствий (`atlas/alliance.js`) — внутренняя жизнь и скрипты эпика; тело отношений (дрейф, торговля, фронт) — `atlas/diplomacy.js stepDiplomacy` раз в год. Что общее с умом пешки: список в порядке выбора, полосы `reflex > red > yellow > routine` — первая, где есть предложения, прерывает остальные, выбор записан на субъект (`why`). Что иное: такт — сезон; в полосе выбирают **жребием по весам**, а не лучшего — логово и двор это много воль, и летопись сохраняет разнообразие; задача субъекта — его отряд: пока он в пути, взвешиваются только верхние две полосы, и выбранное ими дело сначала зовёт отряд домой.

Перенос сделан тик в тик там, где это возможно: порядок обращений к потокам сохранён (предложения в порядке списка, бросок жребия только при двух и более предложениях, бросок силы), и мир без главарей совпал с прежним хэш в хэш на четырёх сидах; главари — статистикой (счёт набегов, подчинений, выводков, войн на тех же сидах тот же в пределах разброса: единственное отличие — прежний главарь бросал жребий и при одном варианте). Державы перенесены с переменой такта — двор думает каждый сезон, а не раз в год: войны стали деятельнее (на четырёх мирах войск 26 → 51, штурмов 20 → 36, войн 29 → 41, набегов Зеленокожих 94 → 74 — набег теперь соперничает с войском и логовом за ход державы), городов к концу истории столько же (53/63/69/54 → 51/64/71/55). Что впереди — в [Отложено](TODO.md). Полигон — `tools/world-check.mjs` ([Проверки](TESTING.md#полигон-дел-мира)).

## Расы и народы

`data/races.js` (расы), `data/peoples.js` (народы, `kin`), `atlas/population.js` (состав города). Три слова, три уровня:

- **Раса** — тело: SPECIAL, здоровье, скорость, удар, взрослость, сроки жизни, плодовитость, пища, множители, врождённое, мировоззрение, ценности, биомы расселения. Таблица «Расы». Одиннадцать разумных рас: человек, полурослик, великан, лесной эльф, тёмный эльф, дварф, орк, гоблин, огр, тролль, гнолл. **Подрас больше нет**: разновидность расы (горный и холмовой дварф, высокий эльф, ледяной тролль) — отдельная раса, если она нужна, добавленная копией строки; что было у прежних подрас и куда делось — `docs/MIGRATION.md`. Логова троллей трёх видов несут свои биомы и имя в строке логова (`data/lairs.js home`, `plural`).
- **Народ** — кто идёт по карте мира и строит города: Эльфы, Дварфы, Люди, Зеленокожие. Народ назван по расе (`race`): её мировоззрение, нравы держав, эталон рождаемости. **Расы народа** (`kin`): какие расы держат его города — у Людей человек, полурослик и великан, у Зеленокожих орк, гоблин, гнолл, тролль и огр, у Эльфов и Дварфов по одной. Вес расы в городе — `base` × (`KIN.any` + «Биомы расселения» расы по биому города): один источник пригодности земли для всех. Первая раса — своя, остальные — меньшая родня.
- **Уклад** — как народ правит своими державами (`data/polities.js`, [Державы и уклады](#державы-и-уклады)).

**Состав города** (`atlas/population.js`). Город держит жителей по расам и трём полосам возраста — дети (до «Взрослый» расы), взрослые, старики (от `TOWN_LIFE.age.oldAt` срока жизни): `t.heads = {раса: [дети, взрослые, старики]}`; `t.pop`, `t.kin` (доли) и `t.age` — суммы, их никто не пишет напрямую (проверка — `npm run demography`). Все перемены жителей идут через операции состава: родились (дети), умерли по полосам, ушли в войско (взрослые), уведены в полон, уехали, пришли поселенцами, осели чужаками — и каждая убыль записана по причине в `t.vital` года («за год» в карточке города и державы). Группа, что идёт между местами — набор войска (`p.group`), поселенцы, переселенцы — той же формы: расы и возрасты уходят как есть и приходят как были. **Чужаки** — расы других народов среди жителей (`strangersOf`): они оседают по торговым путям и переездом ([Демография](#демография)), растят преступность державы, у Дварфов их выживают (`folk.expel`), в смешанных городах селится вампир. Отдельного поля `t.folk` больше нет.

Что раса делает в городе: рождается и умирает по своему телу, работает взрослой (руки — взрослые × `hands` народа), идёт в ядро каравана по долям столицы (`RETINUE.kinds: 'kin'`), открывает постройки и рецепты своей расы долей ([Требования](#требования-построек-и-рецептов): топь-застава троллей, мясной котёл огров, логова варгов, пауков и гиен). Еда, сила и нужды пока одни на народ — это следующий шаг калибровки.

## Народы и города

`atlas/peoples.js`, `atlas/towns.js`, справочники `data/peoples.js` (`WORLD_PEOPLES`, `TIERS`, `CAPITAL`, `TOWN_LIFE`), `data/townBuildings.js`, `data/races.js`.

**Народы мира** — эльфы и дварфы (эпоха древних), люди и зеленокожие (эпоха молодых). Народ — поле на той же грубой сетке, что звери: ёмкость K от родных биомов расы (`home`; дварфам ещё и богатство руд) и плотность u, которая растёт логистически и расползается фронтом Фишера–КПП, быстрее по своим краям (`moves`). Где живут два народа, каждый теряет долю по плотности другого (Лотка–Вольтерра): друзья делят землю, враги выдавливают друг друга (`DIPLOMACY.compete`). Землю держат города: в пределах `TOWN_LIFE.hold.near` шагов расселения народа (`spacing`) от его живого города поле живёт как живёт, дальше `hold.far` — тает на `hold.fade` в год, между — отчасти. Народ, чьи города сожжены или оттеснены, уходит с этой земли за несколько лет, а не красит её вечно.

**Приход** (`arrive`). У каждого народа две группы, далеко друг от друга (`TOWN_LIFE.apart`: от своих — не ближе `own` ширины крупной сетки, от любого стоящего города, чужого народа тоже, — не ближе `others`, пока такая земля есть; нет — лучшая из оставшихся: эльфы и дварфы не высаживаются все в одном углу). Эльфы пробуждаются в самой древней чаще, дварфы выходят у самых богатых жил, люди приплывают к самому удобному берегу, Зеленокожие приходят туда, где от всех городов дальше всего. Каждая группа сразу закладывает первый город и державу. В «Заселении мира» народ высаживает рука (`landBand`): город встаёт на лучшем месте рядом со щелчком.

**Новые города** основывают только поселенцы полного города ([Демография](#демография)). Место — лучшее в округе: родной биом, вода, берег, плодородие, лес, руды, крутизна, по весам `site` народа. Новый город входит в державу того города, откуда пришли поселенцы.

**Рост.** Жители рождаются от жителей. Город растёт к тому, что кормит его земля, но не выше того, сколько вмещает жильё. Землю считают так: плодородие, родной биом расы народа, дорога или гавань, столичный множитель, еда и торговля построек, плюс привоз по сети, минус вывоз. Город сверх предела так же убывает. Формулы и числа — `TOWN_LIFE` и `TOWN_FX`.

**Постройки.** Каталог мира `data/townBuildings.js`: 127 построек в 10 категориях. У каждой — расы (`peoples`), что нужно в державе (`requires`, `requiresAny`: постройки, что стоят в каком-нибудь городе её державы), ступень, место (`needs`, `needsAny` из `PLACE_NEEDS`), предел, потоки ([ниже](#потоки-построек)), металлы, эффекты (еда, ремесло, торговля, оборона, вера, знание, слава, здоровье; жильё — из `house`) и, у 40 из них, двойник на локальной карте (`local`): постройки поселения берут расы отсюда (`races`, `localPeoples`). Как постройки входят в оценки города — `atlas/towns.js` (`townFx`, `room`, `might`, `raidShare`). Город строит одну вещь за раз ([Стройка](#стройка)) — то, что ему нужнее: оценка `Σ нужда × вкус народа × эффект` (`chooseBuilding`, `townNeeds`); нужды — из состояния города (тесно, голодно, рядом логова или недавний набег, стоит на дороге, размер), вкус — `taste` народа. Каждый город строит для себя, а что ему можно, говорит одно требование постройки ([Требования построек и рецептов](#требования-построек-и-рецептов): народ или уклад, расы среди жителей, что стоит в городе или в державе, ступень, размер, место), проверенное одной проверкой (`canBuild`, `realmBuilt`). Полный список построек — в [Справочнике](REFERENCE.md).

Особые действия построек: мост и перевоз снимают цену брода у города (`a.f.bridge`), монетный двор удваивает тепло торговых путей, гавань открывает морские пути, башня мага и храм павших гасят гниль.

**Ступени и столицы** (`TIERS`, `tierOf`). Три ступени, и город зарабатывает их постройками; число жителей — только нижний порог. У каждого народа свои слова: Эльфы — приют / селение / город, Дварфы — застава / посёлок / крепость, Люди — хутор / деревня / город, Зеленокожие — стойбище / становище / твердыня. Город, у которого жителей стало меньше `TIER_FALL` порога ступени, хиреет на ступень ниже. Столица — не ступень, а флаг (`capital`): тронный зал, дворец и монетный двор строит только она, тронный зал — один на державу. С тронным залом столица зовётся своим словом (`CAPITAL`: столица, чертог, столица, ставка).

**Дварфы** (`data/peoples.js` dwarves, `data/races.js` dwarf). Живут в горах (высокогорье 1, вулкан 0,5, предгорья 0,4), тесно и кланами. Шаг городов 8 — самый плотный народ. В любой постройке не для жилья — койки на 5 / 10 / 15 жителей по ступени (`bunks`, `atlas/towns.js townFx`): дварф спит в мастерской под удары молота. Преступность в их державах растёт вчетверо медленнее (`ruinGrow: {crime: 0.25}`, `atlas/kingdom.js`): все друг друга знают, а за преступление не отмыться за четыре века. Поселенцы идут и на чужую землю, если под местом руда не беднее `oreLand` 0,5, и не селятся ближе двух шагов к городам Зеленокожих (`avoid`; `atlas/peoples.js settleSpot`). Подземные ходы, каменная стена (`tierBy`) и зал предков (свой вариант святилища) — с 0-й ступени, кузня големов — с 1-й. Инструмент в ручной мастерской и мастерской ремесленника — из камня вместо брёвен (`workSwaps`, `atlas/economy.js`). **Знание камня** (`stoneLore`, `atlas/economy.js digOf`): серебро, золото и мифрил в пяти клетках от шахты — во всей горе — Дварфы находят и добывают ×2, ×3 и ×4. Стены растут дальше каменных: бронзовая → железная → стальная → мифриловая, каждая на месте прежней, со слитками на содержание. **Переработка** (`recycler`, одна на город): раз в сезон, после закупок, превращает то, что у города сверх запаса, в то, чего не хватает постройкам и основным нуждам жителей, — по цене в золоте 4 к 1, до 400 золотых излишка в год при полных руках (`atlas/treasury.js recycle`).

**Смешанные города.** По торговым путям и переездом в город оседают расы других народов — живые люди из соседних городов, не доли из воздуха ([Расы и народы](#расы-и-народы), до `DIPLOMACY.mingleMax` чужаков). В смешанных городах селится вампир.

## Стройка

`atlas/build.js`, числа — `TOWN_MONEY.build` в `data/townBuildings.js`. Перенесено из ветки Elves на деньги этой ветки. Город строит **одну вещь за раз** — свой проект:

- **Выбор.** Совет города берёт то, что нужнее (`chooseBuilding`: нужды, вкус народа, роль города в державе — [Совет державы](#совет-державы)), из того, за что город может заплатить (`planBuild`: материалы со склада и из связанных городов, работа жителей, сначала из гранта державы). Чего заплатить не может, пропускает, до `tries` раз.
- **Оплата — при закладке.** Деньги и материалы уходят сразу (`doBuild`), угодье занимает свою клетку.
- **Работа.** Строители — `crew` (0,006) жителей — каждый сезон вкладывают свои рабочие дни. Постройке нужно `days` по ступени (60, 180, 480) × (1 + рабочих мест / `jobsPer` (20)) × (1 + жилья / `housePer` (400)) человеко-дней. Готово — постройка встаёт, совет берёт следующую. Большая бригада за сезон может закончить мелочь и начать следующее.
- **Брошенный проект.** Если город больше не может его строить (держава потеряла нужное), проект бросают. Сделанная работа лежит в `t.works`: вернётся город к нему — продолжит с того же места и второй раз платить не будет.

Так город строит со скоростью своих рук: большой — много вещей в год, хутор — одну за несколько лет. Годовой шанс стройки (`TOWN_LIFE.build`) и прибавка за размер (`TOWN_FLOW.build`) убраны. Грант державы оплачивает проект, а не даёт лишних построек. Карточка города — строка «строится»: что, сколько сделано, сколько сезонов ещё. Проверка — `npm run build:check`.

## Демография

`atlas/demography.js`, `atlas/peoples.js` (`sendSettlers`, `foundFrom`), числа — `TOWN_LIFE` и у каждого народа `settlers`, `migrate`, `welcome` в «Народах мира». **Люди — ресурс, как золото или брёвна.** Они рождаются от жителей городов, переходят между городами, уходят в войско, попадают в полон и умирают. Из ничего жители не берутся: извне в мир приходят только первые отряды народа (и те, кого высаживает рука). Перенесено из ветки Elves на экономику этой ветки.

- **Прирост** — раз в год, весной: `growth` × `breed` народа × (1 + `prestige` × слава) × обратная связь державы × нужды × жители × (1 − жители/предел). `breed` — плодовитость народа: эльфы 0,8, дварфы 0,9 (старшие народы растут медленнее), люди 1,3, зеленокожие 1,45 (`bornOf`, проверка — `npm run demography`). Предел — что кормит земля и вмещает жильё, не меньше `minTarget`; в голодный год город доедает заготовки со склада ([Деньги городов](#деньги-городов)). Город сверх предела убывает так же. Ни броска, ни пола: прежние `drift` и `minPop` убраны. Чтобы народы не измельчали без людей из воздуха, `growth` поднят с 0,14 до 0,22.
- **Возраст и смерть** (`lifeYear`, `atlas/population.js`; числа — `TOWN_LIFE.age`; у каждой расы — таблица «Расы»: «Взрослый», «Жизнь от», «Жизнь до», «Плодовитость», «Гибнет в драках ×»). Рождения и смерть — два отдельных потока. Город держит состав по расам и полосам возраста ([Расы и народы](#расы-и-народы)). Сроки: эльфы 1000–1500, дварфы 300–400, люди 60–80; у зеленокожих орки 40–60, гоблины 20–30, гноллы 30–45, тролли 150–250, огры 120–200. Здоровье тянет срок к верхней границе мягко: от + (до − от) × (1 − e^(−здоровье / `health`)). Каждый год полоса расы теряет (1 / срок) × (база + (середина полосы / (срок / 2))^`hazard`), не больше `most`; база — дети, больные, неудачники — от `base[0]` (1) в бедном городе до `base[1]` (0,3) в здоровом: старики умирают первыми, дети — в бедном городе. За год доля детей взрослеет (1 / «Взрослый»), доля взрослых стареет (1 / (старость − взрослость)). Прирост (выше) делится между расами по доле × плодовитости расы против расы народа (гоблин у зеленокожих рождается в 1,33 раза чаще орка, тролль — в 0,4 раза) и состоит из двух потоков, записанных врозь (`t.vital` born / came): рождения — `TOWN_LIFE.age.births` (0,35) прироста, дети взрослых этой расы, только в младшую полосу, не больше `perGrown` (0,08) × плодовитость на взрослого в год; и народ с земли (остальное) — по полосам `arrive` [0; 0,92; 0,08]. Основатели приходят взрослыми. Состав дрейфует (гоблины множатся и гибнут быстро, тролли и огры медленно), а дикие племена земли каждый год возвращают свои расы народа на `KIN.pull` (5%) к тому, что даёт биом — столько же приходит, сколько уходит. Голод и теснота уносят жителей любого возраста.
- **Драки у костра** (`brawl` народа, только зеленокожие): каждый год гибнет доля `crime` × преступность державы + `crowd` × (жители / место − `from`), у каждого вида × «Гибнет в драках» (гоблины 2,5, тролли и огры 0,3). Рабы зеленокожих живут `slaveLife` (1–4) года; у остальных — `TOWN_FLOW.slaves.waste`.
- **Поселенцы** — раз в год, после прироста. Город шлёт `settlers.pop` жителей основать город своей державы, если:
  - он полон (жители от `settle.full` (0,75) предела, вовсю — на `full + span`) или просто велик (вовсю — на (1 + `settle.big`) × `from`);
  - в нём не меньше `settlers.from` жителей, и после ухода останется не меньше `keep`;
  - есть свободное место (`settleSpot`): не ближе `spacing` и не дальше `reach` × `spacing` от него, не ближе `spacing` к любому городу, на земле народа (`foundLand`), достойное (`siteBar`), ближе — лучше (`settle.near`).

  Пороги народов (`from` / `keep`): эльфы 100 / 60, и уходит 20, а не 30 (их медленные города при общем старте дорастали до 150, когда землю вокруг уже заняли), дварфы 150 / 90, люди 130 / 80, зеленокожие 110 / 70. Шаг (`spacing`): дварфы 8, люди 11, зеленокожие 13, эльфы 14.

  Шанс — `settle.chance` × полнота, не чаще раза в `settle.every` (3) года с города, не больше `settle.max` (2) новых городов в год на народ. Поселенцы уносят со склада то, что он может отдать из `settlers.goods`: заготовки — свою еду и первый запас нового города, брёвна или камень, орудия (у зеленокожих — шкуры и оружие).
- **Война** уносит мирных, не только бойцов, и каждая убыль записана ([Расы и народы](#расы-и-народы)): сожжённое угодье губит `DIPLOMACY.warLoss.work` (25–40%) его работников — поле горит с жнецами; осада морит голодом (`ARMY.starve` в день без запаса); штурм уносит `battleLoss` города, из них уведённые в рабство — в рабство, остальные в могилу; набег — `raidLoss`, из них `raidTake` уведены. Войско возвращается домой тем составом, что ушло, за вычетом павших — павшие записаны городу «на войне».
- **Переезд** — каждый сезон. Жители уходят туда, где лучше. Тянут слава города и то, как сыты его базовые нужды (`t.needs.basic`), а впускает свободное место. Доля готовых уехать — `migrate` народа: эльфы и дварфы 0,005, люди 0,02, зеленокожие 0,03. Город сверх своего места отправляет `overflow` излишка. Если за сезон из города собирается меньше `moveLeast` (0,5) человека, никто не едет. Едут внутри своей державы. В город державы-торговки едут, если до него не дальше `moveReach` × `spacing`, а он своего народа или народа, который принимает переселенцев (`welcome`: люди — эльфов, дварфов и зеленокожих; зеленокожие — всех; эльфы и дварфы — никого). Чужбина ценится в `abroad` (0,6) от родного. Чужие оседают своими расами среди жителей, до `DIPLOMACY.mingleMax`. **Смешение по торговле** (`atlas/diplomacy.js mingle`): город на торговых путях с городами других народов принимает `DIPLOMACY.mingle` × `folk.take` народа своих жителей в год — живых людей из тех городов (сколько те могут отдать сверх `minTarget`), поровну по путям, только от народов, которых принимает (`welcome`).
- **Опустевший город.** Где жителей меньше `abandon` (10), город бросают, и они уходят в ближайший город своей державы.
- **Ничто не пропадает и не берётся из ничего:**
  - пленные павшего логова — от старости, от державы, от соперника, от бедствия — уходят каждый в ближайший город своего народа (`freeCaptives`);
  - войско, чей город пал, возвращается в ближайший город своей державы;
  - венец победы стягивает людей в столицу из других городов державы (`drawTo`), а не прибавляет их;
  - полон не забирает больше, чем осталось жителей.

Проба — `npm run people` (городов и жителей у народа, основано поселенцами, опустело, переехало), проверка — `npm run demography`.

## Угодья и сеть снабжения

`atlas/sites.js`, справочник `data/sites.js` (`SITES`, `NET`).

**Угодья.** 18 построек каталога помечены `site`: поля, рощи, загоны, рудники, каменоломни, лесосеки и прочее. Они стоят не в городе, а в своей свободной клетке в радиусе города по ступени (`SITES.radius`), одна постройка на клетку (`a.siteAt`), с тропой к городу. Клетка выбирается по пригодности, ближе к городу и рядом с другими угодьями и дорогами. Набег, битва или дракон сжигают угодье, сожжённый город теряет все; город хочет постройку снова и ставит её через обычный выбор. Пень помнится `SITES.remember` лет.

**Сеть снабжения** (модель плесени). Каждую весну город считает, что кормят его земля и живые угодья. Излишек отдаётся по связям в города с нехваткой; город в один год либо отдаёт, либо берёт. Связи — пары торгующих городов (`tradeLinks`) с проводимостью 0…1: связь, по которой идёт поток, толстеет, без потока — гаснет и рвётся (`NET`). Поток изнашивает дороги. Город, который несколько лет подряд получает заметную долю еды по связям, один раз попадает в летопись: «…живёт привозным хлебом». По сети сейчас идёт только еда.

## Дороги и морские пути

**Дороги** (`atlas/roads.js`, `data/roads.js ROADS`). Раз в `ROADS.every` лет каждый город шлёт движение к ближайшим городам держав, с которыми нет вражды. Путь — A* по цене местности (`cost` по биомам, крутизна, брод); наезженная дорога дешевле, поэтому движение собирается на одних путях, а заброшенные зарастают. Уровни: тропа, дорога, тракт. `roadAccess(a, i)` — насколько клетка на дороге (0…1).

**Морские пути** (`atlas/sea.js`, `SEA`). Город с гаванью шлёт корабли к ближайшим гаваням держав, с которыми торгует (с маяком — дальше). Путь — A* по воде, клетка воды дешевле суши, проложенный путь ещё дешевле; уровни — морская тропа и морской путь. Путь между гаванями — торговый путь держав, как дорога.

## Державы и уклады

`data/polities.js` (уклады), `atlas/polities.js` (одна модель), `tools/polity-check.mjs`. Королевство людей, племенной стан гоблинов, башня некроманта, разлом демонов и волчье логово — **одна модель мирового субъекта, держава**: место (столица или само логово), владения, правитель или его отсутствие, сюзерен или его отсутствие, отношения и дела. Масштаб отличается набором включённых правил, а не второй системой существования. Хранение остаётся прежним — держава народа в `a.realms`, логово в `a.lairs` — а `atlas/polities.js` один способ спросить то же у любого: `profileOf` (уклад), `rulerOf` (правитель-личность), `seatOf`, `holdingsOf`, `lordOf` / `vassalsOf` (данники, без колец — `mayBend`), `polityLabel`. Второй копии субъекта нет.

**Уклад** (`POLITIES`, таблица «Уклады») — профиль: `rule` (совет / вождь / личная власть / стая / одиночка), `title` правителя, `systems` — какие своды правил действуют (двор, указы, казна, города, совет державы; у логов — ничего: логово живёт как логово), `seat` — где живёт правитель, `ruler` — ведёт ли войско (`leads`), шанс погибнуть в разбитом войске (`battle`), при штурме столицы (`storm`) и с пепелищем (`razed`), преемство (`vacancy`: двор назначает / борьба за власть / поднимется новый / держава кончается), раскол при борьбе (`split`), личные каналы (`channels`). Держава народа берёт уклад по `polity` народа (по умолчанию — id народа: humans, elves, dwarves, orcs); логово — первый профиль, чей тест подходит его виду: `tower` (башня, `domain`), `camp` (племя), `rift` (демоны), `manor` (вампир в городе), `barrow` (мёртвые), `dragon`, `den` (прочие звери). Числа профилей — для калибровки, не замер.

## Правители и личности

`atlas/persons.js`, `atlas/succession.js`, `atlas/control.js`. **Личность** — постоянный человек истории: правитель державы, главарь логова, держатель должности двора. Одна запись в `a.persons`, кто бы на неё ни указывал: `lair.leader`, `realm.kingdom.court[должность].person`, отряд в походе (`at: {kind, id}`). У личности тело (раса), имя, возраст (`born`, `dies`), место, дела. **Должность — не тело**: срок должности вышел (`until`) — держатель ушёл с поста и жив; трон заняла новая личность той же расы при столице (`crownRuler`, двор — `COURT.fill` в год). Должность некроманта/призывателя — способность, не раса: некромант-орк — орк.

**Смерть — одно событие** (`personDies`): по возрасту (`stepPersons` весной; у главарей — `LEADER.life`), в бою, где личность была (`partyBeaten`: вождь орды идёт с войском — `ruler.leads`), при штурме столицы, где она была (`townStormed`: по `storm` / `razed` уклада, двор тоже), от руки каравана (`campaign/march.js worldOutcome`: главарь логова или вождь с войском — именной противник сцены, `person`; его судьба — из записи боя: убит, связан — пленник каравана, жив вне трона, бежал или устоял — жив; быстрый режим — своё правило `CAMPAIGN.scene.auto`; мировой отряд теряет павших сцены и тех, кого караван действительно увёл — связанные, которым в караване не нашлось места, уходят, как и главарь), с гибелью логова. Второй раз личность не умирает: сцена, применённая дважды, не меняет мир. От события расходятся следствия, по порядку:

1. **личные каналы** (`control.js`, `ruler.channels`; канал держится способностью личности — `abilities`: necromancy, summoning, — а не титулом): мертвецы некроманта остаются без хозяина — башня больше не поднимает (`stepTower`), её данники вольны (`bend` требует хозяина, `freeVassals`); призыв эльфов — дело локальной карты, на карте мира ничего не держится; големы — кузни и города, древни — рощи, боевые звери — ям: смерть короля их не трогает;
2. **должность** (`succession.js rulerFell`): логово без главаря ждёт нового (`heirAt`, `LEADER.heir`) — или кончается, если уклад `none` (дракон — сам своя держава); трон державы — по укладу: `court` — трон пуст, правит совет (`vacant` должности), двор назначает после `SUCCESSION.mourn` лет; `contest` — орда без вождя: следующей весной сильнейший город ставит своего (`stepSuccession`) или держава раскалывается (`split`, `breakAway`);
3. летопись различает: «умер своей смертью», «пал в бою», «погиб при штурме столицы», «убит караваном», «трон пуст, правит совет», «орда без вождя», «мертвецы остались без хозяина».

**У личности один владелец счёта.** В каждый момент человек считается ровно один раз: в счёте города (`heads`), в войске (`p.group` — набор, как взят), в караване (член с `person`) или отдельно — как личность. Переход передаёт его целиком или оставляет как было. Ушедший с поста возвращается в счёт города только там, где он есть (`backToCrowd`): при столице — сразу; с войском в походе — остаётся личностью с пометкой `crowd` и входит в счёт того города, где сойдёт (`stepOff`, `stranded`, `townGone`), а до того ведётся отдельно; `inCount` ставится только после того, как счёт его принял. Пленник каравана (`memberFate`): снятые путы (`unbound`) — он спутник каравана и при нём, не в логове; в логово он возвращается, лишь покинув караван — отпущенный в конце похода, бежавший; погибший спутником — одна смерть; привезённый пленным в столицу — пленник при ней (`kept`). Именной вождь при войске — вне `men`: его тело на сцене не списывается с войска, его судьба — своё событие. Личность при караване (пленник, спутник) — караванная: весна мира её не старит, караван берёт её по возрасту как участника (`campaign/index.js agePersons`), одна смерть. Войско: все потери — боя (`armyLosses`), дороги, сцены (`sceneLosses`) — только в `men`; домой приходит набор × `men / men0`, павшие — в книгу «на войне», уведённые караваном — «уведено», и сумма сходится с тем, что ушло.

Гибель правителя не равна потере столицы: сожжённая столица переносит трон (`seatFallen`), а личности, что были в ней, идут в новую столицу (`townGone`); правитель в другом городе жив. Потеря столицы не делает город ничьим и не передаёт его убийце: земля меняет хозяина отдельным делом. Карточка державы: уклад, правитель (возраст, в походе, на троне с), трон пуст / орда без вождя, люди по расам, потери за год. Карточка логова: уклад, без хозяина. Сценарии — `npm run polity`.

## Державы и расколы

`atlas/realms.js`. Раса — не народ: народ мира — поле плотности расы и её города, **держава** — столица и города, что к ней тянутся. Все дела (отношения, торговля, войны, набеги Зеленокожих) — между державами. Держава — субъект той же модели, что и логово ([Державы и уклады](#державы-и-уклады)).

- `a.realms = [{id, people, name, capital, founded, color, align, root, seatSince, kingdom, mourn?, contest?}]`.
- **Имя** — от земли столицы (`data/peoples.js EPITHETS`): богатая руда (только у тех, кто живёт рудой), вода, биом; занятое имя в расе не повторяется. На карте держава — оттенок цвета расы, кольцо — столица.
- **Мировоззрение** державы (`align`, компас ±5, `data/values.js`) — рядом с точкой расы, у державы раскола — рядом с точкой старой державы. Каждый год оно смещается: войны ожесточают, торговый мир смягчает, долгое правление одной столицы укрепляет закон, сожжённая столица его расшатывает; и всё тянется назад к точке основания (`ALIGN_DRIFT.realm`).
- **Земля державы** (`realmLand`, числа `data/peoples.js REALM_LAND`; слой карты «Державы»). Каждый живой город держит землю, до которой достаёт по суше: шаг стоит длину × (1 + `steep` × крутизна), вода останавливает, предел — шаг расселения его народа × (`reach` + `tier` × ступень + `capital` у столицы). Где достают двое, землю держит тот, кому она ближе в долях своего предела. Народы (слой «Народы») — где живёт раса; державы — чьи это страны: у одной расы их может быть несколько, и граница между ними видна. Считается для карты, не сохраняется.
- **Раскол снизу** (`SCHISM`, `stepRealms`). Город второй ступени, у которого людей почти как у столицы и который стоит далеко от неё (город с гаванью при столице без гавани считается дальше), несколько лет подряд — претендент («зреет раскол»). Каждый год он откалывается с шансом, который растёт с расстоянием и в войну или после набега на столицу. Новая держава берёт мировоззрение рядом с точкой старой, города делятся по близости к столицам, отношение двух держав — настороженность, иногда сразу война «не поделили власть».
- **Раскол сверху** (`seatFallen`). Сожжённая столица: трон переходит самому славному городу («столица перенесена»), а если второй почти не уступает первому — держава раскалывается надвое. Без городов держава «сгинула».

## Отношения, торговля, войны

`atlas/diplomacy.js`, числа — `data/diplomacy.js DIPLOMACY`, память рас — `data/relations.js`.

- **Отношение** −5…+5 у каждой пары держав, чьи города встали ближе фронта (`DIPLOMACY.front`). Первая встреча пишется в летопись с тоном. Отношение начинается с памяти: худшая из старых памятей их рас друг о друге (у двух держав одной расы — память расы о себе) плюс близость мировоззрений; каждый год тянется к ней. Общая земля двух рас его портит, торговые пути греют (не выше памяти + `tradeCeil`), набеги Зеленокожих портят.
- **Слова**: дружба, мир, настороженность, вражда, война (`states`).
- **Торговля**: только между державами, что не воюют и не враждуют (`trades`). Связанные дорогой или морским путём соседние города двух держав — торговый путь; монетный двор считает путь вдвое.
- **Война** — дело державы (`warOn`, [Нравы](#нравы-дела-логов-и-держав)): при отношении не выше `warAt` и общей границе, если народ войны начинает (эльфы — нет). Державы по очереди собирают войско (`march`) и идут на ближайший город врага ([Отряды](#отряды)); одно войско на войну, не чаще `ARMY.everyYears`. Война изматывает обоих; мир (`makePeace`, красная полоса) — когда отношение поднялось до `peaceAt` или после `longest` лет. Фронт и границу (`rel.border`, `rel.front`) держава читает из тела отношений, которое считается раз в год.
- **Последствия битв**: город теряет жителей; обескровленный город сжигают — остаётся пепелище (`a.ruins`); под стенами ложатся курганы (`f.barrows`), которые дают гниль и долю «курганов» клетке.
- **Набеги** (`raidTown`, у зеленокожих): город с воинами идёт на ближайший город нелюбимой державы, с которой они уже встретились; добыча растит город, отбитый набег стоит дороже; не больше `raidsPerYear` в год на державу.

## Отряды

`atlas/parties.js`, числа — `data/parties.js` (`PARTIES`, `ARMY`, `DRAGON`). Всё, что ходит по карте как сущность, — один объект `a.parties`: набег логова, выводок, войско державы, войско союза, отряд главаря, дракон. Поведение по роду — `BEHAVIOURS[kind] = {day, arrive, stay, home, lost}`, его заполняют системы-хозяева.

- Сезон — тик мира, внутри него отряд ходит 30 дней. Пешие и верховые идут по `findPath` (дороги быстрее, горы и болота медленнее), крылатые летят по прямой. Скорости — `PARTIES.speed`.
- Состояния: `go → arrive → stay → home → gone`. Отряд, который долго не дошёл (`giveUp`), поворачивает назад.
- **Войско.** Собирается в ближайшем к врагу городе — доля его жителей (`ARMY.levy` 0,1 × `levy` народа: у людей каждый десятый, у Зеленокожих — каждый третий) и боевые звери (`beastLevy`: Зеленокожие ведут всех обученных; голова в силе — по своей цене, `beastWorth`: здоровье × удар × `WAR_BEASTS.men`; выжившие возвращаются; обычный скот остаётся дома), сила от числа бойцов, ремесла и обороны города. Идёт на город врага и садится в осаду: каждый день может сгореть угодье, город проедает запас, потом голодает. Штурм — когда войско достаточно сильно, через предельный срок или без припасов. Взятый город грабят, обескровленный сжигают. При мире войско поворачивает домой.
- **Фуражиры.** Вокруг войска в походе и на осаде — поле `a.f.scourge`: угодья там не кормят, дороги не наезживаются; поле гаснет за год.
- Караван кампании — тоже отряд, но мир его не водит ([Кампания](CAMPAIGN.md)).

## Потоки построек

Таблица «Постройки городов» (`data/townBuildings.js`) — единственная истина о постройке мира. Кроме того, кто строит и где, у каждой записаны потоки за год при полной работе:

- **`house`** — сколько жителей вмещает. Место города = `TOWN_FX.room[0]` (120) + Σ `house`. Действует: эффект «жильё» больше не задаётся руками, а выводится из `house` (`fxOf`, `townFx`), так что нужды и вкус народа взвешивают его как раньше.
- **`jobs`** — сколько рук постройка берёт у города; **`heat`** и **`fire`** — заряды топлива в год на тепло жилья (× климат: холодный 1,6, умеренный 1, тёплый 0,4) и на жар работы ([Кухни и топливо](#кухни-и-топливо)); **`any`** — что постройка берёт из набора благ (кузня големов — любые слитки); **`in`**, **`out`** — что тратит и что даёт, в благах `TOWN_GOODS` (еда, сырая еда и заготовки — в человеко-годах; таблица «Блага городов»); **`recipes`**, **`opens`**, **`req`** — рецепты, индикаторы ([Цепочки 6.1](#цепочки-61-индикаторы-рецепты-виды-строк)).
- **`metals`** — металлы, которые кузнецы и рынки державы работают, пока такая постройка стоит в одном из её городов: бронза — горн, железо — кузня, сталь — литейня или магмовая кузня, мифрил — магмовая кузня, серебро — ювелир. Металл, которого не открывает ни одна постройка, работают все.

**Город живёт по потокам** (`atlas/economy.js townEconomy`, правила `TOWN_FLOW`). Раз в сезон, до роста:

- **Постройка — единица мощности.** Числа построек — деревенские (пашня — 30 рук, 110 зерна) и совпадают с локальной картой; большой город ставит их много: единиц одного вида может быть не больше `max` или одной на каждые `per` жителей (`unitsMax`, по пику населения `t.peak`); строит город по одному проекту ([Стройка](#стройка)). Новые единицы угодья расширяют его клетку (`atlas/sites.js`); сожжённое угодье теряет одну единицу, клетка пропадает с последней. Эффекты (`fx`) и содержание державы считаются по видам построек, жильё — по каждому дому.
- **Люди — ресурс.** Рабочие руки — взрослые жители × доля народа (`hands`: эльфы 0,67, дварфы 0,92, люди 0,83, зеленокожие 1; дети и старики не работают). Постройки арендуют свои `jobs` по порядку категорий (еда первой); чему не хватило рук, работает на долю; снесённая постройка отдаёт руки.
- **Рабы** (`t.slaves`): пленные набегов зеленокожих становятся рабами города (а не жителями); постройка сперва берёт рабов — до 80% мест, раб работает на 0,6 вольного, — остальное вольные (мастера и надсмотрщики); рабы едят, как жители, и каждый год 10% из них уходят.
- **Блага.** Что постройки дают (× потоки народа), делится между теми, кто их берёт (с заменами народа), за несколько кругов. Без жёсткого блага (руда для горна, зерно для мельницы) постройка стоит, без мягкого (`soft`: орудия, оружие, броня, мёд, горшки, травы, зелья, брага, роскошь, соль — или столбец «Обходится без» самой постройки: рыбакам волокно на сети, мастерской ремесленника кость и кожа) работает вполсилы. Постройка тратит благо лишь настолько, насколько работает: мастерская, что стоит без кожи, не жжёт дров — остаток идёт на склад. Постройка чужого народа (взятая) работает вполсилы. Топливо жилья × климат (`heatFactor`).
- **Еда и рост.** Город растёт к меньшему из места в домах и прокорма: прокорм = (земля + море) × (1 − гниль + 0,3 × торговля) + еда построек (готовая еда и заготовки; сырое не едят — его варят кухни, а эльфы едят плоды сырыми) / `eat` народа − рабы; плюс привоз по сети, минус вывоз. Эффект «запасы» (бывшая «еда») есть только у амбара, погреба, коптильни, вешал и солеварни: дольше держится осада, меньше уносит мор и лютая зима, дешевле паёк. Кормят постройки своим `out` (пашня — зерном, пристань — рыбой); выбирая стройку, город ценит её по тому, сколько она кормит (`foodNet`).
- **Море** (`atlas/sea.js seaFeed`, `TOWN_FLOW.sea`): вода вокруг города кормит, как земля, если в городе есть рыбаки — хижина рыбака 0,3, пристань 0,5, гавань 0,7 доли от земли. Верфь даёт лодки (`TOWN_FLOW.boats`): рыбаки (хижина, пристань, гавань, речная пристань) ловят до ×1,5 по работе верфи. Пристань — у всех народов; гавань даёт морской промысел и хочет свою пристань в самом городе, маяк — свою пристань или хижину рыбака (поле `here`).
- **Эффекты по работе.** Постройка даёт свои эффекты (оборону, ремесло, славу…) по своей загрузке — руки и сырьё, — не ниже `TOWN_FX.work` (половины): кузня без металла даёт половину обороны. Жильё — всегда целиком. Загрузка сохраняется в городе (`t.work`).
- **Выбор стройки** (`chooseBuilding`, `TOWN_FX.flow`): к нуждам прибавляется нехватка благ (постройка, что даёт недостающее), лишнее благо (постройка, что его берёт: мельница — лишнее зерно; лишняя еда не в счёт — она не хранится, это хлеб города, а не повод строить коптильню), нужда в еде (постройка, что даёт еду; у большого города она есть всегда — `TOWN_FX.needs.food[1]` за ступень, своя пашня); все эти добавки вместе — не больше `flow.cap` (промысел на семь благ не стоит семи промыслов). Блага постройки читаются с заменами её народа (ювелир эльфов берёт дерево, а не металл). Постройка, которой не хватит рук, не строится; та, что берёт жёсткое благо, которого никто в державе не делает, стоит `flow.idle` (жильё — никогда: его не останавливают). Нужда в жилье растёт круче прочих (`needs.housing` 2): город, что упёрся в место, строит дома раньше мастерских.
- Карточка города: руки, рабы, сколько кормят постройки, чего не хватает. Хозяйство (`t.econ`) считается заново каждый сезон и не сохраняется; сохраняются загрузка построек (`t.work`), склад, казна и цены рынка.

Числа подобраны под эльфов (`npm run buildings`: эльфийские города кормятся своими постройками, всё жёсткое, что тратят, сами и делают). У остальных народов цепочки ещё не замкнуты (дварфам мельницы без зерна, святилищам мёд, Людям и Зеленокожим металл и орудия) — до их разбора их города слабее, чем были.

Раньше постройки и металлы открывали технологии держав. Они убраны: кто строит, решает столбец «Расы», когда — «Нужно в державе», а постепенность стройки дадут потоки.

### Цепочки 6.1: индикаторы, рецепты, виды строк

Схема согласована с документом «Карточки построек Forest» (редакция 6.2). Числа — `data/townBuildings.js`; расчёт — `atlas/economy.js`; выбор и стройка — `atlas/towns.js`, `atlas/build.js`.

- **Ресурс и индикатор.** Ресурс — то, что копится, тратится и продаётся. Индикатор — флаг «у города есть»: он горит или нет (`INDICATORS`).
  - Постройка зажигает свои `opens`, пока стоит хотя бы одна такая: поле — «зерно», «лён»; сад — «плоды»; пасека и собиратель — «мёд»; мельница — «мука».
  - Народ города зажигает `people:<народ>`, раса народа, которой в городе не меньше `KIN.least`, — `kin:<раса>`.
  - Склад зажигает `stock:<благо>`: благо есть на складе или сделано в этот сезон — своё или привозное.
  - Индикаторы построек привязаны к городу, торговля их не возит; складские горят и от привоза.
- **Рецепт** (`recipes` постройки) идёт, когда горят все его индикаторы (`req`; `a|b` — любой из двух).
  - Идущие рецепты одной постройки делят её мощность: доли — по наличию сырья на складе (поровну, когда всего хватает). Погас индикатор — рецепт встал, его доля ушла остальным.
  - Рабочих у постройки одно число по её тиру, сколько бы рецептов ни шло.
  - Пример: пивоварня, четыре рецепта. Поле → «зерно» → зерновая брага на всю мощность; сад → «плоды» → зерновая и плодовая пополам; сожгли поля — плодовая на всю.
  - Постройка с `req` (сталеварня — «на складе: слитки железа») стоит, пока индикатор не горит.
  - Работа постройки, что живёт одними рецептами (горн, кузня, пивоварня), — сумма работы её рецептов; работа каждого рецепта лежит в `t.work['постройка:рецепт']` (логово зверей — по ней).
- **Виды строк** (`kind`; столбец «Вид строки»):
  - *здание* — основа линии (`line`);
  - *вариант* — другая основа для народа (бережная вырубка эльфов, боевой стан, хижина шамана);
  - *тир* — строится на месте прежнего (`upgrades`), сохраняет рецепты линии. Первый тир ставится только на место основы, дальше — и новыми единицами. Тир считается тем, из чего вырос: для «Нужно в державе», пристроек и ступеней города (`lineHas`). Тир угодья встаёт на клетку прежнего;
  - *пристройка* — своё здание при основе (`here`): пасека при поле, огороде или саде; сталеварня и магмовый горн при горне; маяк и верфь при гавани;
  - *улучшение* — без рук, меняет мощность основы (`boost`): плуг, тягловые мулы, удобрения полей и пещер, крепь, ловушки. Каждое — одно на город.
- **Слоты** (`TOWN_SLOTS`): своих работ в городе — 8 / 16 / 24 по ступени, улучшений — 1 / 2 / 4. Угодья на карте и жильё слотов не берут; две одинаковые постройки — два слота; тир встаёт на место основы. Полный город, совету которого нечего строить, сносит свою работу хуже `idle` (0,5) — худшую, одну за сезон (`razeWorst`).
- **Вес за ступень** (`TOWN_FX.flow.tierUp`, `tierAt`): постройка, открывающая следующую ступень (список `needsAny` ступени), получает у совета +1, когда в городе уже `tierAt` (0,8) жителей этой ступени и такой постройки нет. Боевой стан — в списке ступени 2.
  - Город на пределе сносит свою работу, что два года подряд шла хуже четверти (`raze`, `years`; `atlas/build.js razeIdle`), — освобождает место.
- **Сырая еда — одна** (`raw`): зерно, мясо, рыба, плоды, грибы, мёд, мука. Вид сырья — индикатор.
  - Сырое варят кухни (кострище → общинный очаг → поварня — тиры; хлеб при «муке» и мясной котёл огров — рецепты кухни).
  - Заготовительный двор сушит, солит (пока есть соль на складе), коптит — рецепты.
  - Пивоварня сбраживает — рецепт на каждый вид сырья.
  - Эльфы едят сырое как есть.
- **Мёд — не ресурс.** Пасека (пристройка поля, огорода или сада; опыление +10%) и хижина собирателя дают сырую еду и зажигают «мёд»; при нём пивоварня варит медовую брагу из сырой еды. Святилища и храмы мёда не тратят, жители его не покупают; Эльфы браги не пьют.
- **Тара — одна** (`ware`): горшки гончарни или бурдюки мастерской (рецепт Зеленокожих).
- **Топливо — одно** (`fuel`, в зарядах): древесный уголь углежогов, каменный уголь рудника (по богатству клетки углём), кизяк стад. Бревно горит зарядом, хворост — половиной.
- **Деньги — кошелёк.** Доход построек (перевоз, застава, трактир, гавань, монетный двор) идёт золотом в кошелёк мастеров.
- **Сводные постройки.**
  - Карьер даёт камень или глину по месту (`placeOut`).
  - Соляной промысел: выварка рассола, у Эльфов — соляной ручей.
  - Логово зверей: варги, пауки и шёлк, гиены — рецепты по расе Зеленокожих (орки, гоблины, гноллы).
  - Ручная мастерская (тир 0, без инструмента) → мастерская ремесленника: бурдюки, луки (Эльфы и Люди), корьевая броня (Эльфы) — рецепты.
  - Застава: топь-застава троллей — рецепт.
  - Загоны: большие стада Зеленокожих — рецепт.
- **Инструмент** (`tools`) — мягкий расходник почти всех производств: без него полсилы, при частичном обеспечении — по доле.
- Не перенесено из схемы: деление эффектов на «показатели державы» и «улучшения города» (эффекты по-прежнему считаются городом), сорта древесины и волокна по карте.

### Кухни и топливо

Числа — `data/townBuildings.js`: `FUEL`, `POOLS`, `KITCHENS`, `TOWN_FLOW.gather`, `rawFood`; в таблицах — «Блага городов» (столбец «Сырое») и «Жизнь логов и городов».

- **Сырая еда** (`raw`) — одна: что её дало, видно по индикаторам ([Цепочки 6.1](#цепочки-61-индикаторы-рецепты-виды-строк)).
  - Откуда берётся: поле, огород, сад, грибная пещера, пасека, хижины собирателя и охотника, рыбаки и промысловая пристань, бойня, костяная мука Зеленокожих.
  - Народ, который ест сырое (`eatsRaw`), кормится им, как готовым. Таковы эльфы. Кухня у них переводит сырую еду в готовую с потерей пятой части, поэтому у эльфов одна кухня на город — для приезжих (`lineMax` народа: `{kitchen: 1}`, тиры линии вместе; `atlas/towns.js lineFull`). Тир на месте прежней кухни строить можно.
  - Сырое не копится и не продаётся (как еда): его варят там, где сделали.
- **Бойня** — единственное место, где забивают скот (дварфы, люди, зеленокожие, где есть загон или выгон): 12 голов в год → 60 сырой еды, 90 шкур, 60 кости. Загоны и выгоны только разводят; склад держит по 2 головы на загон для приплода.
- **Кухни** — тиры одна другой, у всех народов:
  - кострище — 40 → 32;
  - общинный очаг — 80 → 80;
  - поварня — 240 → 288.

  Хлеб (при «муке») и мясной котёл огров — рецепты кухни; сушка, засолка и копчение — рецепты заготовительного двора.
- **Топливо — одно.** Тепло жилья (`heat`) и жар работы (`fire` постройки и рецепта) — заряды одного топлива (`FUEL`):
  - топливо (`fuel`: древесный и каменный уголь, кизяк) — 1 заряд;
  - бревно — 1;
  - хворост — 0,5: жители собирают его руками, 2 вязанки на голову в год (`TOWN_FLOW.gather`), он не копится.

  Город жжёт то, что у него есть, самый дешёвый заряд первым. Чего не хватило, ложится в спрос на топливо: город покупает его у соседей или ставит углежогов (200 брёвен → 648 зарядов).
- **Наборы** (`POOLS`): слитки (кузня големов), слитки по ценности (обряды), топливо, чеканка, материалы роскоши — каждый из того, что осталось после прямых `in` построек. Без своего набора постройка стоит, как без жёсткого блага (жильё — никогда; обряды — вполсилы).

### Металлы по рудам

Числа — `data/townBuildings.js` (`ORE_GOODS`, `METALS`, поле `dig`, рецепты горна и кузни). Пять потоков — бронзовый, железо-стальной, серебряный, золотой, мифриловый; у каждого своя руда и свои слитки:
- **Руды** — сырой ресурс (как сырая еда): только в плавку. Бронзовая (медь и олово), железная, серебряная, золотая, мифриловая.
- **Слитки** — обработанный ресурс (как готовая еда): в кузню, роскошь, чеканку, на обряды и големов; их наличие на складе — индикатор для рецептов и предметов каравана.

Как они делаются:
- **Добыча по геологии.** Рудник копает 240 руды в год, глубокие шахты дварфов (тир рудника) — 500 и мифрил. Добыча делится по тому, насколько клетка угодья богата каждой рудой (поля `ore_iron`, `ore_bronze`, `ore_silver`, `ore_gold`, `ore_mithril`). Клетка без руд — железо. Ещё рудник даёт топливо по богатству клетки углём. Прииск промывает золотой песок: 100 золотой руды в год (раньше — 200 золота сразу в казну).
- **Плавильный горн** — рецепт на каждую руду, идёт, пока руда на складе (своя или привозная): бронзовая 120 → 72 слитка, железная 120 → 86, серебряная 120 → 60, золотая 120 → 60. Развитая плавильня (тир) — втрое больше.
- **Сталеварня** (пристройка горна): 140 слитков железа → 56 слитков стали. **Магмовый горн** дварфов: 20 мифриловой руды → 10 слитков мифрила.
- **Кузня** — рецепт на каждые слитки: лучший металл даёт больше на выходе. На 50 слитков и 10 кожи: бронза — 11 инструмента, 8 оружия, 1 броня; железо — 15, 10, 2; сталь — 22, 15, 3. Мифриловые изделия куют только Дварфы: 10 слитков → 15 оружия, 5 брони, 3 роскоши. Рабочие и армия тратят инструмент, оружие и броню по их стоимости.
- **Кузня големов** берёт любые слитки (набор `bars`); голем делается из слитков своего металла со склада.
- **Потоки народов** (`flows`, `placeFlows`) — по каждой руде и слиткам: дварфам руды ×1,5 (и ×1,25 под горой), слитки ×1,25. Зеленокожие плавят серебро и золото на продажу (`tradeUp`); сталь у них только привозная.
- **Рынок каравана** считает руду её благом.

### Роскошь

Перенесено из ветки Elves. Числа — `LUX` в `data/townBuildings.js` (таблица «Жизнь логов и городов», lux). Ювелирная мастерская стала **мастерской роскоши** и больше не требует самоцветов на месте.
- **Материалы.** Мастерская работает **любые два материала** из дерева, камня, самоцветов и слитков бронзы, железа, серебра и золота. Это те два, которых у города больше всего по тому, сколько мастерская их берёт; третий — только если тех не хватило. Каждого материала уходит `take` в год: дерева и камня — возами (90), самоцветов — горстью (9), мифрила — 3.
- **Ценность.** Роскошь стоит столько, сколько ушло в неё материала, × `markup` (1,5), в единицах роскоши: резная утварь из дерева и камня — гроши, серебро с самоцветами — дорого.
- **Очерёдность.** Мастерская берёт последней, после кухонь и топлива: брёвна сначала греют и варят.
- **Монетный двор** чеканит из слитков золота, слитков серебра или самоцветов (`MINT`: в год 10, 30 и 25) — из каждого, сколько его на складе, и монета стоит ушедшего × 1,6.
- **Погребальные обряды** (пристройка святилища) отдают павшим любые слитки по стоимости (`RITE_WORTH`: 20 золотых ценности в год): чем дороже металл, тем меньше его уходит; сначала самый дешёвый. Без металла храм работает вполсилы (набор `rite` мягкий: `POOL_SOFT`).

### Асимметрия народов

Народ отличается не набором бонусов, а тем, какие цепочки благ у него замкнуты. Три механизма, общие для всех:

- **Потоки и замены народа** (`data/peoples.js` `flows`, `swaps`; столбцы «Потоки ×» и «Замены благ» в «Народах мира»): множитель на то, что его постройки дают, и благо, которое его постройки не берут, с заменой.
- **Уровни жилья** (`upgrades`): жильё следующей ступени строится на месте прежнего, место города растёт на разницу (`atlas/towns.js upgradeOf`, `houseGain`). Шалаши → избы (люди), подгорные жилища (дварфы), дома на деревьях (эльфы); шатры или шалаши → длинный дом; избы → каменные дома; дома на деревьях → древесный чертог.
- **Коррупция от грубого жилья**: она растёт на 0,03 в год за город × долю его места в шалашах и шатрах (`roughShare`, разруха `rough` в `data/kingdom.js`). Добротное жильё её сдерживает.

Проверка `npm run buildings` требует у разобранного народа (`DONE`), чтобы всё, что его постройки тратят (с заменами), давали его же постройки.

**Эльфы** (разобраны): лес, природа, трофеи; металл — табу.
- **Соляной ручей** (из ветки Elves): у соли на земле эльфов ручей сохнет на солнце без огня — 40 соли в год (рецепт `spring` соляного промысла, только эльфам). Соляной промысел открыт всем народам; его рецепт выварки рассола (200 соли, жар 80) требований к народу не имеет — варят ли эльфы рассол, решает автор ([Отложено](TODO.md)).
- Потоки: еда и зерно ×1,25, травы, мёд, зелья ×1,5, шкуры ×1,25 (охота), камень и глина ×0,5 (добывают щадяще); металл в рецептах заменяют деревом (железное и святое дерево), 3 к 1; пива не варят — вместо выпивки мёд и медовое вино (`drink → honey`), и в нуждах жителей тоже. Долгая жизнь, мало детей: города растут × 0,8 (`breed`).
- Открыты им: пашни, каменоломня, глиняный карьер, соляной промысел, дубильня. Закрыты горн, кузня, рудник и всё металлическое.
- Свои постройки: дома на деревьях (вместо шалашей, у леса, дают немного дерева), древесный чертог (ступень 2), плодовые рощи (еда, дерево, травы, волокно), лесной промысел (дерево, тёс, волокно, шкуры, травы, мёд, изредка самоцветы), священная роща (травы, самоцветы, самородное золото — дары леса), мастерская коры (плетёный доспех), колючая изгородь (вместо частокола), тайные тропы. Мастерская луков берёт дерево и волокно, без кожи.
- Поселение и поход (`npm run elves`):
  - **металл — табу** (`data/kinds.js RACE_MATERIALS`): бронзу, железо и сталь эльф не делает, не берёт со склада и не носит; серебро и мифрил можно. Отряды эльфов собираются без металла (`data/roles.js pieceOf`), караван не покупает, не берёт в трофеях и находках то, что его эльфам нельзя (`agents/equipment.js mayTake`); стражи выходят с луком и костяным копьём;
  - **луки без навеса** (`data/recipes.js races`): дерево и тетива из кожи, жил или волокна; без тетивы — простой лук из одного ствола (слабее, `selfbow`). Жилы снимают с туши вместе со шкурой (`CARCASS.sinew`). Рецепт с `races` берёт только работник этого народа;
  - **плетёный доспех** (`wicker`): кора, волокно, немного кожи; броня 0,3;
  - **колючая изгородь** вместо частокола (`data/buildings.js thornhedge`, `colonyRace`): защита и добыча налётчиков как у частокола, а чужой в зоне поселения идёт на 40% медленнее и теряет здоровье о шипы (`THORNS`, модификатор поселения `thorns`). Эльфийское поселение частокол не ставит, людское изгородь не растит;
  - **дитя леса** (`data/races.js` elf: `forestGuard`, `jobPace`): в лесу удар по эльфу на пятую часть слабее; камень эльф добывает вдвое медленнее, в поле работает на четверть быстрее.
- **Тег «Лесной»** (`sylvan`, `data/tags.js`): может быть в отряде эльфов — волк, лиса, олень, кабан, медведь, рысь, лось, древень.
- **Древень** (`data/bestiary.js treant`): старое дерево, сошедшее с корней; редок в лесу и джунглях, изредка в тайге, на карте не больше одного. Медленный, стрелы и клинки берут его плохо (колющий ×0,35, рубящий ×0,7), ветвями бьёт тяжело (дробящий), огонь жжёт его вдвое; первым не нападает, но отвечает тому, кто его ударил (`standGround`). Сила около 300 — как три человека в простой одежде. Срубленный даёт 20 брёвен.
- **Верстак резчика** в поселении больше не требует рудника: самоцветы приходят с рудника, от торговца или дарами леса.
- **Лесные союзники на карте мира** (`atlas/wilds.js`, числа — `wilds` в «Народах мира»). Эльфы сами в бой лезут мало: за них стоят звери земли и древни.
  - *Роща.* У эльфийского города в лесу просыпаются древни — `grove.grow` (0,5) в год, до `grove.cap` по ступени (2 / 4 / 6; `t.treants`). Лес вырубили или город упал ступенью — лишние засыпают.
  - *Стража.* В силе города (`might`) древни стоят по своей цене (здоровье × удар × `WAR_BEASTS.men`, у древня 26 жителей), а звери земли — `guard` (0,25) жителей, если лесные звери живут вокруг (самый густой лесной вид фауны клетки; выбитых — по биому). Сила города бьёт и логова, и набеги, и штурмы (`t.wardMen`).
  - *Поход.* Войско эльфов берёт зверей земли у своего города на `beasts` (0,25) своих бойцов и, если идёт на город в лесу, древней ещё на `treants` (0,25) (`p.wild`). Они бьются и гибнут вместе с войском, а домой не идут — уходят в лес. Летопись называет их при сборе.
  - *Звенья.* Призыватель у эльфов весит 1,5 (был 0,4), щит 0,3, копьё 0,7; «роща» — два призывателя за луками, «стражи леса» — копьё, два лука, призыватель и знахарь; отряд эльфов берёт «рощу» втрое чаще прочих звеньев.
- **Призыватель зверей** (`agents/summon.js`, числа `data/roles.js SUMMON`): роль `summoner` в отряде эльфов (посох, держится сзади) или эльф поселения и каравана — доля расы `summons` (15%), закреплённая за ним по id и сиду мира. Раз за бой зовёт лесных зверей, что живут на этой карте (биомы карты × обитание вида), на четверть силы своих рядом, не больше четырёх. Призванные — фракция «союзники» (`allies`, у колонии) или фракция призвавшего: бьют его врагов и тех, кто бьёт его людей (`agents/behaviours/summoned.js`), а когда врагов долго нет — уходят в лес. Через сутки призыватель может позвать снова.

**Дварфы** (разобраны): добыча и мастерство; горы, камень, металл, предки; плотная жизнь под горой; рабства не терпят.
- Потоки: руда, камень, самоцветы ×1,5; металл и уголь ×1,25; орудия, оружие, броня ×1,25; мёд они не берут — пиво вместо него, 1 к 1; ткань не ткут — кожа и шкуры (под горой нет выгонов), горшки — каменные чаши (`cloth → leather`, `pots → stone` 2 к 1), так что ткацкой и гончарне у них делать нечего. У крутых склонов и пещер ещё +25% руды и камня (`placeFlows`). Грибные пещеры дают и зерно (грибной солод): мельница, жернова и пивоварня у них живут. Детей мало: города растут × 0,9 (`breed`).
- Жильё: шалаши 100 → подгорные жилища 400 → подгорный чертог 700 (ступень 2, на месте жилищ).
- **Кузня големов** (город, ступень 2, нужна кузня в державе; 6 рук, 40 металла и 20 угля в год; `atlas/golems.js`, числа `GOLEMS`): со следующего сезона после постройки — голем в сезон. Он берёт на себя постройку по порядку (рудник, шахта, каменоломня, горн, кузня, литейня, угольные ямы, лесопилка…): ей нужно вдвое меньше рук, а выход больше на 25/35/45/60% по металлу (бронза, железо, сталь, мифрил). Предел — один голем на 400 жителей. Когда держава осваивает металл лучше, город перековывает голема (был бронзовый — стал мифриловый). Сверх того големы встают стражей: каждый — как 4/6/8/12 жителей в силе города и в его войске. Голем делается, только пока кузня работает хотя бы наполовину (`GOLEMS.make.work`), и из металла склада (`make.metal`, 20 на голема).
- **Голем** (`data/constructs.js`, четыре вида по металлу) и тег **«Механизм»** (`mechanism`): нет нужд и морали — не бежит; не травится, не кровит, не оглушается, не боится; не лечится ни лекарем, ни зельем, ни сам — чинится только у кузни (`agents/golem.js`, `GOLEM_REPAIR`). Здоровье 3/4/5/6, броня (как `resist` к рубящему и колющему) 0,4/0,5/0,55/0,6, мифриловый быстрее. Бьёт тяжело, дробящим. Сила — от 390 (бронзовый) до 1080 (мифриловый).
- **Роли** (`data/roles.js`): мастер-кузнец (`smith`, молотобоец: двуручный молот, дробящий удар ×1,3, первый ряд); мастер горна (`forgemaster`: без оружия и брони, «горновой огонь» — плюёт горящим маслом на дальность метания, поджигает цель и землю под ней, три раза за бой с долгой перезарядкой; огонь его не берёт); берсерк (`berserker`, общая роль: два оружия, без брони; рана бросает его в бешенство на 120 тиков — удар Силой ×1,3, шаг ×1,2, уклонение +0,15, потом усталость, шаг ×0,8 на столько же; пока бешен или устал — нового бешенства нет, следующее — только от новой раны после усталости). Звенья дварфов: «наковальня» (щит, два молотобойца, мастер горна, арбалет) и «бешеные».
- **Дружина дварфов** (`data/raids.js dwarves`, `data/seam.js REALM_BANDS`): приходит только в войну (`WAR_ONLY_BANDS`), за неприязнь не ходит; пленных не берёт, не жжёт; у сильной — големы лучшего металла её уровня.
- **Поселение** (`npm run dwarves`): подгорное жилище вместо избы (камень, у скалы; тёплое почти без дров), грибная пещера (еда без пашни, у скалы: 9 грядок, собирают как ягоды), каменная стена вместо частокола (защитники получают вдвое меньше урона), магмовая кузня строится у магмы (прочим — только захватом), кузня големов: голем в начале сезона из лучшего металла на складе (сталь, железо, бронза — 10 и 5 угля), не больше 1 + 1 на 6 жителей; стоит на страже у горна (`agents/behaviours/golem.js`), у горна же его чинят; с ней камень, руда и ковка на четверть быстрее. Темп работ дварфа: камень и руда ×1,25, ковка ×1,2.
- **Караван**: в дварфийском городе с кузней големов продают голема — лучшего из стражей города (он уходит из города), иначе из лучшего металла державы; один на караван. Голем везёт два короба, тянет повозку, ничего не ест, стоит на страже лагеря, чинится в городе с кузней или у походной кузни; в силе каравана он как 2–5 рыцарей.
- **Чужаки** (`folk`): дварфы любят только дварфов — чужих в свои города берут вчетверо реже (`take` 0,25), каждый год выживают их на 3% жителей (`expel`), а с общей земли теснят в полтора раза сильнее (`push`).
- **Рабство**: закон — запрет; пленных не берут — упавшего врага перевязывают и отпускают (поселение и караван), рабов не покупают и не продают, в набеги за рабами не ходят, с рабовладельцами из-за чужих рабов не воюют. Но **свои в неволе** — повод для войны: дело державы «освобождение» (`atlas/deeds/liberate.js`, числа `SLAVE.liberate`): город идёт на ближний город, где дварфы в рабстве (`t.slavesOf`), или на логово, где они в полону; против державы это война. Победа — освобождённые приходят в город свободными.

**Зеленокожие** (разобраны; прежде народ звался «орки»): самый пёстрый народ — его расы орки, гоблины, гноллы, тролли, огры. Терпимы к чужакам, уживаются друг с другом, живут войной.
- **Кочевники-воины** (из ветки Elves): роскошь, самоцветы и серебро, едва они легли на склад, меняют у проезжих торговцев на оружие по 0,8 стоимости (`tradeUp`, каждый сезон). Роскоши жители не хотят вовсе, а оружие — их нужда (`wants`: 0,004 на голову в год). Плодятся быстрее людей (`breed` 1,45 против 1,3).
- **Свои цепочки** (из ветки Elves): костяные жернова мелют кость охоты и загонов в муку (40 → 14), где зерна мало; мастерская бурдюков шьёт их из кожи (10 → 10), и в бурдюках зеленокожие держат питьё и зелья вместо горшков (`swaps`: горшки → бурдюки).
- **Расы в городе** (`kin` народа в `data/peoples.js`, `atlas/towns.js townKin`): в каждом городе живут все расы народа, вес каждой — `base` × (`KIN.any` + «Биомы расселения» расы по биому города); бóльшая — главная. Степь и луга — орки, предгорья и леса — гоблины, саванна и пустыня — гноллы, болота и тайга — тролли, огры понемногу. Своя постройка расы (`kin`) требует её доли в городе не меньше `KIN.least`. Гноллы теперь в линии отношений «зеленокожие».
- **Набор и рост** (`levy` 10/3, `breed` 1,45, `needs` 0,5, `beastLevy` 1): в поход идёт треть города и все обученные боевые звери; обычный скот остаётся дома — наравне с войском людей, где идёт каждый десятый, а то и сильнее; города растут на четверть быстрее (много детей, выживают не все; к тому их кормят набеги и рабы); благ жителям нужно вдвое меньше, и их замены — кость вместо горшков, дерево вместо соли и тёса, выпивка вместо мёда — действуют и в нуждах, и в стройке. Набеги и штурмы вывозят товары и золото (`plunder`), культ ходит в набеги втрое чаще и выбирает богатую цель по силам.
- **Культ войны** (`warCult`): каждый год шанс 0,3 затеять войну с любым соседом по границе — каким бы ни было отношение, и с другой державой зеленокожих тоже; не раньше чем через 2 года после прошлого мира. Война длится 2–5 лет и кончается сама, отношение возвращается к довоенному («без обид»). Их набеги портят отношение вдвое меньше. Сила города и войска ×1,15. Нет своей державы зеленокожих на границе — культ бьёт ближайшую свою (`far`: фронт — ближайшая пара городов, как далеко ни были). Совет держав зеленокожих тянется к розе втрое сильнее (`rosePull` 3). Своя брага — рецепт кухни с 0-й ступени (сырьё 4 → брага 40).
- **Рабство**: законно; в рабы берут всех — набеги за пленными идут на любую державу, свою родню тоже, и на станы диких племён (`atlas/deeds/captives.js`). Дикие племена зеленокожих в ответ ходят набегами на их города.
- **Земля и жильё**: у пастбищ и на равнинах еда, звери и шкуры ×1,25 (`placeFlows`). Тесноты не любят: дом вмещает ×0,75 (`house`: шалаши 75, шатры 150, стан орды 300 на ступени 2 вместо шатров); шатры для них — дом, коррупции от грубого жилья нет (`roughHome`); топят войлочный шатёр кизяком, не дровами (`heat` 80 — в степи леса нет). Без мёда, соли, горшков и тёса: пиво духам, копчёное мясо, черепа и рога, грубые брёвна (`swaps`); каменоломня открыта.
- **Мясо — основа рациона** (`places`, `workFlows` в `data/peoples.js`): кочевники пасут стада и охотятся на любой открытой земле (место «выпас», `grazing`: луга, степь, саванна, тундра, кустарники, пустыня, предгорья, высокогорье — вместо «лугов, степи или саванны»), хижина охотника даёт им сырой еды ×2, бойня ×1,5; поля, огороды и собиратели ×0,5, рыбаки ×0,75. Совет взвешивает постройку по тому, сколько она кормит у этого народа.
- **Свои постройки**: загоны зеленокожих (большие стада: еда, шкуры, кость, звери), логово варгов (орки), логово пауков (гоблины: паутина — ткань и волокно), бойцовские ямы (все), гиеньи норы (гноллы), топь-застава (тролли: дань с дорог), мясные котлы (огры). **Бойцовские ямы** в городе: каждый сезон ловят зверя или чудовище своей земли — самого густого, крупнее лучше (`atlas/beasts.js`, `WAR_BEASTS`), не больше одного на 200 жителей; боевой зверь в силе — как здоровье × удар × 2 жителей. В поход он переходит из города в конкретное войско, выжившие возвращаются; пока зверь в пути, город его не учитывает и не заполняет освободившееся место новым. Логова варгов, пауков и гиен выращивают свой вид в тот же отдельный запас (`t.warBeasts`), если работают хотя бы наполовину (`WAR_BEASTS.work`). Варги, пауки и гиены едят сырую еду (мясо со склада), не готовую. Разумных не ловят: тролль — зеленокожий.
- **Ватага зеленокожих** (`data/raids.js orcs`): все виды; звенья — ватага, рой, «всадники». В отряде ровно один **чемпион** (метка `champion`: здоровье ×1,6, Сила и Выносливость +2, стоит до последнего).
- **Роли** (`data/roles.js`): **наездник на варге** (орк) и **наездник на пауке** (гоблин) — один боец из двух тел (`agents/mount.js`, `RIDE`): идёт шагом зверя, зверь кусает при каждом ударе всадника, удар по паре с шансом 0,6 приходится на зверя; пал зверь — всадник пеший и оглушён, пал всадник — зверь дерётся сам, боевой зверь банды. **Загонщик**: сеть и дротики, кость и кожа, железа не носит (`maxTier: 0`), по зверям и чудовищам бьёт ×1,3, приводит 1–2 боевых зверей той земли. **Берсерк** — и у зеленокожих (орки, гноллы).
- **Поселение** (`npm run greenskins`): загон вмещает вдвое больше (`PEN_K`); логово варгов (нужны орки) и логово пауков (нужны гоблины) каждый сезон растят боевого зверя на страже лагеря (`settlement/warbeasts.js`, `WAR_DENS`), пауки прядут верёвку; бойцовские ямы: зверя, побитого у ям, не добивают, а ломают в боевого — он бьётся за колонию.

**Люди** (разобраны): среднячки — своего дара нет, зато все дороги ведут к ним.
- Приплывают к пустому берегу, а не к эльфийскому (`arrive.free` 0,7: берег, где уже живёт другой народ, им не мил). Живут среди других: на общей земле чужой народ теснит их вдвое слабее (`folk.mix` 0,5), а свой город они ставят и под чужими холмами — ближе к чужому городу, чем к своему (`folk.near` 0,7 × шаг расселения): так молодой народ находит себе место в мире, который древние уже поделили. Плодятся: города растут × 1,3 (`breed`). Чужих принимают в полтора раза охотнее (`folk.take` 1,5), торговля их теплит ×1,25 (`trade`). Толпа чужих народов растит преступность: разруха «преступность» растёт ещё на 0,3 в год за город × долю чужих в нём (`grows.folk`, `data/kingdom.js`) — у людей она выше всех.
- **Свои постройки**: ристалище (рыцари и чемпион в дружине), ипподром (ступень 2, после ристалища, у пастбищ: конные рыцари), притон (головорезы), торговый пост (торговый путь от него стоит вдвое, как от монетного двора). Жильё: шалаши 100 → избы 250 (где угодно: тёс привозят), длинный дом 300 (у леса), каменные дома 400 (ступень 2).
- **Хозяйство людей** (из ветки Elves):
  - срубы (150 мест, до 6, без требований к месту; избы встают на их месте);
  - пашня вместо поля (`ploughland`, вариант строки поля): поле людям не строится. Люди корчуют, ровняют и удобряют землю похуже (`arable`: плодородие от 0,3, ровность от 0,6) и берут с неё в полтора раза больше поля (165 сырой еды и 100 льна; зажигает «зерно» и «лён»). Плуг, тягловые мулы и удобрения, пасека и пивоварня принимают пашню как поле;
  - трактир, один на город: варит любое сырое (150 → 120 еды), варит свою брагу (300) и продаёт ужин (50 золота);
  - храм людей держит церковную школу: знание 0,15 сверх веры (`fxBy`);
  - рожают чаще (`breed` 1,3), расселяются теснее (`spacing` 11).

  Порча зерна из Elves не перенесена: еда здесь не хранится.
- Сверка народов бок о бок — `node tools/race-balance.mjs` ([Проверки](TESTING.md)).
- **Дружина людей** (`data/raids.js host`, `atlas/towns.js realmBand`, `data/seam.js HOST_BANDS`): держава людей шлёт дружину по тому, что построила: ополчение и стена щитов; с ристалищем — звено рыцарей и один чемпион, с ипподромом — конница, с притоном — налётчики с головорезами. Разбойники «Серых волков» остаются разбойниками.
- **Роли**: рыцарь (тяжёлый доспех, меч, булава или копьё со щитом, металл на ступень выше банды, держит строй как щитоносец) и конный рыцарь (рыцарь на боевом коне — один боец из двух тел, как наездник зеленокожих). Обе — только в звеньях дружины (`linkOnly`). Рыцарь каравана в тяжёлом доспехе со щитом бьётся рыцарем.
- **Поселение** (`npm run humans`): ристалище (защитники получают на 10% меньше урона), притон (налётчики уносят на пятую часть меньше), торговый пост (караваны торговцев в полтора раза чаще, модификатор `caravans`).

## Требования построек и рецептов

`data/requirements.js` (факты, условия, чтение старых полей), `core/requirements.js` (одна проверка: `meets`, `explain`, `reqText`, `reqErrors`), `atlas/requirements.js` (факты города: `townFacts`, `whyBuild`, `buildingNeedText`). Расовые, государственные и общие постройки — **один каталог** (`data/townBuildings.js`), а доступность решает одна система требований; рецепты и дела спрашивают её же.

- **Факт** — что мир может сказать о городе (таблица «Факты»): народ, уклад державы, доля / число / руки расы среди жителей, постройка стоит (в городе или в любом городе державы; `exact` — именно эта запись, не тир линии), место, индикатор, благо на складе, жителей, ступень, столица, правитель жив. Факты не лежат в таблице значений — они читаются с города в момент проверки. Факт — не расходуемый ресурс: наличие металла проверяет условие, расход остаётся во входах.
- **Условие** — `{fact, arg?, op, value, scope?}`; операции `= != > >= < <= in not-in`; группы `{all: […]}` и `{any: […]}`. Пороги живут в условии, не в факте: доля гноллов одна, «гноллов не больше 5 %» — условие того, кто просит. «Людей больше 80 %» — строго больше, по доле до округления; ровно 80 % не проходит. В пустом городе доли нет — сравнение не выполняется, и «≤ 5 %» тоже. Неизвестная раса при живом городе — доля 0; неизвестный факт — ошибка данных (`reqErrors`).
- **Старые поля строк** (`peoples`, `kin`, `requires`, `requiresAny`, `here`, `tier` / `tierBy`, `pop`, `capital`, `needs`, `needsAny`; у рецептов `req`: индикатор, `kin:x`, `people:x`, `stock:g`, `a|b`) читаются как требования (`needsOf`, `reqNeeds`, `workNeeds`): строки остаются короткими, проверка видит одну форму. `kin` несёт прежний порог `KIN.least` (8 %), пока его не настроят вручную. Строка может нести и `need` — требование, записанное явно; оно добавляется к коротким полям. Столбец «Требования» таблицы «Постройки городов» показывает всё одной строкой.
- **Область**: доля расы в городе — не доля в державе; постройка «в державе» (`scope: 'realm'`) — в любом её городе.
- **Этапы**: стройка проверяет требование при выборе, закладке, каждый сезон стройки и при вводе (`canBuild`, `atlas/build.js`; совет — тот же проверяющий): утрачено на полпути — работа ждёт в `t.works`; работа — `req` и `workNeed` постройки и требования рецептов каждый сезон (`atlas/economy.js`). Порог стройки (`need`) не копируется в условие работы: упала доля людей до 79 % — новую такую постройку не заложат, а стоящая стоит и работает; кто хочет гасить работу — пишет `workNeed`. Захват города меняет уклад (факт читается с нового владельца), постройки и люди остаются.
- **Объяснение**: `whyBuild(a, t, b)` → каждое условие с чтением и вердиктом («ступень 2, нужно не меньше 2 — да; столица: да — да; жителей 1000, нужно не меньше 800 — да»); справочник и интерфейс берут его оттуда же, откуда стройка. Пределы числа, слотов, линии и угодий остаются своими правилами `canBuild`.

Проверка — `npm run polity` (ровно 5 % проходит «≤ 5 %», ровно 80 % не проходит «> 80 %», город и держава — разные доли, пустой город не проходит, захват и смена правителя — разные следствия, стройка и совет спрашивают одно).

## Деньги городов

`atlas/treasury.js`, числа — `TOWN_MONEY` (`data/townBuildings.js`). У города три кошелька — **казна** (`t.gold`), **жители** (`t.peopleGold`) и **мастера** (`t.makersGold`); каждый платёж идёт из одного в другой, и деньги ходят по кругу: жители покупают — мастера получают выручку — платят зарплаты и покупают сырьё — жители снова покупают; казна берёт налоги и возвращает их содержанием и стройкой. Раз в сезон, вместе с хозяйством:

- **Склад** (`t.stock`): что постройки сделали и не потратили, копится — до года того, что город делает и берёт (не меньше `least`); постройки сначала берут со склада. Город держит запас: сезон того, что возьмут его мастерские (`keep`), и сезон базовых нужд жителей (`safety`) — из него берут только свои жители; остальное продаёт. Еда на склад не идёт — она ходит по сети людьми. **Заготовки** (`stores`, единица — человеко-год) идут: копятся, продаются и покупаются как любое благо, уходят податью в казну державы, с поселенцами и в войско. В голодный год, когда земля, постройки и сеть кормят меньше жителей, чем есть, город ест заготовки со склада — заготовка на жителя в год (`atlas/peoples.js`); в прокорм сезона они не входят.
- **Мастерские покупают сырьё** у связанных по сети городов (`atlas/sites.js`), у которых этого больше их запаса, **по цене продавца в этом сезоне** (у чужой торгующей державы — × `foreign`). Платят мастера покупателя мастерам продавца. Купленное работает в тот же сезон; товары крепят связь сети, как еда (`link` золота — как один накормленный).
- **Нужды жителей** (`needs`, × `needs` народа, с его заменами): нужды сезона считаются в его начале: базовое (брёвна, ткань, горшки, соль, кожа, выпивка, орудия) и — тем больше, чем богаче, — достаток (роскошь, мёд, зелья, ткань, выпивка, травы). Сначала базовое — со своего склада сверх запаса мастерских, потом в связанных городах, — затем так же достаток, пока хватает денег. Чего жителям не хватило, то на рынке дороже (`price.need`). Как закрыты нужды (`t.needs`), так и растёт город (× 0,95 … 1 и × до 1,1 за достаток) и лояльна держава (`needs` в лояльности). Чего жители не смогли купить (`t.needs.lack`), то тянет город строить мастерскую, что это делает.
- **Купцы**: что сверх места на складе, продаётся проезжим купцам — самое дорогое первым, пока хватает их кошелька (`merchants.purse` на жителя за сезон × (1 + торговля)), дёшево (× 0,4 цены), где есть рынок, торговый пост, корчма, караван-сарай или гавань — × 0,7. Остальное пропадает. Купцы и постройки, дающие золото (пост, гавань, россыпь, монетный двор), — откуда деньги приходят в мир.
- **Зарплаты** — `makers.wage` за сезон за каждого занятого вольного работника (рабам не платят), пока у мастеров хватает денег; недоплата — «долг» в карточке. **Налоги** — с дохода сезона: `makers.tax` с выручки мастеров, `people.tax` с заработка жителей; доход от стройки, содержания и жалованья гарнизона облагается в следующем сезоне (`t.carry`). Содержание казна платит после сбора налогов.
- **Содержание**: каждая постройка (а не вид) стоит золота — `UPKEEP` по категориям × `upkeep.gold` в год; казна платит его жителям, что их держат. Не хватает казны — доплачивает держава; неоплаченное (`t.unpaid`) — постройки работают хуже и растёт упадок.
- **Стройка** (`planBuild`, `doBuild`, `build`): постройка берёт материалы по своему виду (с заменами народа) (`build.mats`: дома — брёвна (тёс — то, что изба берёт в год, а не из чего её рубят: иначе город без лесопилки не построил бы ни дома), укрепления — камень, мастерские — брёвна); после замен одинаковые материалы складываются до резервирования — со своего склада, а чего нет — у связанных городов; брёвна и камень, которых не достать, жители собирают сами втрое дороже (`gather`: надбавка — их часы, золото не получает никто; сбор занимает свободные руки). Работа — по ступени (`labor`: 0 — деревня строит своими руками, 10, 30). Платят деньги державы на стройку (`t.grant`), потом — кто строит (`payer`): дома — жители, промыслы и мастерские — мастера, остальное — казна. Нет материалов или денег — город берёт следующую по желанию постройку (до `tries` раз).
- **Выбор стройки** сторонится постройки, чьё благо и так лежит на складе (цена на полу, `TOWN_FX.flow.glut`), и не ставит ту, на которую нет свободных рук.
- **Добыча** (`plunder`, `atlas/deeds/captives.js`, `raidTown.js`, штурм в `atlas/diplomacy.js`): выигранный набег вывозит `plunder.raid` товаров и золота побеждённого города, штурм — `storm`; культ войны (зеленокожие) — × `cult`, ходит в набеги втрое чаще (`warCult.raids`) и выбирает цель по добыче и силам (`dare`). Золото — жителям-воинам и доля вождю в казну, товары — на склад (лишнее уходит купцам). Доли: набег 0,25, штурм 0,5, культ × 3 (у зеленокожих набег уносит три четверти, штурм — всё). Культ войны уводит и людей: `plunder.slaves` (0,4) потерь побеждённого города при набеге и штурме становятся рабами его города (`driveOff`, `t.slaves`, `t.slavesOf`) — вместо пленных, что вливаются в набег у остальных народов.
- **Подати** (раз в год): держава берёт долю казны города сверх запаса на жителя (`tax.keep`) — по указу о податях: тяжёлые 30%, обычные 15%, лёгкие 5%; и ещё ту же долю того, что склад может отдать из благ казны (`realm.kind`), — натурой, пока их не хватает складу державы ([Казна державы](#казна-державы)). **Расходы державы**: каждый сезон — войско (`realmKeep`: гарнизоны, жалованье, заготовки и снаряжение войскам в поле), раз в год — стройка (`realmSpend`, `t.grant`); пустая казна растит упадок.
- **Показатель «экономика»** державы прибавляет полноту казн её городов (`money`).
- **Скот** на складе (`stock.beasts`) — обычные животные для еды и торговли, без военной силы. Загоны и пастбища дают приплод; взрослый излишек расходуется на еду, шкуры и кости (`TOWN_FLOW.herd`), сохраняется племенной запас. Боевые звери (`t.warBeasts`) сюда не попадают; варгов и пауков на еду не забивают. В местном поселении загон забивает взрослый излишек, когда припасов меньше `HERD.meatBelow` на жителя, сохраняя `HERD.breeders` взрослых каждого разводимого вида.
- **Походное снаряжение** (`atlas/army.js`, `ARMY.kit`, `wear`, `heal`): при отправке войско берёт имеющиеся оружие, броню и травы со склада. В бою травы спасают часть раненых; голод ими не лечат. В поле оружие и броня изнашиваются на `wear.season` (5%) за сезон, держава доводит их до нормы со своего склада. Вернувшиеся приносят снаряжение пропорционально уцелевшим людям, с износом 10% после победы, 35% после поражения, 5% без битвы. **Припасы**: при сборе войско берёт заготовки на `supplies` (120) дней — со склада державы, потом своего города; чего нет, добывает фуражом, но выходит не меньше чем с `supplyFloor` (половиной) припасов. Каждый сезон держава шлёт заготовки на сезон: накормленное войско не тратит припасы, ненакормленное ест свои. Стражевые големы тоже переходят в войско и возвращаются; потери людей, зверей и големов сразу снижают силу отряда.
- **Самоцветы**: обычный лесной промысел их больше не даёт; редкая примесь рудников и священных рощ сокращена в десять раз. География месторождений сохранена.
- **Цены рынка сезона** (`t.market`, сохраняются): чего не хватает — дороже, чем полон склад — дешевле (× 0,6 … 1,8); по ним торгуют города и караван.

**Караван на рынке города** (`campaign/town.js`): караван торгует с мастерами города. Его товары они покупают на свои деньги (нет денег — не берут), проданное идёт на склад; за покупки, еду, кузнеца, алхимика, наём и пленных караван платит мастерам, купленное уходит со склада; заработок каравану платят они же. Цены — по рынку сезона; паёк дешевле, где у города излишек еды.

Карточка города: три кошелька, нужды и достаток, оборот сезона (жители купили, зарплаты, налоги, купцы, содержание, пропало), гарнизон и деньги на стройку; карточка державы — казна и расходы за год. Артефакт «Экономика Леса» — разбор состояния по нескольким мирам. Прогоны до исправления сезонного шага напрямую с новыми не сравниваются: прежде хозяйство вызывалось только весной при сезонных объёмах платежей и производства. `npm run economy:history -- 5,9,21,27,47` прогоняет полные истории и печатает по каждому народу население, закрытие нужд, нехватку сырья и простой за последние 20 лет; `--levy=0.5` позволяет сравнить прежний набор Зеленокожих на том же коде. `npm test` проверяет все четыре сезона, расход скота, походные запасы и повторяемость кандидата `chain-balance --check` (включая отложенные доходы `carry`).

### Казна державы

Сведено из ветки Elves на казну этой ветки. Числа — `TOWN_MONEY.realm` в `data/townBuildings.js`. Казна — это **золото** (`realm.gold`) и **склад** (`realm.stock`) благ из `realm.kind`: заготовки, оружие, броня, травы — до `kind[g]` на каждые 100 жителей державы (5, 1, 0,5, 0,3).

**Каждый сезон** (`realmKeep`, `atlas/kingdom.js stepRealmKeep`) держава содержит войско:
- **гарнизоны** — `spend` × `army` (в мир 0,4 × 0,3, в войну 0,4 × 0,7) золота казны в год, по четверти за сезон: человек в год за `man` (3) золотых, по жителям городов (`t.garrison`, человек в силе города), жалованье — жителям;
- **войска в поле** — `wage` (0,2) золотого на бойца в год, по четверти за сезон; чего казна не доплатила, `desert` (0,3) × недоплаченную долю бойцов уходит за год;
- **еда войск** — заготовка на бойца в год со склада державы; накормленное войско не тратит своих припасов, ненакормленное ест их ([Отряды](#отряды));
- **снаряжение** — оружие и броня в поле изнашиваются на `ARMY.wear.season`, держава доводит оружие, броню и травы до `ARMY.kit` со склада.

**Раз в год**, в конце года (`atlas/kingdom.js`):

1. **Подати** — по указу (`taxYear`). С каждого города: `ставка` × казну города сверх `tax.keep` на жителя — золотом; и ещё `ставка` × то, что склад может отдать из благ казны (то, что иначе ушло бы купцам), — натурой, пока их не хватает складу державы. Коррупция уносит по дороге `corrupt` (0,03) × свои очки, не больше `corruptMax` (0,35), — и золота, и благ. Эти деньги уходят из мира, в карманы чиновников. Коррупция растёт × бюрократию народа (`bureau`): эльфы 0,7, дварфы 1, люди 1,2, зеленокожие 1,5.
2. **Двор** (`realmDuties`) — `court` (3) золотых за каждую занятую должность на 1000 жителей; недоплата двору растит упадок (`court` в «Разрухе»).
3. **Дань** (`payTribute`). Держава, которая ненавидит соседа (отношение ниже −1,5) и в `ratio` (2,5) раза слабее его, платит ему `tribute.share` (5%) казны; в летописи — строка.
4. **Гранты на стройку** (`realmSpend`) — `spend` × (1 − `army`) золота казны, по ветру совета ([Совет державы](#совет-державы)).

В течение года казна получает ещё:
- **пошлины** — `duty` (5%) с того, что город покупает у города другой державы; платят мастера покупателя, в казну его державы;
- **добычу** — при штурме столицы державы-штурмовщики уносят `seat` (половину) её казны.

**Совет податей.** Указ «подати» читает запас казны — сколько лет прошлогодних трат она держит (`reserve`):
- меньше полугода — «тяжёлые: казна пуста» (0,3);
- больше четырёх лет — «лёгкие: казна полна» (0,05, лояльность +0,15);
- иначе, как прежде: тяжёлые в войну, лёгкие при ропоте, обычные.

Книга казны за год (`realm.fisc`) — в карточке державы: подати (из них натурой), сколько унесла коррупция, пошлины, добыча, дань, двору, войскам, заготовки и снаряжение войскам, недоплаты; там же склад державы и гарнизоны сезона. Проверка — `npm run fisc`.

**Торговля держав** из Elves (`atlas/trade.js`: излишек державы туда, где у другой нехватка) отдельно не переносилась: здесь её делает покупка между городами по связям, у чужой державы — дороже (`foreign`) и теперь с пошлиной. Склад державы — блага для войска (заготовки, оружие, броня, травы); гранты на стройку — золотом.

## Держава как королевство

`atlas/kingdom.js`, справочник `data/kingdom.js`. Раз в год, в конце года (зимой, чтобы учесть набеги всего года), каждая живая держава подводит итог в `realm.kingdom`:

- **четыре показателя** (`REALM_STATS`): культура, экономика, лояльность, стабильность — из эффектов построек её городов, мировоззрения, должностей, указов и события года, минус разруха;
- **четыре вида разрухи** (`RUINS`): коррупция, преступность, упадок, раздоры — каждый растёт от своего источника, гасится своим показателем и отнимает от другого;
- **содержание построек** (`UPKEEP`) по категориям — в золоте из казны города за каждую постройку (см. [Деньги городов](#деньги-городов)); подати по указу идут в казну державы, она тратит их на гарнизоны и стройку;
- **указы** (`EDICTS`): подати, праздники, набор войска — берётся первый уровень, чьё условие выполнено;
- **двор** (`OFFICES`): правитель, полководец, казначей, первосвященник — личности мира ([Правители и личности](#правители-и-личности)) при столице, служат свои годы и уходят с поста живыми; пустая должность отнимает от показателя; трон после смерти правителя — по укладу;
- **события года** (`REALM_EVENTS`) — таблица случайностей с условиями.

Обратная связь в мир — `FEEDBACK` (числа подбираются при балансе): раздоры и низкая лояльность повышают шанс раскола (`schismFactor`); экономика ускоряет рост городов, стабильность прибавляет им силы (на год, в пределах `range` 0,7…1,3; хранится в городе — `t.realmFx`). «Рынок по ступени города» (`MARKET_TIERS`) читает кампания; по умолчанию без предела.

## Совет державы

`atlas/mind.js`, числа — `data/mind.js` (таблица «Совет державы»), роза каждого народа — `rose` в «Народах мира». Двор ([Нравы](#нравы-дела-логов-и-держав)) выбирает дела вовне, совет держит курс дома. Три вектора — **агрессия, рост, экономика**, как роза ветров: у каждой постройки и дела двора свои доли, в сумме единица. У народа роза — куда он годами ведёт державу: зеленокожие 0,55 · 0,30 · 0,15 (война), люди 0,25 · 0,45 · 0,30 (рост), дварфы 0,20 · 0,20 · 0,60 (ремесло и запас), эльфы 0,35 · 0,20 · 0,45 (стражи: оборона и ремесло, растут медленно). Совет перенесён из ветки Elves на экономику этой ветки ([Деньги городов](#деньги-городов)); там, где у Elves были склад державы, гранты материалами и кошели городов, здесь гранты казны на стройку.

- **Вектор постройки** — её `vec` в «Постройках городов». Где его нет, вектор считается:
  - постройки еды (`VEC_RULES.cat`) — рост: они кормят потоками, а не эффектом;
  - из эффектов (`VEC_RULES.fx`): оборона → агрессия; жильё, еда, здоровье → рост; ремесло, торговля, знание → экономика; вера 0,3 · 0,7 · 0; слава пополам;
  - из того, что постройка даёт (`VEC_RULES.out`): оружие и броня → агрессия; еда, зерно, заготовки и скот → рост; прочее → экономика.

  Казармы заданы вручную: 0,9 · 0,1 · 0.
- **Вектор дела** — `DEED_VEC`: война, поход, набег, полон — агрессия; логово и разведка — пополам агрессия и рост; освобождение — 0,6 · 0,4; мир — экономика.
- **Курс** — что держава делала: золото, которое города заплатили за постройки (`planBuild`), по вектору постройки, и гранты казны на стройку по их вектору. Это скользящее среднее за `course` (20) сезонов. Новый совет начинает с того, что города уже построили.
- **Нужды сезона** (флаги 0…1):
  - нужда — базовые нужды жителей (`t.needs.basic`) ниже `fed` (0,95);
  - теснота — жители/место выше `crowd` (0,6);
  - угроза — война (1) или угроза логов городам;
  - нехватки — сколько благ не хватает работам городов, полная при `short` (6);
  - казна пуста — золота державы меньше `hoard` (5) на 100 жителей.
- **Ветер** = роза + `pull` × (роза − курс), не меньше нуля, + `needs` (0,8) × нужды: угроза → агрессия, нужда и теснота → рост, нехватки → экономика. Ветер — доли, сглаженные `smooth` (0,7). Когда новый ведущий вектор обходит старый на `turn` (0,05), в летописи появляется строка («Совет … повернул к войне: угроза»).
- **Роли городов** — раз в год, весной. Каждый город, кроме столицы, получает флаг вектора: по каждому вектору столько городов, сколько просит ветер. Первыми идут те, кто уже туда тянет (`role`: построенное, угроза для агрессии, избыток земли для роста). Город держит роль, пока счёт её вектора держится. Роль — приоритет, не приказ: желание постройки × (1 + `build` (1,5) × её доля по роли × послушание). Столица тянется по ветру (`seat` от силы).
- **Послушание** = `obey.base` + `obey.loyalty` × лояльность державы, 0…1, × (1 − доля коррупции: `obey.corrupt` × её очки, не больше `obey.corruptMax`).
- **Гранты на стройку по ветру** (`councilShares`). Раз в год казна державы делит гранты на стройку (`realmSpend`, [Деньги городов](#деньги-городов)) по долям ветра. Доля каждого вектора идёт городам этой роли по жителям; столица берёт `seat` от доли каждого вектора; город, где жителям не хватает базовых нужд, считается и за рост. Вектор, который не несёт ни один город, делится на всех по жителям. Жалованье гарнизонам совет не трогает.
- **Двор по ветру:** вес каждого дела × (1 + `deed` × ветер по его вектору).

Карточка державы — раздел «Совет»: роза, курс, ветер, нужды, роли, гранты, послушание. В карточке города — роль, а если город строит против роли, то и вектор, к которому он на деле тянет. Слой карты «Воля державы»: города в цвете роли, нити к столице, рамка — строит против роли. Проба — `npm run mind`, проверка — `npm run mind:check`.

## Бедствия, боссы и артефакт

`atlas/calamity.js`, справочник `data/calamities.js` (`CALAMITIES`, `CAL`, `OMENS`, `FALL`, `ARTIFACTS`). Бедствия идут в эпическом мире (`cfg.epic`) и в «Заселении мира» (`cfg.free`, их ставит рука).

- **Заря мира.** В начале истории бог оставляет артефакт (одно из имён `ARTIFACTS`) в святилище — клетке суши в глубине мира (`a.sanctuary`, `a.artifact`). Путь артефакта — `a.artifact.trail`.
- **Три бедствия эпического мира**, по одному на эпоху (`a.calamities`). Вид выпадает из семи: пробуждение древнего выводка, пришествие некроманта, король-лич, вампирский двор (только при народах), открытие разлома, восстание великанов, орда гоблинского царя.
- **Фазы**: `waiting → omens → rise → fallen`. Знамения начинаются на доле эпохи `CAL.start` и идут несколько лет, по строке в год; потом восход; потом гибель.
- **Восход.** Место — далеко от прошлого бедствия (у первого — от святилища), не у города; после дикой эры — в досягаемости набега от городов народов. Вампир селится в городе. Встаёт логово босса, вокруг — логова свиты, по всему миру оживают ещё несколько логов. Артефакт переходит к боссу. С шансом `CAL.fromLeader` бедствие поднимается на живом главаре подходящего рода: он сохраняет имя и титул и растёт до силы босса.
- **Босс** — существо своего вида, выросшее за его пределы (`CAL.boss`). Пока он жив, логово держится не слабее `floor`, набеги сильнее, выводки чаще; соперники и отдельные города его не трогают.
- **Гибель.** В дикую эру — дракон: ближайший живой дракон убивает босса и засыпает надолго, израненный; без драконов босса разрывают его же стаи. После дикой эры — союз держав (ниже). Если никто не справился к последним годам эпохи, безымянные герои запечатывают босса. Если логово пало раньше — босс пал вместе с ним.
- **Могила** (`a.graves`): курганы на месте гибели и запись с годом, эпохой, боссом, тем, кто его сразил, и надписью (`epitaph`). Артефакт уходит в могилу и ждёт следующего хозяина.
- **В «Заселении мира»** рука задаёт вид (или «решит мир»), место и через сколько лет (`FREE.calIn`), не больше `CAL.free.max` непрошедших; первое бедствие оставляет святилище и артефакт (`addCalamity`).
- Четвёртое бедствие, которое собирается к выходу каравана, и квест эпического мира описаны в [Кампании](CAMPAIGN.md).

## Союзы против бедствий

`atlas/alliance.js`, числа — `data/calamities.js ALLY`. Модуль ничего не знает об эпическом мире, кроме переданного бедствия.

- **Сбор.** Через несколько лет после восхода (после дикой эры) в союз входят державы с живым городом в досягаемости босса, а если таких нет — ближайшие. Войны между ними прекращаются, отношения не ниже `truce` и теплеют каждый год.
- **Поход.** Каждая держава собирает долю жителей своего ближайшего к боссу города и идёт на его логово. У логова войска ждут друг друга и штурмуют вместе: их сила против силы босса и живых логов свиты, обе с разбросом.
- **Победа** — босс пал от союза, войска теряют часть бойцов. **Поражение** — теряют больше, следующий поход через `ALLY.retry` лет.
- **Распад.** Через несколько лет мира после гибели босса союз распадается: отношения каждой пары возвращаются почти к прежним, а державе, не приславшей войска, это припоминают. Старые войны дальше начинаются сами, по порогам дипломатии.
- На босса, которого ищет караван, союз не идёт.

## Летопись мира

`a.chronicle` — строки `{era, year, season, text}` (у этапов суши — `stage`, у бедствий — `topic: 'calamity'`, у державы — `topic: 'kingdom'`, у похода — `campaign`). Место события — биом и сторона света («в тайге на северо-востоке», `wherePhrase`).

**Сворачивание мелочи.** Новые дороги пишутся одной строкой за круг, отбитые набеги дикарей и мертвецов — одной строкой за год, постройки — только приметные (`notable`) и большие; удачные набеги, битвы, сожжения, выжженные логова — каждый своей строкой.

**Уровни строк** (`atlas/chronicle.js lineLevel`, правила — `data/worldChronicle.js LEVEL_RULES`): **важное** — эпохи, бедствия, войны и мир, расколы и гибель держав, сожжённые города, приход народов, дракон, первые встречи, строки похода и сотворения земли; **мелкое** — набеги вышедшие и отбитые, выводки, старые логова, дороги, мор, крысы, «осели», постройки, осады, двор и события державы; остальное — **обычное**. Правило — регулярное выражение, первое совпадение решает.

**Текстом.** `worldChronicleText` — летопись по эпохам с выбранной подробностью: шапка, «Сотворение мира», блок каждой эпохи (с её бедствием), «После эпох» (годы похода). `calamityChronicleText` — летопись катаклизмов: заря и святилище, каждое бедствие от знамений до могилы с боссом и союзом, надписи могил, путь артефакта. На экранах мира и кампании — переключатель «Важное / Обычное / Всё», «Катаклизмы» и выгрузка в файл; выбор подробности помнится в браузере.

## Сохранение и библиотека миров

**Ядро** — `atlas/save.js`. Мир хранится целиком, не сидом: правка генератора меняет мир с тем же сидом, а летопись надо сохранить.

- `saveAtlas(a, name, kind)` пишет мир через общий кодек `core/serialize.js` (справочники — ссылками), с описью `meta` (`worldMeta`: название, сид, размер, годы, города, державы, отпечаток, эпический ли, вольный ли, поход в нём, квест).
- Поток истории сохраняется позицией (`histRnd`) и пересобирается из сида при открытии; рабочие буферы поиска пути и гнили не сохраняются (`SCRATCH`). Мир, сохранённый посреди истории, доживает её сезон в сезон так же, как непрерывный.
- Два вида записи: **мир** (`WORLD_KIND = 'forest-world'`, файл `.world`) и **земля** (`LAND_KIND = 'forest-land'`, файл `.land`) — суша без истории с правками руки. Землю берёт «Заселение мира».

**Браузер** — `ui/worlds.js`: база IndexedDB `forest` (`ui/store.js`), хранилища `worlds` (сжатый gzip мир) и `worldIndex` (опись для списка, без самого мира). Сохранить, сохранить поверх, открыть, удалить, переименовать, выгрузить файлом, открыть файл (он кладётся в библиотеку). Все режимы, которым нужен мир, — «Заселение мира» и кампания (и стоянки на клетке мира) — берут его отсюда.

## Клетка мира становится локальной картой

Шов собран в `seam/cell.js` — единственном модуле, который знает и мир, и локальную карту; локальная карта мир не импортирует. Числа перевода — `data/seam.js`. Техника шва — в [Архитектуре](ARCHITECTURE.md).

`cellPlan(a, i, {name, id, race})` → `{seed, ref, region, extra}` — простые данные без размера карты. Сид локальной карты — `сидМира@x,y`; `ref` — какой мир, какая клетка, какой год.

| Что | Откуда в мире | Во что на локальной карте |
|---|---|---|
| Местность | `cellBiomes` (с подземьем и курганами) | доли биомов региона |
| Недра | `cellGeology` | порода, уровни руд, золотой песок, золотая жила, магма |
| Дикие грядки | доли биомов × веса `FLORA` | `flora` региона |
| Звери | `faunaAt`; логово рядом делает своего зверя чаще (`SEAM.lairBeast`) | `faunaShift` региона; если дичи нет совсем — немного оленей |
| Дороги | `roadAccess` клетки и её кольца | `road` региона — частота караванов |
| Климат | средняя температура, размах года, осадки, широта | `meanT`, `trange`, ливни, рост растений, порог возгорания, долгота дня |
| Плодородие | `fert` | множитель плодородия участка |
| Ворота | стороны, куда уходят дороги мира (до двух); река входит со стороны самого полноводного притока и выходит туда, куда стекает (`f.down`), широкая — у большой реки | дорожные и речные ворота участка: реки и дороги продолжаются за край в нужную сторону |
| Соседи | ближайший город расы колонии (свои), ближайший город торгующей державы (торг), станы племён и логова мертвецов (`LAIR_BANDS`), народ племён по полям в досягаемости — и без логова рядом (`FOLK_RAIDS`), мертвецы некроманта по полю мертвецов, башня некроманта — культисты (пул живых и мёртвых клетки, `cultPool`), враждебные державы (`REALM_BANDS`), разбойники у городов людей, гниль самой земли | `neighbours` участка: дни пути, шанс набега, веса банд; их читает `outside/scripted.js` |

Колония при сшиве — город нулевой ступени ближайшей державы своей расы, со всеми её друзьями и врагами; мировоззрение державы передаётся переселенцам. Источник угроз в `d` клетках — в днях пути по `SEAM.days`, дальше `SEAM.raidDays` не ходит.

**Где это используется.** `world/site.js makeSite(cfg)`: если в настройках игры есть `cfg.cell`, участок собирается из плана (`siteFromRegion`), размер карты и сезон высадки — из меню, ползунки воды, леса и гор не действуют. На экранах мира щелчок по клетке показывает её строку в карточке (`ui/atlasView.js cellText`). Кампания строит из той же клетки свою небольшую карту стоянки (`campaign/camp.js`, размер — `data/camp.js`).

## Проверки

Числа цепочек подбирает `node tools/chain-balance.mjs [сиды] [--full]`: множитель выхода каждого блага, при котором постройкам меньше всего не хватает (по цене) и меньше простаивают, недалеко от таблицы; `--full` — проверка полной историей на других сидах. Первый подбор (октябрь 2026): брёвна ×2, уголь ×1,44, металл ×1,44 — нехватка на полной истории 18% → 12%, простой 15% → 9%; третий круг уже подгонял под свои миры и не принят. Что осталось — не числа, а места: соли и горшков не хватает там, где в державе нет солеварни и гончарни; постройку, чьё жёсткое сырьё в державе никто не делает, город почти не ставит.

Экономику городов проверяет `npm run economy` (`tools/economy-check.mjs`, входит в `npm test`): море и лодки, эффекты по работе, склады и казны, покупка между городами, подати, рынок каравана и паёк.

Мир проверяют `npm run world` (полигон дел мира: главарь, логово и двор державы перед городом и соседями на земле «Заселения мира», [Проверки](TESTING.md#полигон-дел-мира)), `npm run atlas` (суша, история, эпический мир, бедствия, союзы, летопись; печатает доли руд), `npm run atlas:save`, `npm run seam`, `npm run leaders`, `npm run kingdom`, `npm run polity`, `npm run mind:check`, `npm run demography`, `npm run build:check`, `npm run fisc`, `npm run land`, `npm run settle`, `npm run questhand`; замер эпического мира — `npm run atlas:epic`. Все команды — в [Проверках](TESTING.md).
