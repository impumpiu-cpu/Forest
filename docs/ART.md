# Картинки Forest

Карты рисуются в одном из двух оформлений:

- **Картинки** — рисунки из `src/art/**/*.svg`, демонстрационный режим, по умолчанию;
- **Схема** — прежние значки: круги, буквы, квадраты; тестовый режим.

Переключатель — кнопка ◈ у кнопок зума на каждой карте или клавиша **G** (П) на любом экране; выбор помнит браузер (`forest.skin`). Оформление только читает мир: симуляция, сиды и проверки от него не зависят.

Если у вещи ещё нет картинки, в режиме «Картинки» она рисуется схемой. Поэтому любую картинку можно убрать, и игра не сломается.

## Как заменить картинку

1. Найдите файл в `src/art/` (список — в витрине, `npm run gallery`, подпись над каждой картинкой — путь без `.svg`).
2. Откройте его в Inkscape, Figma, Illustrator или в текстовом редакторе, поправьте, сохраните **под тем же именем** как «Обычный SVG» (Inkscape: *Сохранить как → Plain SVG*).
3. Обновите страницу игры или витрины. `tools/serve.mjs` (его запускает `Forest.bat`) собирает `src/art/sprites.js` заново, когда игра его просит. Без сервера: `npm run art`.
4. `npm run art:check` скажет, если в файле что-то не по договору.

Новая картинка для вещи, у которой её не было, — новый файл с нужным именем (раздел «Имена» ниже).

## Договор SVG

- `viewBox` задаёт поле рисунка. Почти везде `0 0 100 100`; постройки — по форме участка (`0 0 100 100` для 2×2, `0 0 150 100` для 3×2…).
- Читаются: `path`, `circle`, `ellipse`, `rect` (и `rx`), `polygon`, `polyline`, `line`, группы `g`; `fill`, `stroke`, `stroke-width`, `opacity` — атрибутами или в `style`; `transform` любого вида. Пропускаются (art-check об этом скажет): текст, градиенты, картинки, фильтры, маски, `defs`.
- Без обводки контура вещь теряется на траве: контур — `stroke="ink"`, обычно `stroke-width` 4–5 на поле 100. Линии тоньше 1 пикселя на экране игра утолщает (до 2,5 раза), чтобы маленькая картинка не рассыпалась.

### Цвета

Цвет — либо `#hex`/`rgb()`, либо **слово из `src/art/palette.js`**. Слова дают одной картинке разные цвета:

| Слово | Что подставляет игра |
|---|---|
| `skin` | кожа расы (`look.skin` в «Расах») |
| `hair`, `beard` | волосы: свои у расы, у людей, полуросликов, дварфов, великанов — разные у разных существ |
| `cloth`, `faction` | цвет стороны: одежда пешки, лицо щита, знамя, крыши города (цвет державы) |
| `armor` | цвет надетой брони (`color` предмета) |
| `metal` | металл клинка по материалу (бронза, железо, сталь, мифрил…) |
| `fur`, `hide` | шкура зверя (`look.color` вида) |
| `ink`, `light`, `shade`, `shine` | контур, белки и клыки, плоская тень и блик |
| остальные (`wood`, `stone`, `roof`, `thatch`, `leaf`, `fire`…) | материалы, одинаковые везде; меняются в `palette.js` |

### Ступени размера — `class`

| class | Когда видно |
|---|---|
| — | всегда |
| `small` | только на самом малом размере (знак, жетон) |
| `figure` | со средней ступени (пешка, город поближе) |
| `detail` | только крупно (лицо, узоры, мелочи) |

### Флаги — `class`

Любое другое слово в `class` — флаг: часть рисуется, только когда игра его дала; `no-<флаг>` — только когда не дала.

- Тела: `coat` (шуба), `jerkin` (куртка), `plate` (любая латная), `lamellar`, `scale`, `mail`, `wicker` (узор лат), `heavy` (наплечники от железа и выше).
- Звери: `up` (стоит), `rest` (лежит, спит), `tame` (ручной).
- Постройки: `done` (готова), `build` (строится). `lit` (работает: дым, огонь) и `ruin` — заготовлены, игра их пока не даёт.
- Города: `walls`, `stone` (каменные стены), `port`. Столица — не флаг: над городом ставится отдельный значок `map/crown`.

### Точки — `data-anchor`

Кружок с `data-anchor="имя"` не рисуется: это место, куда игра ставит другое.

- `bodies/*`: `head` (круг головы — голова вписывается в него), `hand` (правая рука), `off` (левая — щит), `back` (заплечное).
- `held/*`: `grip` — рукоять, совпадает с рукой тела.
- `back/*`: `strap` — где вешать.

## Имена

| Папка | Файл | Чья картинка |
|---|---|---|
| `heads/` | `<id расы>.svg` | голова расы или человекоподобного чудовища; вид может назвать свою в таблице: `look.head` |
| `bodies/` | `common`, `slim`, `stout`, `small`, `broad`, `huge`, `robe`, `bones`, `hand` | тела пешек; чьё какое — `render/art/pawn.js BODY`, вид может назвать своё: `look.body` |
| `held/` | `<form предмета>.svg` (`sword`, `spear`, `shield`…) | что в руках; нет формы — по `glyph` |
| `back/` | `<form>.svg` (`quiver`, `basket`, `pan`) | за спиной |
| `marks/` | `alarm`, `anger`, `sleep`, `token` | штрихи состояния у головы; подложка жетона |
| `beasts/` | `<look.shape>.svg` | звери и чудовища (`look.shape` вида) |
| `buildings/` | `<id постройки>.svg` | постройки локальной карты |
| `towns/` | `<народ>-<ступень>.svg` (`humans-2`; id народов — `elves`, `dwarves`, `humans`, `orcs` — Зеленокожие) | города мира |
| `parties/`, `lairs/`, `map/` | см. витрину | отряды, логова, прочие знаки карты мира |

## Пешки

Существо с `look.shape: 'person'` — пешка: тело (`bodies/`) в цвете стороны, голова расы, броня по надетому предмету, оружие в руках, заплечное. Повёрнута влево или вправо — куда шла (`faceX`). Спит или ранена — лежит. Рядом с головой — штрихи: синие — бежит, оранжевые — бьётся, z — спит.

Пешка ниже 18 пикселей (обычное приближение) превращается в жетон: голова на круге цвета стороны.

## Устройство

- `src/art/**/*.svg` — источники; `src/art/sprites.js` — из них (не править).
- `tools/art-build.mjs` — сборка; `tools/art-check.mjs` — проверка (в `npm test`).
- `src/render/skin.js` — переключатель; `src/render/art/` — художники: `sprite.js` (рисунок и кеш), `pawn.js`, `beasts.js`, `buildings.js`, `world.js`; `index.js` — что рисует каждая карта; `coverage.js` — сколько игры уже с картинкой (art-check, витрина); `showcase.js` — что показывает витрина.
- Прежние значки остались на месте в `render/renderer.js`, `ui/atlasOverlays.js`, `ui/campaignView.js`; перед каждым стоит вызов художника картинок.
- `gallery.html`, `src/app/gallery.js` — витрина: живая локальная карта и все картинки по размерам.
