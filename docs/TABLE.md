# Таблицы, мировоззрение, главари и новое меню

Рабочий документ ветки `Table`. Цель ветки — навести порядок в структуре данных и в запуске, заложить основу для асимметрии рас (следующая большая задача). Первый круг вопросов закрыт: решения записаны в каждом разделе, план этапов — в конце. **Работа начинается по команде.**

Условные обозначения: ✅ есть в коде · 🟡 есть частично · ⬜ нет.

## 1. Репозиторий как база данных

### Что есть сейчас

Почти всё, что описывает мир, лежит в справочниках `src/data/*.js` (≈60 файлов), а системы только читают их. Но справочники неоднородны: `Registry` с id, обычные массивы, матрицы (`relations.js`), наборы констант (`DIPLOMACY`, `OPINION`), строки с функциями (`name: m => …`). Сведения об одной сущности разнесены по файлам: раса — это `races.js` + `balance/creatures.js` + `peoples.js` + строка в `relations.js`.

### Решения

- **Слой описания поверх кода**, данные остаются в `.js` вместе с комментариями. Перенос в JSON/SQLite — не сейчас.
- **Схемы таблиц** — `src/data/schema/`: для каждой таблицы источник, ключ, столбцы с типом и границами, ссылки на другие таблицы, вычисляемые (только для чтения) столбцы. Строки с функциями показываются как «формула» и не правятся.
- **Экран «Настройки → Таблицы»** строится по схемам: список таблиц, таблица, сортировка, фильтр, подсказка столбца.
- **Правки — только для экспериментов**: слой `overrides` хранится в браузере и выгружается файлом; «запекания» в исходники нет. Слой входит в сохранение мира и в его хеш: мир, сотворённый с правками, без них загрузится с предупреждением.
- **Одна сущность — одна строка на экране**, файлы остаются раздельными: «Раса» = `races.js` + `creatures.js` + народ из `peoples.js`.
- Выгрузка любой таблицы в CSV/JSON.
- `npm run check-data` берёт границы и ссылки из схем.

## 2. Оружие: форма × материал × качество + клеймо

### Что есть сейчас

Предмет = форма (`forms.js`) × материал (`materials.js`) × качество (`quality.js`, +0…+4). У формы есть тип удара (`blow`: колющий / рубящий / дробящий) и защита по типам (`vs`).

### Решения: клеймо мастера

Таблица `data/balance/marks.js`. Клеймо — свойство народа-кузнеца, а не формы.

| Клеймо | Народ | Свой тип |
|---|---|---|
| Эльфийская работа | эльфы | колющий |
| Орочья работа | орки | рубящий |
| Гномья работа | гномы | дробящий |
| — | люди | нет: середняк, ни бонусов, ни штрафов |

- **Бонус крупный** (черновик: +25%), сильнее одной ступени качества (+15%). Действует **только на свой тип**: урон этого типа и защита от этого типа.
- **Одно клеймо на вещь**, двух не бывает.
- **«Чужая» форма сохраняет свою природу и получает долю своего типа.** Гномий меч — по-прежнему меч (рубящий), но в его ударе появляется дробящая часть, и она усилена клеймом: «заточенный лом не перестаёт дробить». Технически: удар клеймёной вещи делится на тип формы и тип клейма (черновик: 70 / 30; для формы своего типа — 100% и полный бонус). Защита (`vs`) клеймёной брони и щита растёт против типа клейма.
- **Клеймо ставится только при ковке в городе** народа-мастера (кузня города в кампании). Ни поселение, ни караван клейма не ставят, даже если в них есть кузнец этой расы. Купить у торговца или взять трофеем — можно.
- **Городская ковка — не ниже +1** (добротное и выше), чтобы ковать в городе было выгодно и с клеймом, и без него (у людей).
- Цена: множитель клейма поверх цены качества; `npm run items` и `npm run arena` учитывают клейма.

**Числа (этап 5):** бонус 25%, доля типа клейма в «чужой» форме 30%, городская ковка +1, в городе от ступени 2 — +2. Всё в таблице «Правила клейма».

## 3. Мировоззрение: компас ±5

### Что есть сейчас

Оси уже есть, но в шкале ±3 и без столиц (`data/values.js`): **порядок** (закон ↔ хаос) и **милосердие** (добро ↔ зло). Раса задаёт точку и разброс, пешка получает свою точку около неё; это влияет на мнение, помощь раненому, реакцию на продажу пленных.

### Решения

**Три слоя, всё обрезается по ±5:**
1. **Раса** — центр на компасе ±5.
2. **Столица (держава)** — при основании: раса + отклонение до ±3 по каждой оси. Каждый народ приходит двумя группами — значит две державы одной расы с разным характером.
3. **Пешка** — столица + отклонение до ±3. Без мира (полигон) роль столицы играет раса.

Отклонение — «колокол»: крайние значения редки, но возможны. **Белые вороны задуманы**: добрый народ может дать злую пешку, гном может быть хаотичным. Под них позже — свои механики отношений.

**Компас ползает со временем:**
- держава: долгая война, набеги, резня городов → к злу; долгий мир, торговля → к добру; распад и смены столицы → к хаосу; долгое правление одной столицы → к закону;
- пешка: спасли, перевязали, поделились → к добру; предательство, пытки, продажа пленных рядом → к злу; служба, присяга, порядок совета → к закону; побег, бунт, жизнь вне закона → к хаосу.
Скорость — малая, правила — в таблице сдвигов.

**Ярлык клетки на карточке** — девять клеток классического компаса, порог, например, |значение| ≥ 2:

| | **Хаотичный** (≤ −2) | **Нейтральный** | **Законопослушный** (≥ +2) |
|---|---|---|---|
| **Добрый** (≥ +2) | хаотичный добрый | нейтральный добрый | законопослушный добрый |
| **Нейтральный** | хаотичный нейтральный | истинно нейтральный | законопослушный нейтральный |
| **Злой** (≤ −2) | хаотичный злой | нейтральный злой | законопослушный злой |

Рядом остаются две оси числами.

**Расстановка рас** (решение по оркам: орда → −2 в хаос; остальное — текущее ×5/3, правь в таблице):

| Раса | Закон ↔ хаос | Добро ↔ зло | Ярлык |
|---|---|---|---|
| Гномы | +5 | 0 | законопослушный нейтральный |
| Тёмные эльфы | +3 | −3 | законопослушный злой |
| Полурослики | +2 | +3 | законопослушный добрый |
| Лесные эльфы | +2 | 0 | законопослушный нейтральный |
| Люди | 0 | 0 | истинно нейтральный (самый широкий разброс) |
| Орки | **−2** | −2 | хаотичный злой |
| Великаны | −2 | +2 | хаотичный добрый |
| Тролли | −2 | −2 | хаотичный злой |
| Гоблины | −3 | −2 | хаотичный злой |
| Огры | −3 | −3 | хаотичный злой |
| Гноллы | −2 | −5 | хаотичный злой |
| Некроманты | +2 | −5 | законопослушный злой |

**Где сказывается:**
- **державы**: стартовое отношение = память рас + близость на компасе; две державы одной расы при большом расхождении могут враждовать и раскалываться (`SCHISM` уже есть); злые охотнее идут в набег, законопослушные реже рвут мир;
- **внутри группы**: `OPINION` пересчитывается под ±5, кроме штрафа за разрыв появляется плюс за близость;
- **взаимопомощь**: перевязать чужака, поделиться едой, вступиться — пороги по оси добра; держать слово, слушаться совета и дозора — по оси закона.

## 4. Основа для асимметрии: постройки, расселение, технологии

### Решения

Полноценных «технологий» (изобретений, дерева) в этой ветке нет — это следующая стадия. Здесь закладываем основу таблицами:

- **Технологии — таблица-список**, `data/tech.js`: каждая строка просто включает уже существующие уровни материалов, формы, рецепты и постройки (`opens`).
  - **Доступность — по расе**: что раса вообще может знать (`races`).
  - **Открытие — по державе**: что конкретная держава уже знает (`a.realms[].tech`). Пока открытие — простое правило (эпоха, ступень городов); как держава к технологии приходит, решим в асимметрии.
- **Постройки станут расовыми**: в `townBuildings.js` поле `peoples` уже есть — в схеме таблицы делаем его видимым и правимым, чтобы потом развести постройки по расам.
- **Особенности расселения** (плотность: 60 тыс. гномов занимают меньше места, чем 15 тыс. эльфов или орков) — столбец в таблице народов, заполняем в асимметрии.
- **Бафы/дебафы рас за территорию** — формат таблицы раса × биом → эффекты; числа — в асимметрии.

**Караван — это караван.** Он ничего не изобретает: у него есть только база, остальное покупается в городах. Список того, что каравану доступно (постройки стоянки, рецепты), выносится в таблицы для экспериментов.

## 5. Новое меню и `Forest.bat`

### Решения

- Рядом со старым запуском — новый; **старый (`start.bat`, `index.html`) остаётся техническим полигоном**.
- `Forest.bat` — тот же сервер (`tools/serve.mjs`), открывает `forest.html`; новая оболочка — `src/app/`, ядро общее.
- **Мелькание старого блока** (`#explain` и старый текст `#worldInfo` в `index.html` видны до загрузки модулей) — исправляем в этой ветке.

**Главное меню** (названия пока такие):

**1. Создать землю** — только земля и климат, без народов и истории.
- Генерация: плиты, рельеф, море, температура, ветры, осадки, реки, биомы.
- **Инструменты первой версии — правка базы, а не результата**:
  - *терраморфинг*: сдвинуть плиты, поднять/опустить плиту или участок;
  - *климат*: температура полюсов и экватора (и, вероятно, влажность).
  После правки алгоритмы заново считают всё, что ниже по цепочке: залегание руд, реки, озёра, биомы.
- Сохранить землю — отдельный тип записи в библиотеке и файлом.

**2. Заселение мира** — загрузить землю и вести историю вручную. **Эпох нет.**
- Пользователь вносит «возмущение»: **Расы** (какие и где высадить), **Монстры** (кого и куда; ручное добавление логов), **Катаклизмы** (до трёх — основа эпика).
- Затем запускает время: **+5 · +10 · +25 · +50 · +100 лет**; смотрит результат, снова вмешивается или мотает дальше. Летопись сбоку.
- Тонкая настройка карты и правил — из таблиц.
- Сохранить мир с обитателями и летописью.

**3. Кампания** — загрузить живой мир, выбрать столицу, поход за артефактом, который остановит грядущий катаклизм. **Локальная карта (поселение) — только внутри кампании**, отдельной кнопки нет.

**4. Быстрый старт** — нынешняя «Эпическая кампания» одной кнопкой: **видимый случайный сид** (с кнопкой «случайный» и копированием) → земля → история → выбор столицы → поход.

**⚙ Настройки** — раздел **Таблицы** (раздел 1) и общие параметры (подробность летописи, скорость, автосохранение).

## 6. Главари логов (новое)

### Что есть сейчас

- Логово (`atlas/lairs.js`) — точка с хозяином-видом, силой и возрастом; в «диффузном» режиме оно кормится, растёт, плодит новые логова, дерётся с соседями и шлёт набеги.
- В 30 лет логово становится древним (`ANCIENT_YEARS = 30`, летопись: «о нём слагают страшные сказки»).
- У катаклизма есть босс: существо, выращенное за пределы своего вида (`agents/special.js` `bossSpecial`), его логово не падает, пока он жив, и он ведёт набеги.
- По карте уже ходят «отряды» (`atlas/parties.js`): набег из логова, выводок, армия державы, дракон в полёте — с путём, днями и отрисовкой.

### Предложение

**Главарь** — именной лидер древнего логова, который переводит логово из диффузного режима в дискретный.

- **Появление**: логово старше 30 лет (древнее) получает шанс в год родить главаря; один главарь на логово. Летопись: «В логове … поднялся главарь — …».
- **Статы**: как у босса катаклизма, но слабее — выращен за пределы своего вида на меньшую величину (`bossSpecial` с меньшим `add`/`cap`). Имя, мировоззрение, ценности — как у пешки. Главарь катаклизма остаётся ступенью выше.
- **Пешка на карте мира**: главарь — отряд в `parties`, его путь виден наравне с армиями держав (свой значок и цвет).
- **Думает и планирует**: у главаря есть цели, а не случайные набеги:
  - *набег* на слабый город поблизости (как сейчас, но цель выбирает он, по силе и добыче);
  - *расширение*: увести выводок и основать дочернее логово, которое ему подчиняется;
  - *война с соседним логовом* или *подчинение* слабого логова (растёт «владение» главаря);
  - *уход и смена логова*, если его теснят;
  - позже — *сделки*: только у видов с разумом (`mind: 'sentient'`), с державами по мировоззрению.
- **Смерть главаря**: убит в бою, армией державы, героем кампании — логово возвращается в диффузный режим и слабеет; летопись пишет, кто его убил.
- **Кампания**: главарь — именной противник по дороге, у него есть трофей; его логово можно найти по слухам в городах.

**Решения**
- 6.1. Главарь (вожак) может появиться у **любого** логова, и у зверей тоже: вожак волчьей стаи, старый медведь.
- 6.2. Потолок — **30 главарей** на мир одновременно (число в таблице, подберём по скорости и по виду карты).
- 6.3. Главарь **стареет и умирает**; на его месте поднимается новый — с новым именем и новыми статами.
- 6.4. Когда поднимается катаклизм: **50/50** — новый босс или один из живых главарей; из главарей выбирается подходящий (по силе и виду, правило — на этапе 6).

## 7. Материалы на выбор и допуск рас (сделано — этап 7а)

Запрос от 23.10: разрешённые материалы для рас — таблицей, чтобы сразу запрещать расе тот или иной материал; материалы сгруппировать так, чтобы рецепт и постройка просили «материал на выбор» (любой камень, любой металл, любую древесину), а уже выбранный конкретный материал влиял на прочность, внешний вид и — для своей расы — давал своё.

### Что есть сейчас

- **Ресурсы склада** (`data/resources.js`) — по одному на вид: одна `wood`, один `stone`, металлы отдельно (`bronze`, `iron`, слитки серебра, мифриловая руда). Рецепты и постройки поселения (`data/recipes.js`, `data/buildings.js`) просят их по имени: `{wood: 18}`, `{stone: 18, iron: 2}`.
- **Материалы вещей** (`data/balance/materials.js`) уже сгруппированы классами (`class`: wood, bone, hide, metal, cloth…): форма вещи (`forms.js` `of`) берёт любой материал своего класса — это и есть «материал на выбор», но только для вещей, и у класса `wood` один материал.
- **Породы камня** уже есть в геологии мира (`data/geology.js` `ROCKS`: базальт, андезит, гранит, гнейс, кристаллический сланец, песчаник, известняк, глинистый сланец) — у каждой клетки карты мира своя порода, но на локальную карту и в склад она не попадает: там просто «камень».
- **Пород деревьев** нет: лес на карте — один `forest`, древесина — одна.
- **Допуска рас к материалам** нет; есть только технология державы на металл (этап 7) и клеймо народа (этап 5).

### Предложение

**1. Семейства и члены.** Ресурс склада становится *членом семейства*:
- `камень` → породы из `ROCKS` (тот же список, что в геологии мира: из какой породы клетка, такой камень и добывают);
- `древесина` → породы деревьев (новая таблица: сосна, ель, берёза, дуб, ясень, лиственница, …, и особые — например, **святое дерево** эльфийских рощ);
- `металл` → бронза, железо, сталь (позже), серебро, мифрил;
- (по мере надобности) `кость`, `шкура`, `ткань`.
Рецепт и постройка просят семейство: `{stone: 18}` значит «18 любого камня», `{wood: 6}` — «любой древесины»; где нужно конкретное — просят член (`{oak: 4}`, `{iron: 2}`). Работник берёт со склада то, что есть, по правилу выбора (сначала худшее, что годится? лучшее? своё? — вопрос 7.3).

**2. Член семейства влияет на результат.** У каждого члена — множители, как сейчас у материалов вещей: прочность, вес, тепло, цена, цвет. Для построек: стена из гранита крепче, чем из песчаника; цвет постройки на карте — цвет породы. Для вещей: древесина становится материалом класса `wood` со своими множителями (дубовая палица крепче сосновой), камень — материалом пращи и (позже) молотов.

**3. Допуск рас — таблица раса × член семейства** («Материалы рас»), три значения:
- *можно* (по умолчанию);
- *нельзя* — раса этот материал не использует вовсе (не берёт со склада, не куёт, не носит; например, эльфы — железо? гномы — святое дерево?);
- *мастерство* — раса работает его по-особому: свои множители поверх общих. Пример из запроса: **эльф из святого дерева** делает оружие не слабее стального — у святого дерева для эльфов `dmg`, `dur` как у стали, для остальных — как у хорошего дерева (растопка, рукоять, молоток — им всё равно, чья древесина).

**4. Где это видно.** На локальной карте: из какой породы камень (по клетке мира), какие деревья растут (по биому), что лежит на складе по членам. На карте мира — пока только постройки городов (каменные стены из местной породы). В кампании — вещи из святого дерева у эльфийских кузнецов.

### План работ (черновик)

1. Таблицы: «Породы камня» (из `ROCKS` + множители), «Породы деревьев» (новая, с биомами, где растут), «Металлы» (из материалов), семейства; «Материалы рас» (можно / нельзя / мастерство с множителями). Только данные и экран — игра пока не меняется.
2. Склад и добыча на локальной карте: камень по породе клетки, древесина по деревьям биома; рецепты и постройки просят семейство, работник выбирает член; сохранения старых игр переводятся (старый `wood` → «древесина вообще»).
3. Влияние членов: прочность и вид построек, множители вещей из древесины и камня; цена.
4. Допуск рас: «нельзя» и «мастерство» в ремесле, снаряжении, торговле; святое дерево эльфов.
5. Карта мира и кампания: местная порода у городов, кузни и рынки по допуску рас.

Это большой кусок, он трогает склад, рецепты, постройки, торговлю и сохранения поселения; предлагаю делать его отдельным этапом после этапа 7 (перед «Создать землю») или вынести в начало асимметрии — вопрос 7.1.

### Вопросы

- 7.1. Когда: сразу (этап 7а, до «Создать землю»), или первым шагом асимметрии?
- 7.2. Сколько пород деревьев на старте и какие особые? Предлагаю 6 обычных (сосна, ель, берёза, дуб, ясень, лиственница) и 2 особых (святое дерево — эльфийские рощи; железное дерево — джунгли?).

### Этап 3 · правки таблиц для экспериментов (версия 0.62.0)

- **Как устроено.** Правка пишет значение прямо в определение, которое читает игра (вид, материал, строку матрицы отношений, параметр дипломатии), а число кода запоминает; сброс возвращает его. Исходники не трогаются: без слоя правок игра такая, как написано в коде. Где лежит значение у таблиц-копий, говорит схема (`target`): раса пишется в свой вид, «На стоянке» — в `CAMP_FX`, матрица — в `RELATIONS`. После правки «Форм» и «Материалов» предметы пересобираются (`rebuildItems`, определения сохраняют себя — на них ссылаются сохранения).
- **Код.** `src/data/schema/layer.js` — слой как данные, подпись, отметка мира и текст предупреждения; `src/data/schema/edits.js` — запись, проверка, сброс, применение целого слоя; `src/ui/tableEdits.js` — хранение в браузере (`forest.tables`) и в файлах, применение при старте. Обе страницы (`forest.html` и `index.html`) подключают его первым, поэтому правки уже на месте, когда загружаются системы и делается игра или мир.
- **Что правится.** Всё, кроме вычисляемого (Предметы (итог), Действие SPECIAL, КС-поправка, «Можно собрать в поле»), ключей, формул и столбцов-связок из других таблиц (народ и эпоха у расы — правятся в «Народах мира»). Классы материалов и форм не правятся: они меняют сам набор предметов. Постоянные числа кода (возраст древнего логова — `ANCIENT_YEARS`) видны, но не правятся: их сделаем параметрами, когда до них дойдёт этап.
- **Проверка при вводе.** Каждое значение проверяется по своему столбцу (пределы, существующие id, слова из списка, вид значения у параметров); неверное не записывается, причина видна в строке под панелью. Значение, равное числу кода, — не правка.
- **Экран.** Над таблицами — панель правок: «Правка: вкл/выкл», счётчик, «Выгрузить правки» (`forest-tables.json`), «Загрузить правки…» (заменяют нынешние), «Сбросить таблицу», «Сбросить всё», список всех правок «было → стало» со ссылкой на таблицу и ↺ у каждой. В режиме правки правимое подчёркнуто; щелчок открывает поле: число, да/нет (щелчок переключает), выбор из списка для слов и ссылок, строка для наборов («forest 1, meadow 0.5»), пределов SPECIAL («S 1-10, P 3-11»), сдвигов («S +1, I -1») и списков. Enter или уход с поля — записать, Esc — отменить. Правленая ячейка — в рамке, с подсказкой «в коде: …» и ↺. Таблицы с правками отмечены точкой в списке. Счётчик правок виден в шапке обоих меню.
- **Мир и игра помнят правки.** Новый мир (`a.tables`) и новое поселение (`w.tables`) получают отметку: подпись, число и сам слой. Отметка сохраняется вместе с ними и входит в хеш мира (у поселения — во весь сохранённый мир). Мир без правок — без отметки, такой же, как раньше. Открытый мир или загруженная игра, созданные под другими правками, предупреждают плашкой сверху и в строке статуса («Мир создан с правками таблиц (6 правок), а сейчас правок нет: дальше всё идёт по исходным числам»). В библиотеке миров у таких — «с правками таблиц (N)».
- **Проверено.** `tools/check-tables.mjs` в `npm test`: правка доходит до вида, матрицы и предметов; неверные значения, вычисляемое и постоянное отклоняются; мир с правками несёт их и меняет хеш, без правок — нет; сброс возвращает числа кода; слой применяется заново. В браузере: правка ячеек всех видов, ошибка ввода, выгрузка и загрузка файла, сохранение после перезагрузки, быстрый старт с правками и предупреждение при открытии этого мира без них.
- **Чего пока нет.** Балансные прогоны и арена (`npm run balance`, `arena`) идут по числам кода: правки — только в браузере. Если понадобится, добавим им ключ `--tables файл.json`.

### Этап 4 · мировоззрение ±5 (версия 0.63.0)

- **Компас** (`data/values.js`): оси «закон ↔ хаос» (`order`) и «добро ↔ зло» (`mercy`), каждая ±5 (`AXIS_MAX`). Точки рас — по таблице раздела 3, орки −2 в хаос; некромант — +2 / −5. Поле `spread` у рас убрано: разброс теперь один для всех — `ALIGN`.
- **Три слоя.** Держава при основании получает точку в пределах ±3 (`ALIGN.realm`) от точки расы; держава, отколовшаяся в расколе, — от точки той, от которой откололась. Пешка — в пределах ±3 (`ALIGN.pawn`) от точки своей державы: члены каравана — от столицы похода, наёмники и спутники — от державы города, поселенцы на клетке мира — от соседней державы своей расы (`seam/cell.js` кладёт её точку в план клетки). На полигоне и для прочих (пленные, освобождённые, переселенцы другой расы) центр — раса. Каждый бросок — «колокол» из трёх случайных; держава тянет свой поток случайных чисел, поэтому история мира от этого не сдвигается.
- **Ярлык** — клетка классического компаса, от ±2 по оси (`ALIGN.cell`): «законопослушный добрый», «хаотичный злой», «истинно нейтральный», с родом и числом. На карточке поселенца — ярлык и обе оси числами; в списке столиц кампании — ярлык державы («законопослушные злые»), числа — в подсказке.
- **Отношения держав.** Память, с которой держава встречает другую и к которой отношение возвращается каждый год, = память рас + близость взглядов (`compassFeeling`): +0,5 в одной точке, до −1 на расстоянии 10 и дальше. Две державы одной расы с далёкими взглядами начинают холоднее — основа для вражды и раскола.
- **Мнение пешек** (`data/relations.js` `OPINION`, под новую шкалу): разрыв по добру ≥5 → −1, по закону ≥6,5 → −0,5, близость (≤1,5 по обеим осям) → +0,5. Пороги взаимопомощи — тоже в таблице: перевязать того, кого не выносишь, — от добра 1,7; пустить на ночлег неприятного — от 3,3.
- **Компас ползёт** (`ALIGN_DRIFT`). Держава каждый год: каждая война −0,12 к добру, мирная торговля +0,04; 30 лет под одной столицей +0,02 к закону, сожжённая столица −1 к закону; и всё время её тянет назад к точке основания (5% разрыва в год) — долгая война держит её примерно на 2,4 ниже, мир — на 0,8 выше. Пешка: перевязанный +0,2 к добру (умиравший — +0,4), не милосердные, видя продажу пленного, −0,15, бежавший пленный −0,5 к закону, каждый совет +0,01 к закону, но не дальше 1,5 от точки рождения.
- **Таблицы.** Пределы осей в схеме берутся из `AXIS_MAX`; новая таблица «Мировоззрение» (группа «Отношения») — все числа `ALIGN` и `ALIGN_DRIFT`, правятся как остальные.
- **Проверено.** `tools/align-check.mjs` в `npm test` (`npm run align`): ярлыки, пешка в ±3 от центра и в ±5 по компасу, сдвиги в пределах, близость взглядов, у держав свои точки и разные у двух держав народа, память держав учитывает взгляды. `npm test` зелёный; сцена ссоры в логических проверках (T26) теперь сама задаёт двум поселенцам далёкие взгляды, а не полагается на брошенные. Короткий балансный прогон (6 сидов × 20 дней) — как до этапа: все живы, 13 жителей, 11–12 построек. Победы союзов над бедствиями на 11 эпических мирах — 4 против 5 до этапа (сначала, с весом близости ±1/−1,5, было 2; вес уменьшен до +0,5/−1).
- **Заметно в мирах.** Державы, которые много воюют, сползают к злу: гномьи державы долгой истории нередко «законопослушные злые». Если это слишком сильно — уменьшить `drift.realm.war` в таблице «Мировоззрение».

### Этап 6 · главари логов (версия 0.65.0)

- **Кто и когда.** Древнее логово (с 30 лет; возраст теперь правится — `LAIR_AGE.ancient` в «Правилах логов») любого вида, кроме драконьего (дракон сам один), усадьбы вампира и логова босса бедствия, раз в год с шансом 8% поднимает главаря; одновременно в мире не больше 30 (`LEADER.max`). Звери получают **вожака**, полуразумные и разумные — **главаря** (у разумных — имя своей расы и прозвище: «Хракк Тихий»), нежить — **владыку**, демоны — **князя**. Главарь — существо своего вида, выросшее за его пределы на +2…5 по Силе, Выносливости и Ловкости (у босса бедствия +6…12).
- **Из поля в пешку.** Логово с главарём больше не шлёт набегов и выводков само. Каждую весну главарь с шансом 25% выбирает план и ведёт своих отрядом по карте мира, как войско (`atlas/parties.js`, вид `leader`; на карте — пятиконечная звезда, у самого логова — серебряное кольцо, к логову-господину от данника тянется тонкая линия):
  - **набег** на город в досягаемости (×1,5 дальности набега племён; у вожака зверей вес набега ×0,35 — зверь больше охотится, чем грабит); удача кормит логово, разбитый набег может стоить главарю жизни (25%);
  - **выводок**: уводит молодых и основывает дочернее логово — его данника;
  - **подчинение**: слабейшее соседнее логово (до трёх территорий, вдвое слабее с запасом ×1,3) становится данником и каждый год отдаёт 4% силы господину;
  - **война** на соперника: побеждённый остаётся с 55% силы или гибнет.
- **Конец главаря.** Стареет и умирает (20–50 лет правления) — со следующего года новый поднимается с шансом 50% и с новым именем и статами; гибнет в разбитом набеге или бою, вместе со своим логовом, от рук каравана. Данники господина без главаря освобождаются.
- **Бедствие.** С вероятностью 50% (`CAL.fromLeader`) бедствие поднимается на живом главаре: среди видов бедствий своей эпохи — самый сильный главарь, чьё логово годится (после дикой эры — в досягаемости городов, как и обычное бедствие). Он сохраняет имя и свой титул («Вожак Хромой»), растёт до силы босса, летопись говорит: «на него пал выбор бедствия».
- **Кампания.** Отряд главаря у каравана — противник с главарём во главе (на локальной карте — именной, усиленный; `boss` противника). Стоянка во владениях логова с главарём опаснее: шанс ночной стычки ×1,6, сила ×1,3, и ведёт их главарь. Победа над таким отрядом убивает главаря: «… пал от рук каравана», строка в летописи мира. В городах рассказывают о ближайшем главаре, однажды о каждом.
- **Летопись.** Подъём, смерть, подчинение, дочерние логова, разбитые соперники — обычные строки; выход в набег, дань, отбитые атаки — мелкие. Строк о главарях за историю — около 700–900 на малом эпическом мире.
- **Таблицы.** Все числа — `LEADER` в «Правилах логов» (`leader.*`), правятся.
- **Проверено.** `tools/leaders-check.mjs` в `npm test` (`npm run leaders`): главари только в подходящих древних логовах и не больше 30; уходят от старости, в бою, с логовом; сильнее своего вида; у данников живой господин; логово с главарём не шлёт набегов само; бедствие берёт главаря боссом (в трёх мирах — четыре раза); отряд главаря у каравана — именной противник, разбитый — мёртв. `npm test` зелёный.
- **Как изменился мир** (малые эпические миры): набегов на города на ~60% больше, население к концу истории на 5–9% меньше, логов чуть меньше (главари разоряют соперников). Поход: с короной 90% (было 85%), гибнет 2,4 из восьми (было 3,0) — на границе цели; первая версия (главари ходили чаще и разоряли логова до 35%) давала 93%, поэтому главари теперь реже выходят (25% в год, набег ×0,7), а побеждённое логово сохраняет 55% силы. Сценарий союзов в `atlas-check` — снова на сиде 4; союз валит босса в 3 мирах из 12.

Земля даёт деревья своих биомов и камень своей породы (клетка мира, иначе своя порода полигона), поочерёдно по весам — без случайных чисел. Старые сохранения переводятся сами.
- **Выбор**: костёр и растопка берут худшее, ремесло и стройка — лучшее из того, что раса может делать. Деревянная вещь помнит, из чего она («дубина (дуб)», «лук (святое дерево, работа мастера)»); постройка — из какого камня и дерева (видно в карточке, а склад в подсказке строки показывает, что из чего).
- **Допуск в игре**: рецепт не берётся, если раса не может делать его материал; пешка не рубит/не копает, если ничего из здешнего ей нельзя; снаряжение с «табу» не надевается, с «не делает» — надевается, но помечается «грязн.».
- **Сталь**: ресурс, материал (10 вещей), технология «сталеварение» (люди, гномы; литейня или магмакузня), в продаже у литейни. Эльфийские рощи в кампании продают лук из святого дерева.
- **Таблицы**: «Породы деревьев», «Камень», «Материалы рас» (строка на расу, столбец на член семейства).
- **Проверено**: `npm run kinds` (8 проверок: смесь земли, книга склада, худшее/лучшее, святое дерево у мастера и без, сталь против железа, «не делает»/«табу»/«грязн.», сохранение, рынок). Кампания (10 миров, авто): с короной ≈85% (эльфы 90, гномы 80, люди 95, орки 75) — в пределах цели ≤90%.
